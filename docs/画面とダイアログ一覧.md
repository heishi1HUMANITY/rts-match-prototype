# 画面とダイアログ一覧(現行 + 将来)

今から着手する制作順は [アセット・画面・ダイアログの制作優先度](制作優先度.md) を参照。将来画面の「高・中・低」は企画上の旧分類で、独立画面が必要な時期や未採用機能の着手条件はリンク先に整理した。

2026-10-05 時点のクライアント実装(`packages/client/src`)を正とした画面・ダイアログの一覧。将来の画面はここに追記する。スクリーンショットは `docs/screens/`(実サーバー、900×420 のスマホ横持ち相当)。

```
S01 タイトル → S02 再接続中 → S03 ロビー → S04 文明・アドオン選択 → S05 試合HUD → S06 リザルト → S03
                 ↑ 保存済みセッションがあれば起動直後に S02(S01 を省略)
```

## 2. S02 再接続中

| 項目 | 内容 |
| --- | --- |
| 名称 | 再接続中(CONNECTING) |
| 目的 | WebSocket 接続とサーバーからの状態通知を待つ |
| 遷移元 | 起動時(localStorage に名前と playerId がある)、S01 のログイン |
| 遷移先 | サーバーの `lobby` → S03、`match_start` → S05(試合中のリロード復帰) |
| 実装 | `main.ts` の `gotoConnecting()` |

スクリーンショットなし(接続が速く一瞬で遷移する。復帰後の画面は `screens/08b_match_resume.png`)。

### 2.1 構成要素

| 領域 | 表示 | 操作 |
| --- | --- | --- |

| 「別の名前で入る」 | — | 保存した名前と playerId を消して再読み込み(S01 へ) |

接続は指数バックオフ(0.5〜8秒)で自動再試行する。
