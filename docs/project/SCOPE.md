# 初期スコープ

## 目標

世界観の説明を読まず、ブラウザでプレイヤー1人がNPC2陣営と1v1v1の対戦本編を遊べる。
各陣営に1人が属する独立した三つ巴。NPCは人間と同等の参加者で、旧仕様の「現地勢力」とは別。

G1の盤面・部隊移動はユーザー合格・マージ済み。現在はG2の戦略ループを実装する。以下の試合全体は今後の実装目標であり、完成済みではない。

G2は [G2_DESIGN.md](preparation/G2_DESIGN.md) の暫定契約を採用。強襲/偵察、補給と維持費、拠点収入/制圧、首都、生産、2段研究、視界、チケット更新までを手動で試せることを範囲とし、NPC判断・勝敗・脱落・再建を含めない。

G1で実装する盤面・状態の暫定契約は [G1_IMPLEMENTATION_DESIGN.md](G1_IMPLEMENTATION_DESIGN.md) と [DECISIONS.md](DECISIONS.md) のD015以降を参照。ここに記すG1値は最終バランスや完成を意味しない。

## 最初のプレイ可能版

- 開始 → 移動・生産・制圧・自動交戦 → NPCの行動 → 勝敗 → 再戦が一続きで成立。
- 補給と試合内研究を含む、拠点を取り合う判断ができる。
- シード付きマップと固定tickの進行でルールを再現できる。
- プレイヤーは自陣営のみ操作でき、NPCにも資源・視界・コストの制約がある。
- 3陣営を色と記号で区別し、操作対象・HP・資源・チケット・終了理由を表示。
- 必要な説明は機能名と短い操作ガイドで行う。陣営はA/B/C、世界観用語の事前知識不要。
- 終了後の再戦で状態が混ざらない。ローカルの新規cloneだけで実行可能。

## 対象外と後続対象の区別

オンライン対戦、対戦相手の検索・待機キュー、サーバー、アカウント、
永続育成、文明固有能力、指導者、アドオン持ち込み、物語、
ランク、課金、ショップ、クラン、自由チャット。

2026-10-11のユーザー指示により、建築・中立NPC・兵種・研究・部隊操作などの試合内ゲームプレイは後続の必要機能として [網羅表](GAMEPLAY_COVERAGE.md) / Issue #12〜#28で追跡する。最小試作で未実装だったことを全体スコープからの除外にしない。旧仕様の矛盾や暫定ルールとの差は各Issueで設計し、採否未決のまま完成扱いしない。

最小試作のG1〜G4だけでゲームプレイ全体の完成とはしない。試合外機能の除外と、試合内の戦術効果の採否を分ける。
