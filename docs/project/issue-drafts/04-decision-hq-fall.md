# 04 [decision] 首都陥落による即脱落の扱い

- タイトル: `[decision] 首都陥落による即脱落の扱い`
- ラベル: `enhancement`, `kind:decision`

## 本文

### 目的

首都（HQ）HPが0になると即脱落する現行仕様（D058）を維持するか決める。

### 背景（エージェント試遊 2〜4周）

- 2〜4周の試遊9試合のうち6試合が首都急襲で決着。HQ 1200 は強襲＋自走砲5両で約25〜30秒、2400でも7部隊で約27秒、4000案でも数十秒で落ちる（火力は毎秒約100）。
- チケットを200〜300残した陣営が即消え、試合が10〜15分で終わる。研究・専攻を終盤で使い切る前に終わり、「強く見えた者が2人から狙われる」期間が短い。
- 試遊3体が独立に変更を要望。

### 選択肢

1. 現行維持（即脱落）。HQのHP・防御の数値だけで調整（09 の HQ 4000 案）。
2. HQ陥落は大量チケット減＋生産停止（脱落はチケット0のみ）。首都再建なし（D031/D058 の再建なしは維持）。
3. HQに地上向けの防御（砲座・守備）を Lv1 から持たせ、陥落は即脱落のまま。
4. HQ陥落後、一定時間の占領で脱落（その間に奪還可能）。

### 判断材料

- 2 は「首都と全部隊を失うと脱落」の旧条件（D031）に近い。3 は拠点防空（D088）と同じ拡張で実装が小さい。
- 決定後に実装Issueを分け、09 の HQ 値を見直す。
