## ループ中に直した不具合

- main由来（fix-playtest-findings）: 対空識別半径88セル、自走砲が中立拠点を撃てない、守備復活なしで制圧不能、守備なし中立拠点を攻撃不能

- ドライバー: まとめ命令の数え方ほか表示多数

## 追加した仕組み（balance）

- 損失の死因・撃破記録（自陣営分だけ表示）、HUDの損失通知
- 修理のマスタ化と拠点修理（既定0）

## 残った不満（仕組みの判断が要るもの）

1. 首都陥落で即脱落（D058）: 2〜4周で首都急襲が決着を決めた。HP4000でも数十秒
2. 研究の道筋が試合の形を決めない: 兵站は段1→段4直行、段2〜3が無い、効果が小さい（研究ツリー再設計＝F22相当）
3. 生産が陣営1列で補給が余る（上限を上げても残る）
4. 交戦の自動性: 目標撃破後の待機、移動攻撃、待機時の反撃・構え（D090と両立する別命令）
5. 中立化した拠点のHP全快（D045）で2回削る必要
6. 情報: 研究の説明・前提・解放条件、敵拠点砲座の性能、チケット減少の内訳、隣人の勢力の目安
7. 領土圧が開始直後から効く（猶予なし）
