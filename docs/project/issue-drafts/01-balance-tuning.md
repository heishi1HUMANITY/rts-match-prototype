## 本文

### 目的

2026-10-20 のテストプレイ所感（ヘリ量産で敵拠点を中立化して回るだけで勝てる／対空は迂回され守り側だけが消耗する／速すぎて考える時間がない／プレイが軽い）に対し、4点を一つの調整として入れる。#90 の 2026-10-19 追記（期間・ヘリは変更しない）は本Issueで置き換える。決定は DECISIONS D086〜D090。

### 実装範囲（実装済み）

1. 試合時間: 1tickの実時間 `match.tickDurationMs` をマスタ化し既定200ms（旧100ms）。研究収入は 24 centi/tick で実時間1.2pt/sを維持。初期チケット400、時間減衰15〜25分。
2. 研究順: `aircraft-1` を情報段2（survey-1後）へ。段1の対空車両・対空陣地より後。
3. 拠点防空: 所有拠点はLv1から対空（小中大40・首都50、射程4）。強化砲座は段別の対空火力（`turretDamageVsAir`）。
4. 継戦能力: 兵種別弾数、弾切れで火力25%、所有拠点の半径内で補給、残弾閾値と0到達で自動帰還（部隊ごとON/OFF、手動命令優先、制圧中は帰還しない、NPCは帰還中に命令しない）、HUDに残弾と切替。
5. 試遊ループで追加: 損失の死因・撃破の記録（自陣営分のみ表示、HUDに直近の損失）、修理のマスタ化と拠点修理（`sustainment.baseRepairPercent`、既定0で現状維持）。

MatchState schema 29、master schema 31、rules `cp14-time-airdefense-sustain-v1`。

- [x] 標準設定のNPC3陣営12試合で決着の中央値が実時間18〜22分（19.0分）。`npm run audit:match-length`
- [x] 実simでヘリ2機は小拠点Lv1を中立化できず、5機で中立化すると1機以上を失い、残弾で2つ目は落とせない（`balance-invariants.test.ts`）。
- [x] 弾切れで火力が設定比率に下がり、補給圏内で回復し、自動帰還のON/OFFと手動優先・制圧中の不帰還が効く（`sustainment.test.ts`）。
- [x] ヘリ解放研究が対空手段の解放研究より後段（`balance-invariants.test.ts`）。
- [ ] CI（Windows/Linux check、e2e）を最終headで通す。
