# 02 [不具合] 試遊で見つかった main 由来の戦闘・制圧の不具合4件

- タイトル: `[不具合] 試遊で見つかった main 由来の戦闘・制圧の不具合4件`
- ラベル: `enhancement`, `flow:implementing`, `gate:play`
- ブランチ: `claude/fix-playtest-findings`（mainから分岐、実装済み・PR未作成）

## 本文

### 目的

エージェント試遊で見つかった、main 時点から存在する不具合を直す。いずれも修正前に失敗し修正後に通るユニットテストを付けた。

### 実装範囲（実装済み）

1. 対空の識別半径が「猶予tick ÷ 接近速度」で約88セル（100×100のほぼ全域）になっていた → 「猶予tick × 接近速度」で約25セル。D080に注記。
2. 自走砲（構えあり）が、守備を倒した中立拠点を撃てない（構え後の目標再確認が所有拠点しか認めない）→ 選択と同じ条件に統一。
3. 守備の復活を無効（`defenses.respawnEnabled: false`）にすると、守備を倒した中立拠点がいつまでも制圧できない → 制圧処理を続行。
4. 同じ設定で、中立化した元所有拠点（守備なし・HP全快）を攻撃も制圧もできない → 守備のない中立拠点（首都以外）を攻撃対象にする。

### 受入条件

- [x] 識別半径が「射程＋猶予tick×接近速度×√2」と一致する（`air-defense.test.ts`）。
- [x] 構えのある自走砲が守備撃破済みの中立拠点にダメージを与える（`combat.test.ts`）。
- [x] 守備復活なしで、守備撃破済み拠点と守備なし中立拠点を制圧できる（`neutral-defense.test.ts`）。
- [ ] CI（Windows/Linux check、e2e）を最終headで通す。
