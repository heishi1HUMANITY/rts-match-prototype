# 11 [調整] 開始直後の領土圧に猶予を設ける

- タイトル: `[調整] 開始直後の領土圧に猶予を設ける`
- ラベル: `enhancement`, `flow:implementing`, `gate:play`
- ブランチ: `claude/territory-grace`（03 の上に実装済み・PR未作成）

## 本文

### 目的

最初の中立拠点を物理的に取れる前（開始1〜2分）から領土圧でチケットが減る（試遊で毎回 −10〜23）。開始直後の領土圧に猶予を設ける。

### 実装範囲（実装済み、DECISIONS D091）

- マスタ `tickets.territoryGraceTicks`（既定0で現行と同じ）を追加し、その間は領土圧（拠点差のペナルティ）を課さない。時間減衰は対象外。
- 調整ループで値を試し、採用値は 09 と合わせて決める。

### 受入条件

- [x] 猶予中は領土圧が0、猶予後は現行と同じ量になる（`tickets.test.ts`）。
- [x] 既定0で既存のチケットテストが変わらない。
- [x] master schema 32 の移行で旧保存値を保持する（`rules-validation.test.ts`）。

参考: 最終数値案に猶予600tick（2分）を加えても NPC 12試合の決着中央値は19.3分のまま。

### ユーザー検査

要 — チケットの減り方を変えるため。
