# 07 [decision] 交戦の自動性（移動攻撃・待機時の構え・目標撃破後）

- タイトル: `[decision] 交戦の自動性（移動攻撃・待機時の構え・目標撃破後）`
- ラベル: `enhancement`, `kind:decision`

## 本文

### 目的

「戦闘は配置と戦力で決まる答え合わせで、操作の巧さは問わない」（D065）に対し、部隊が自動で応戦しないために操作量で負ける場面を減らす方法を決める。

### 背景（エージェント試遊 1〜4周）

- 拠点へ進軍中の部隊は、撃ってくる敵より目標を撃ち続けて全滅する（D090 で現行維持を決定済み）。
- 目標を倒すと待機に戻り、近くの敵へ移らない。待機中は射程外から撃たれても反撃しない。4セル隣の味方が交戦中でも待機部隊は動かない。
- 30秒3操作の上限下で、交戦中に再命令できず死ぬ場面が各試合で3〜5回。

### 選択肢（D090 と両立する別命令・設定として）

1. 移動攻撃: 途中の敵に応戦しながら目標地点へ進む命令。
2. 待機時の構え（部隊ごと）: 持ち場防衛（射程内の敵を撃ち、近い敵へ寄る）／後退。
3. 目標撃破後の交戦継続: 指定目標が倒れたら視界内の最も近い敵へ移る（部隊ごとON/OFF、自動帰還と同じ形）。

### 判断材料

- 3 は自動帰還と同じ「部隊ごとの切替」で実装が小さい。1 はブラウザ操作（ドラッグ）への割当も決める必要がある。
