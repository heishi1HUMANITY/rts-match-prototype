# 06 [decision] 生産列と余剰補給の使い道

- タイトル: `[decision] 生産列と余剰補給の使い道`
- ラベル: `enhancement`, `kind:decision`

## 本文

### 目的

補給が余り続ける問題の扱いを決める。

### 背景（エージェント試遊 1〜4周）

- 全周で補給が400〜1200余った。生産時間−20%・部隊上限11にしても残る。
- 制約は陣営全体で1本の生産列と部隊上限。前線生産の専攻を取っても出現場所が変わるだけで生産量は同じ。
- 操作上限下では、生産1体ごとに1操作を使うことも詰まりになっている。

### 選択肢

1. 拠点ごとに生産列（所有拠点数だけ並列）。
2. 生産の一括予約（同種×N を1命令）。
3. 余剰補給の使い道を足す（研究ポイントへの変換、前線拠点への投資・強化）。
4. 補給収入を下げて余りを無くす（数値のみ）。

### 判断材料

- 1 と 3 は経済・研究のテンポを変えるため、05 の研究ツリーと合わせて決めるのが安全。2 は操作量だけの変更で小さい。
