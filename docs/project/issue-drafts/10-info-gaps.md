# 10 [情報] 研究・拠点砲座・チケット減少の内訳を表示

- タイトル: `[情報] 研究・拠点砲座・チケット減少の内訳を表示`
- ラベル: `enhancement`, `flow:ready`, `gate:play`

## 本文

### 目的

試遊で繰り返し「判断材料が無い」とされた情報を、霧の範囲を守って表示する。

### 実装範囲

1. 研究: 効果の具体値（`damage-bonus:1` ではなく「火力+1」「維持費−1/部隊」「橋2級を建設可能」）、前提と次に開くノード、完了数による必要量の増加率。
2. 拠点: 強化後の砲座の陸/空火力・射程を強化前に表示。見えている敵拠点の砲座・守備の性能。
3. チケット: 自陣営の減少を「部隊損失／領土圧／時間減衰」に分けて表示（領土圧は公開済みの拠点数から計算できる範囲）。
4. 中立拠点の守備: 接触前でも拠点規模ごとの標準性能（マスタ値）を表示。

### 受入条件

- [ ] 研究カードに効果値・前提・増加率が出る（UIユニットテスト）。
- [ ] 自陣営のチケット減少の内訳の合計が実際の減少と一致する（ルールテスト）。
- [ ] 視界外の敵の数・位置・研究を新たに表示しない。
- [ ] PCと900×420で表示を確認する。

### ユーザー検査

要 — 表示を変えるため。

### CP

CP14。依存: なし。

試遊ドライバー（03）の `rules` には一部（守備性能・修理・首都HP）を出し済み。隣人の勢力の目安（拠点数・推定戦力）は霧との兼ね合いがあるため別途判断。
