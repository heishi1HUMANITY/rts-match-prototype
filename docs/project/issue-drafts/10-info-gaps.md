# 10 [情報] 研究・拠点砲座・チケット減少の内訳を表示

- タイトル: `[情報] 研究・拠点砲座・チケット減少の内訳を表示`
- ラベル: `enhancement`, `flow:implementing`, `gate:play`
- ブランチ: `claude/info-display`（03 の上に実装済み・PR未作成）

## 本文

### 目的

試遊で繰り返し「判断材料が無い」とされた情報を、霧の範囲を守って表示する。

### 実装範囲（実装済み）

1. 研究: 効果の具体値（`damage-bonus:1` ではなく「火力+1」「維持費−1/部隊」「橋2級を建設可能」）、前提と次に開くノード、完了数による必要量の増加率。
2. 拠点: Lv1対空・強化後の砲座の陸/空火力・射程と次レベルの性能を表示。見えている敵拠点の武装。
3. チケット: 自陣営の減少を「部隊損失／領土圧／時間減衰」の累計に分けて記録・表示（資源欄、試遊ドライバー）。
4. 中立拠点の守備: 接触前でも拠点規模ごとの標準性能（マスタ値）を表示。

### 受入条件

- [x] 研究カードに効果値・前提・増加率・次に開く研究が出る（`research-text.test.ts`）。
- [x] 自陣営のチケット減少の内訳の合計が実際の減少と一致する（`tickets.test.ts`）。
- [x] 視界外の敵の数・位置・研究を新たに表示しない（追加はマスタ値と自陣営のデータのみ）。
- [x] PCと900×420で表示を確認した（研究カード・拠点パネル・資源欄）。
