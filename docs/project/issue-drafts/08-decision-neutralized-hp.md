# 08 [decision] 中立化した拠点のHP全快

- タイトル: `[decision] 中立化した拠点のHP全快`
- ラベル: `enhancement`, `kind:decision`

## 本文

### 目的

所有拠点がHP0で中立に戻るとHPが最大に戻る現行仕様（D045、`combat.ts` の `hp: base.owner !== null ? base.maxHp : hp`）を維持するか決める。

### 背景（エージェント試遊 2〜4周）

- 敵拠点を取るには「中立化までHP0にする→全快した拠点を再びHP0にする→制圧」と2回削る必要がある。試遊4体が「説明がなく2回削る理由が分からない」と報告。
- 守備復活あり（標準）では守備も満タンで復活し、奪還が重い（1周目で2体が指摘）。

### 選択肢

1. 現行維持（help・HUDで説明する）。
2. 中立化時のHPをマスタの割合にする（例 `defenses.neutralizedHpPercent`、0なら即制圧可能）。既定値は議論。
3. 敵拠点はHP0で中立化せず、そのまま制圧可能な状態にする（中立化は所有者不在時のみ）。

### 判断材料

- 2 はマスタ1項目の追加で小さく、既定100で現行と同じにできる。調整ループで値を試せる。
