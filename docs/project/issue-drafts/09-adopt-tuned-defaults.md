# 09 [調整] 試遊ループで得た数値案を既定値へ反映

- タイトル: `[調整] 試遊ループで得た数値案を既定値へ反映`
- ラベル: `enhancement`, `flow:ready`, `gate:play`

## 本文

### 目的

エージェント試遊の調整ループ（4周＋最終計測）で得た数値案を既定値にする。値は `tuned-patch.json`（部分マスタ）。

### 実装範囲

- 既定値の変更: 初期チケット450、領土圧上限150%、守備復活なし、中立守備HP 中150・大240、首都HP 4000、部隊上限11（基本6）、強襲弾32、自走砲 対地95・対建造物110、全兵種生産時間−20%、補給/前線回復半径5、拠点修理2%、自動帰還閾値15%、補給線+12・維持費−3・火力各段+3、兵站/戦時経済専攻380pt。
- 保存マスタの移行（旧既定値のままの項目だけ新既定へ）、DECISIONS に不変条件と暫定性を記録、影響するテストの更新。

### 受入条件

- [ ] 標準設定のNPC3陣営12試合で決着中央値18〜22分（最終計測 19.3分）。
- [ ] 戦法ボットでヘリ襲撃の勝率が通常NPCを上回らない（`npm run probe`）。
- [ ] 変更した値がすべてマスタから変更でき、npm run check / references:check を通す。

### ユーザー検査

要 — 試合の時間と強さを変えるため。

### CP

CP14。依存: 01、04（首都の扱いが変わる場合はHP値を見直す）。

### 未検証

最終案はNPC計測のみでエージェント試遊は4周目の案（チケット400・HQ2400 等）まで。
