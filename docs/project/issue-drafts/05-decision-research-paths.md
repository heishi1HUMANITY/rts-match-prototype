# 05 [decision] 研究の道筋が試合の形を決める研究ツリー

- タイトル: `[decision] 研究の道筋が試合の形を決める研究ツリー`
- ラベル: `enhancement`, `kind:decision`

## 本文

### 目的

面白さの定義（#79、D065）の「研究の道筋が拡張先・戦い方・狙う相手を決め、中盤で形になり終盤で使い切る」が、現行ツリーで起きていない。ツリーの形と効果量を決め直す。

### 背景（エージェント試遊 1〜4周、12試合）

- 「研究が試合の形を決めた」と答えたのは12試合中2〜3。形を決めたのは橋の所有と地形、自走砲の解禁。
- 兵站分野は段1（2件）から段4へ直行でき段2〜3が無い。専攻が1〜6分で取れて「中盤で形になる」過程が無い。必要量を上げると今度は中盤に遅れる（500pt で8:20）。
- 段1〜3の効果が小さい: 火力+1（自走砲95に約1%）、補給線+1 centi/tick（収入の約0.8%）、維持費−1。+3/+12/−3 に上げても「手応えなし」の報告が残る。
- 隣人の道筋が見えないまま専攻を決めている（敵を一度も見ずに2分で専攻確定）。
- 要望: 分野ごとの段2〜3ノード（兵站: 前線補給範囲・前線修理、工兵: 橋の強化・破壊）、攻城系研究（対建造物↑と対部隊↓の交換）、%指定の効果、研究の予約、専攻は段2〜3の後のみ。

### 選択肢

1. 2026-10-14 の相談案（段2〜4が三択排他、専攻1つ、約40ノード、必要量 80/160/280/450pt、ヘリは専攻）を採用し実装Issueへ分割。
2. 現行ツリーを維持し、兵站・工兵に段2〜3を足し、効果を%指定にする最小改修。
3. 1 の構造に、攻城/要塞などの対になる段2〜3ノードを加える。

### 判断材料

- 決定後、研究完了率・専攻時期の検算（#81/#87 の不変条件）をやり直す。調整ループ（03 の道具）で道筋ごとの勝率と試遊所感を確認できる。
