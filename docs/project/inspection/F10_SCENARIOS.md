# F10 拠点強化の画面検査

## 対象

- シナリオ: `f10-base-upgrades`（画面表示:「検査：拠点強化」）
- 対戦NPCと現地勢力は停止。Aの研究2種が完了し、OUT-01を所有した状態から開始する。
- 標準ルールでは強化の実時間はLv2が60秒、Lv3が90秒。残り時間を待たずに完了を期待しない。

## 手順

1. 設定画面で「検査：拠点強化」を選んで開始し、拠点パネルからOUT-01を選ぶ。
2. Lv1、HP/最大HP、収入を確認する。Lv2の必要研究・費用・所要時間と現在値が表示される。
3. 「Lv2へ強化」を実行する。補給が一度だけ減り、残り時間が表示され、再度の開始操作は無効になる。
4. 強化完了後、Lv2・最大HP・収入倍率を確認する。HP比率は強化前後で保たれる。
5. Lv2砲座が射程内の敵部隊を攻撃すること、Lv3の解放条件・費用・時間が表示されることを確認する。
6. Lv3強化を実行し、完了後にレベル/最大HP/収入倍率/砲座damageが更新されることを確認する。
7. 拠点への攻撃後はHPが減り、被弾停止時間の間は回復せず、その後に自動回復することを確認する。
8. 強化済み拠点を敵部隊で制圧する。成功後はLv1、Lv1最大HPの30%、強化ジョブなしへ戻る。
9. 別の強化済み拠点で次レベル強化中に所有権を失わせる。ジョブが消え、未完了の費用は戻らない。

## 画面サイズと境界

- 横持ち900×420とPCで拠点選択、強化ボタン、残り時間、理由を確認する。
- パネルが縦に収まらない場合はパネル内をスクロールして強化操作へ到達できることを確認する。
- 研究未完了、補給不足、最大レベル、所有権なし、稼働HPなし、強化中の各条件で実行不可理由を確認する。
- 通常試合ではB/Cが自分の拠点だけを判断材料にし、投資後も共通の残高/強化ルールに従うことを確認する。
- 診断replayでは適用RulesMaster snapshotと内容IDを保持し、現在のマスター保存値に左右されないことを確認する。

実装時のローカルブラウザ確認では、横持ち900×420でAの強化開始後に補給支払い・60秒の残り時間・再操作無効化を確認した。砲座射撃、強化完了、被弾回復、制圧リセット、通常試合のB/C投資、実タッチ端末操作はユーザー検査対象。
