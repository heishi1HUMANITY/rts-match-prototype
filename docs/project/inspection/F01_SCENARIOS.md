# F01 複数部隊の一括操作

対象: Issue #13。固定地点への一括移動を追加する。敵や拠点を追跡する操作はF02で追加する。

## 画面で確認すること

1. 「開始」後、「複数選択」をONにし、盤面の自軍部隊または下の部隊カードを順にタップする。選択数と複数の選択表示が増える。同じ部隊をタップするとその部隊だけ解除する。
2. 「すべて選択」で現在いる自軍部隊を選ぶ。選択した部隊のどれかを地面へドラッグする。複数の経路が表示され、離すと全選択部隊がその目的地へ向かう。地面を短くタップしても一括指示できる。
3. 「部隊停止」で選択中の全部隊が次のセル中心で止まる。選択外の部隊の命令は変わらない。
4. 複数選択をOFFにして未選択の自軍部隊を押すと単体選択へ戻る。選択済みの部隊をドラッグした場合は集団を維持する。「選択解除」で全解除する。
5. 孤立セル(30,10)へドラッグし、到達不能の表示と拒否理由を確認する。命令が通らない部隊があっても、移動可能な他部隊の命令は受け付ける。
6. HUD上へのドロップ、盤外、Esc、二本指への切替、リセットで意図しない移動命令が出ない。一時停止中は選択できるが移動できない。
7. 選択部隊が消滅したらその部隊だけ選択から消える。試合終了・自軍脱落・リセットで全選択とプレビューが消える。

PCと横持ち900×420で、選択ボタン、部隊カードの横スクロール、選択数、経路、停止を確認する。タッチでは複数選択ONのタップと一本指ドラッグ、二本指カメラ操作を確認する。

## 契約と検証の限界

選択はUI/runtimeの状態で、simulationのschema5/rules g3-v1を変更しない。集団命令は重複を除いた部隊ID順に既存move/stopを適用し、結果を部隊ごとに履歴へ残す。一部拒否でも全体を取り消さず、成功数と拒否理由をまとめて表示する。隊形維持、衝突回避、敵や拠点の追跡は今回含まない。

自動テストで選択・一括命令・拒否・履歴再現・入力の取消・描画モデルを検証する。実ブラウザによるピッキング、見た目、画面サイズ、タッチの確認は別途必要。ブラウザ自動操作がURL制限で拒否されたため、これらは未検査として扱う。
