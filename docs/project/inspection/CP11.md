# CP11: プレイ検査票

## 通常設定で1試合

#80の100×100版を現行ルールで通常1試合プレイする。確認は以下3項にまとめた5点。tick処理時間は実装側の測定結果を併記し、人間に測定作業を求めない。
対象のマージ途中で自動生成された票は準備中。まとまりの対象が揃うまでプレイ確認を依頼しない。結果は確認3点ごとにOK / NGと対象Issueを記録する。

## 確認3点

1. HQ間移動の長さと、900×420で2戦線を追えるかを確認する。
2. 最大9部隊が少なすぎる/多すぎるか、決着が戦闘・チケット・安全弁のどれによるかを確認する。
3. 処理時間の測定と体感の重さを確認し、結果まで進んで再戦できる。

## 既知の未検証

マージ済みとプレイ検証済みは別。未使用の専攻・開始地点・傾向・端末と、持ち越し機能は実際に確認した範囲だけ合格にする。自動検証の成功やCPの工程終了からプレイ合格を推定しない。
