# F02 画面確認手順

対象: Issue #14。F01の複数選択・一括停止はそのまま使える。

## 最初に確認する操作

1. 通常設定で開始する。部隊を中立拠点の記号/ラベルへドラッグし、離す。ドラッグ中に「進軍先: 拠点ID」、選択欄に進軍状態が出て、その拠点へ移動・制圧する。
2. 敵が見えたら自軍を敵の記号/ラベルへドロップする。「追跡先: 敵ID」が出て、敵の移動に合わせて進路が変わり、射程に入ると交戦する。
3. 「複数選択」または「すべて選択」で複数部隊を選び、選択済みのどれかを敵/拠点へドロップする。選択群へ同じ対象を指示できる。
4. 地面へ新しくドロップ/タップする。固定地点移動へ戻り、部隊カードの進軍矢印が消える。「部隊停止」でも追跡が解除される。

## 追跡用の短時間検査

「検査設定」で「検査：移動する敵の追跡」を選び、「適用してリセット」。通常のNPC判断を止め、近くのB部隊を初期経路で移動させる検査であり、通常対戦の設定とは別。

開始前にA-01を選び、開始後にB-01へドロップする。A-01は(17,20)、B-01は(21,20)付近から始まり、B-01は近辺を周回する。敵の進行に合わせて追跡経路が更新される。

視界喪失を試す場合はリセットし、今度は遠くのA-02へB-01の追跡を指定する。その後、観測役のA-01を左方へ移動させる。敵が見えなくなるとA-02は「最終確認位置へ・追跡保留」となり、見えない敵の現在位置へ経路を伸ばさない。A-01を戻して再び敵を見せると追跡が再開する。

## 続けて確認すること

- 所有が変わった拠点、破壊された敵前哨拠点、自軍拠点へ進軍しても攻撃・制圧・待機の扱いが破綻しない。
- 孤立セルなどへの固定移動は従来どおり拒否され、既存の指示が残る。
- ドラッグをHUD/盤外/Esc/二本指で取り消すと新命令が出ない。一時停止中は進軍しない。
- 試合終了/リセット/再戦で選択・追跡指定・プレビューが残らない。
- PCと横持ち900×420で対象名、選択数、部隊カード、追跡経路、停止が読める。タッチでも敵/拠点へのドロップができる。

実ブラウザの見た目・ピッキング・操作感は未検査。ブラウザ自動操作がlocalhostのURL制限で拒否されたため、迂回して検査済みとは扱わない。自動テストとCIの結果は対象commitに紐付けてIssue/PRへ記録する。
