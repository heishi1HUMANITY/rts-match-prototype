# F09 画面検査シナリオ

## 起動と設定

ブランチ `feature/f09-research-tree` の最新commitで `npm ci`、`npm run dev` を実行し、表示されたlocalhost URLを開く。検査設定で「生産・研究（NPC停止）」を選び「適用してリセット」を押す。このscenarioはNPC判断を止め、A/B/Cに研究バンクを付ける。通常設定とは別の検査用設定。

## 操作と期待結果

1. 「研究」を開く。戦力・兵站・情報・工兵のカードが分野/段階、費用、効果、前提、排他と一緒に並ぶ。研究のない将来機能は表示されない。
2. 「情報 1」を選ぶ。scenario bankから費用を引き、情報カードが完了になる。盤面で自軍の視界が広がる。
3. 「維持費減額」または「拠点補給収入」を選ぶ。兵站効果の選択で反対側が無効理由「排他」となり、完了後に資源収支の内訳へ反映される。
4. 「戦力研究 I」を完了して交戦を起こす。攻撃+1が部隊のdamageに適用される。次に前提を満たした「戦力研究 II」を選び、進捗が研究ごとに保持される。
5. 「工兵」の橋/索道研究を完了する。該当する設備の建設だけが可能になる。未完了研究は必要な前提IDとともに無効理由を表示する。
6. 研究途中に解除・別研究へ切替・再選択し、未指定時のbank、固定0.2pt/秒、完了時の余剰bank、自動連鎖がないことを確認する。
7. NPCを再開する通常設定へ切り替えてB/Cも研究を進めること、診断JSONを保存してreplay結果が一致することを確認する。

## 判定範囲

確認する対象は研究ツリーの操作、研究済み効果、前提/排他理由、進捗保持、PCおよび900×420横画面。ブラウザで操作した範囲、実機タッチの可否、画面の実測サイズ、対象commitは検査記録へ追記する。研究費用と効果量はF16調整前の暫定値。
