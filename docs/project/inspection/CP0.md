## 通常設定で1試合

公開ゲーム画面でマスタの「標準値へ戻す」→「保存値で新しく開始」を選び、「開始」から結果まで通常設定で1試合プレイする。保存済み独自設定は先にJSONを書き出して退避できる。NPC修正の標準値は3秒ごと・最大2命令。結果はCP0の検査結果Issue #51へ「OK / NG(#54)」として記録し、#12へ反映する。

## 確認3点

1. **対戦NPC B/C / #54：反応する余地がある。**
   OKの具体像：敵の進軍に気づいてから、自軍を選んで移動または生産する判断・操作を行える。勝利の有無だけで判定せず、反応する間もなく押し切られる場合はNG。
2. **F08 / #20：生産した部隊で対処できる。**
   OKの具体像：通常試合内に強襲と偵察を各1部隊追加生産し、区別して通行可能な陸地へ移動指示できる。生産や兵種・移動の不具合はF08、操作時間不足は#54と報告する。
3. **F10 / #22：研究と拠点強化を試す余地がある。**
   OKの具体像：試合開始から5分以内に必要研究を進め、自軍拠点1つをLv2へ上げ、Lv2表示と最大HP増加を確認できる。強化不具合はF10、敵の圧力で操作できない場合は#54と報告する。
