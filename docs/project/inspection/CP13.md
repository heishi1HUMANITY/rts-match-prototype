# CP13: プレイ検査票

## 通常設定で1試合

#85〜#89がマージされ自動検証が通ってから、まとめて通常1試合プレイする。使わなかった専攻・操作は未検証として記録する。
対象のマージ途中で自動生成された票は準備中。まとまりの対象が揃うまでプレイ確認を依頼しない。結果は確認3点ごとにOK / NGと対象Issueを記録する。

## 確認3点

1. 航空の進路と対空の配置を、通知・経路・射程表示から判断できる（#85）。
2. 観測と地点砲撃、前線展開・全域観測・封鎖等で、進出先や戦い方が変わる（#86/#87）。
3. 戦闘見込みを理解でき、首位への警戒・隙への介入を行うNPCに対して配置と研究で対応できる（#88/#89）。

## 既知の未検証

マージ済みとプレイ検証済みは別。未使用の専攻・開始地点・傾向・端末と、持ち越し機能は実際に確認した範囲だけ合格にする。自動検証の成功やCPの工程終了からプレイ合格を推定しない。
