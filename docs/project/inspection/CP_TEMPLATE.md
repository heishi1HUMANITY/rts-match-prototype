# CP\_: プレイ検査票

## 通常設定で1試合

公開ゲーム画面を通常設定で開始し、結果まで1試合プレイする。結果はこのCPのMilestone所属の検査結果Issueへ「OK / NG(#Issue番号)」で記録する。

## 確認3点

1. 今回の操作と表示を使って、意図した行動ができる。
   OKの具体像：対象機能のIssue番号と、試合内で観測できる成功結果を1行で記載する。
2. 追加された効果と試合の時間・強さが、判断できる表示とつながっている。
   OKの具体像：対象機能のIssue番号と、時間・数量・表示などの成功条件を1行で記載する。
3. 結果まで進み、再戦を開始できる。
   OKの具体像：結果に終了理由が表示され、再戦が初期状態から始まる。対象機能が別なら置き換える。

## 既知の未検証

CPの自動収載対象（gate:play / status:unverified）と、残る端末・操作感・暫定調整の未検証だけを記載する。詳細操作・境界条件はSCENARIOSとe2eで扱う。
