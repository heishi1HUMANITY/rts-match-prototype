# G3の画面確認

G3-r01。プレイヤーにコードレビューは求めず、盤面と操作の結果を確認します。グリッド・部隊記号は引き続き仮表示で、完成版の地形・モデル・UI仕上げはG4以降です。

## 開き方

起動中の検査URLは `http://127.0.0.1:5182/`。再現起動は `npm ci` → `npm run build` → `npm run preview -- --port 5182 --strictPort`。

ページを再読み込みし「検査設定」でseed42とscenarioを選択、「適用してリセット」→「開始」。設定の編集だけでは試合を変更しません。対象の完全SHA・CI・起動状況はIssue #4 / PRに記録します。

## まず試すこと

1. **NPC:** 通常設定で開始。B/Cは霧の先で生産・研究・進軍しています。A部隊を中央拠点へドラッグすると、視界に入ったNPCの移動や交戦が見えます。待っているだけでは視界外の敵の位置は表示されません。
2. **時間切れと再戦:** 「検査：20秒で時間切れ」で開始。残り時間が0になると結果が開き、順位・残チケット・終了理由が表示されます。「同じ設定でもう一戦」で最初の配置・資源から再開します。時間切れの順位は生存軍のチケット順、同点は同順位です。
3. **脱落と引き分け:** 「検査：相手2軍脱落」はB/Cが初期チケット0なので開始直後にA1位・B/C同率2位。「検査：同時全滅」は全軍0なので全軍同率1位・全滅引き分け。検査の初期条件であり、通常設定では全軍チケット1000で始まります。
4. **自軍脱落:** 「検査：自軍脱落と観戦」はAが初期チケット0。部隊・生産・研究は使えず、探索済みの盤面と公開チケットで観戦します。カメラと停止・再開は使え、20秒で結果になります。敵が全て見える観戦には切り替えません。

## 通常設定を一試合

標準は5分。Aは自分で移動・生産・研究し、NPCと拠点を取り合います。チケット0、または首都と全部隊を失うと脱落します。首都だけ壊されても部隊が残れば続行できますが、再建・生産はできません。最後の1軍で決着し、5分経過時はチケットで順位を決めます。

終了後に盤面命令・研究・生産が進まないこと、結果の順位と理由、再戦で研究・部隊・生産キュー・探索・選択が残らないことを確認します。「設定に戻る」は同seed/scenarioの開始前に戻るので、通常設定などへ変更できます。

## 操作と表示

- 一時停止・タブ非表示でNPCを含む試合が停止し、明示再開が必要。
- 結果ダイアログ中は背景の盤面操作を遮断。再戦ボタンにフォーカス、900×420では結果全体をスクロール可能。
- G2の3検査設定のみNPCを停止し、制圧・相互交戦・生産/研究の旧検査を維持。
- 診断JSONはschema5/rules g3-v1。開発用の全情報を含み、通常HUDやNPCへ渡すデータとは別。

実ブラウザー自動操作は以前の安全チェックでURLプロトコル制限により拒否されたため、実画面・DOM/pick境界・900×420・実機タッチは確認待ちです。自動ルール検査の成功を実画面の検証済みとは扱いません。
