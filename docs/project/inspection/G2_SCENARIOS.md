# G2の画面確認

G2-r02。NPCの自動進軍と勝敗はまだありません。B/Cも視界・資源・被弾・自動交戦の共通ルールを使います。グリッドと部隊記号は仮表示です。ユーザーにコードレビューは求めず、以下の操作と画面上の変化を確認します。

## 開き方

`npm ci` → `npm run build` → `npm run preview -- --port 5182 --strictPort`。ローカルURLは `http://127.0.0.1:5182/`。検査対象の完全SHAと起動状況はIssue #3へ記録します。

「検査設定」でseedを42、シナリオを選んで「適用してリセット」を押し、その後「開始」します。設定の編集だけでは試合を変更しません。現在の通常/検査設定を盤面左上に表示します。

## まず試す3項目

1. **制圧:** 「検査：制圧」で開始。そのまま3秒待つと下側のOUT-03がA所有になり、補給収支と研究収入が増えます。拠点を押すか「拠点」で、所有・HP・制圧進捗を確認できます。
2. **生産と返金:** 「検査：生産・研究」で開始→「生産」→強襲、偵察の順に予約。補給180から計180を支払い、強襲が生産中、偵察が待機中になります（時間経過による収入は継続）。強襲を取消すと120が返り、偵察が生産へ進みます。偵察は6秒で首都に出現し、ドラッグで動かせます。
3. **研究:** 「通常設定」で開始し「研究」→Iを選択。拠点なしでも毎秒0.2ポイントが充填されます。「指定解除・バンクする」で充填を止めてバンクを増やし、再選択するとバンクが充填され、元の進捗から続きます。「検査：生産・研究」ではバンク150があるため、I（60）とII（90）が選択時に即完了します。IIはI完了前は前提不足です。パネル中も時間・資源・研究進捗が進みます。一時停止中は止まります。

## 検査専用設定の違い

- `standard`: 補給200/研究0、G1同様の部隊位置、中央に3中立拠点。基本研究収入0.2/秒に所有拠点ごと1/秒が加わる。
- `g2-capture`: A部隊だけを下拠点付近へ配置。
- `g2-combat`: A/B強襲を中央の射程境界に置き、現在HP4。偵察を左右へ配置。
- `g2-economy`: A補給180/研究150、下拠点をA所有にする。

検査設定は初期配置・資源・所有だけを変更し、交戦・視界・コスト・時間の処理は通常と同じです。固定敵の試験だけで通常設定の検査を省略しません。

## 検証範囲

自動テスト・型検査・独立レビューと、実ブラウザー・実機の確認は区別します。エージェントのブラウザー操作はURLプロトコル制限で拒否された経緯があり、G2の実画面・タッチ・性能は確認待ちです。ユーザーの明示合格前にマージしません。
