# CP0 NPC難度修正シナリオ

対象Issue: #54。通常のB/C対戦NPCと現地勢力は分けて検証する。

1. **NPC-R01-01 — 判断頻度と公平な命令上限**: 標準値ではB/Cは30tickごとに各2命令以内。低い命令上限でも生産・研究・強化・全部隊を巡回し、必要な指示を永久に後回しにしない。strategy/runtimeのユニットテストとブラウザ診断で確認する。
2. **NPC-R01-02 — 操作の継続**: 研究充填中は別研究へ切り替えず、同じ行軍目標に不要な再指示を出さない。共通commandで支払いと前提を判定する。ユニットテストで確認する。
3. **NPC-R01-03 — 再現と独立性**: seed42/43/44の同command/masterで診断replayが一致する。旧AI rulesVersionは拒否。現地勢力の判断周期は10tickを維持する。runtimeユニットテストとブラウザ診断エクスポートで確認する。
4. **NPC-R01-04 — 通常試合とリセット**: PC/900×420で標準値を復元して新規試合を開始し、診断に30tick/2命令のsnapshotとB/Cの生産・研究・行軍がある。一時停止でtickを止め、再開・リセットできる。Playwrightで確認する。

自動検証は人間の勝率・操作負荷の合格を保証しない。通常1試合の遊びやすさはCP0の再プレイで判定する。既存の保存設定は保持するため、修正した標準値を試す場合はマスタで「標準値へ戻す」→「保存する」→「保存値で新しく開始」を使う。
