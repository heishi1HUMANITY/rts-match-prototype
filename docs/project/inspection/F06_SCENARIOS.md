# F06 / Issue #18 画面確認シナリオ

検査用fixtureは通常設定と区別してHUDのシナリオ欄から選択する。NPC B/Cの自動命令は停止し、Aの初期部隊を中央島へ配置する。通常試合と混同せず、現地勢力の表示・戦闘・拠点操作を短く確認する。

## 現地勢力の戦闘・奪還

1. シナリオから「検査：現地勢力」を選び、適用してリセットする。A部隊は中央島の現地本拠から少し離れて配置される。
2. 中央島の灰緑色の「現」記号の部隊と本拠が表示されることを確認する。現地部隊はAの選択・命令対象に含まれない。
3. A部隊を現地部隊へドラッグして戦闘させる。互いのHPが同じtickの戦闘で減り、現地部隊撃破はA/B/Cのチケットを直接減らさない。
4. 現地所有のOUT-02を選び、本拠と所有表示を確認する。通常の部隊攻撃で拠点HPを0にし、守備が再配置された場合は守備を倒してから既存制圧条件を満たす。
5. Aが奪還した後、補給と研究充填値が増える。すでにA所有となった同じ拠点から報酬が再度発生しない。

## 通常試合の出現

1. 「通常設定」を選び、A/B/Cが開始時に3陣営として表示されることを確認する。
2. 30秒後に中央島へ現地本拠・初期部隊・OUT-02の所有が現れる。試合は5分設定のまま進行する。
3. 現地勢力はHUDの公開状態と可視部隊だけ表示される。未観測の現地部隊位置・HP・生産資源・標的は画面へ出ない。

本拠討伐報酬、時間経過による部隊成長、PC/900×420表示、同時操作を含む最終確認では、通常UI上で再現手順を行う。数値はF16調整前の暫定値。
