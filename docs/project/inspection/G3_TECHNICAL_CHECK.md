# G3 技術検査記録

G3-r01、Issue #4。検査対象の完全SHAとCIはIssue/PRへ記録する。

## 実装と検査範囲

schema5/rules g3-v1。NPCはFactionViewだけで意思決定し、runtimeの共通advanceが人間と同じcommandへ通す。simulationの決着・順位・脱落処理、runtimeの停止/観戦/再戦/診断再生を自動検査する。G2の手動検査scenarioはNPC停止を維持。

通常5分のseed 0/42/43で試合完走、資源/HPの非負・部隊上限・NPCの進行を確認する。短時間fixtureは20秒の時間切れ、自軍脱落後観戦、開始時の2軍脱落・同時全滅を同じルールで再現する。

独立レビューで次を修正した。

- 開始時にtick0のまま終了するfixtureで診断replayと実状態が一致しない。start commandで初期決着を一元化し、開始直後と終了後拒否命令の回帰テストを追加。
- 結果モーダルの背景がinertになり、終了状態の診断を保存できない。結果にも診断保存ボタンを追加。
- 先に脱落した軍がいる全滅結果も「同時」と表示する。全陣営脱落の表現へ修正。

## 未検証範囲

以前の自動安全チェックで内蔵ブラウザー操作がURLプロトコル制限により拒否されたため、別経路で回避していない。実ブラウザー操作、DOM/pickの実動境界、900×420実表示、実機タッチ、native dialogの実表示・フォーカス、実フレーム性能は確認待ち。自動検査の成功だけでuser-review条件を満たしたとはしない。

本番ビルドの既存JS chunkサイズ警告は継続。公開・デプロイなし、ユーザー合格前にマージしない。
