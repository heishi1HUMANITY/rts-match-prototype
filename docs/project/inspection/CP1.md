# CP1: 施設建築のプレイ検査票

## 通常設定で1試合

公開ゲーム画面を更新し、マスタの「標準値へ戻す」→「保存値で新しく開始」から通常設定で1試合プレイする。独自設定があれば先にJSONを書き出して退避できる。研究欄の`facility-turret`（砲座）や`facility-watchtower`（観測塔）を選ぶと施設を解放できる。結果はこのCPの記録Issueに「OK / NG(#23、困った施設・操作)」で記録する。

## 確認3点

1. **F11 / 建築操作：所有拠点へ砲座を建てられる。**
   OKの具体像：通常試合中に砲座研究を完了し、「施設」で所有拠点を選ぶと建築でき、補給・使用枠・残り秒・完成HPが表示される。
2. **F11 / 観測：観測塔の完成と視界が分かる。**
   OKの具体像：観測塔研究後に空き枠へ建築し、完成後の塔表示と周辺の視界を確認できる。地雷・対空・妨害を使った場合は種類名を添えて不具合を報告する。
3. **F11 / 再戦：施設が次の試合へ残らない。**
   OKの具体像：結果に終了理由が表示され、再戦すると施設・設置枠が初期状態へ戻り、建築操作を再び選べる。

## 既知の未検証

NPCの強さ・マップによる早すぎるPvPはユーザー方針で#28へ保留し、CP1では勝利を要求しない。敵圧力で施設を試せなかった場合もその旨を報告する。F19/F21の自動検証成功はプレイ合格に置き換えない。実機タッチ・5施設の最終数値・未使用種類の操作感は未検証。詳細手順・境界値はSCENARIOSとe2eで扱う。
