# CP12: プレイ検査票

## 通常設定で1試合

#81〜#84がマージされ自動検証が通ってから、まとめて通常1試合プレイする。必要な開始地点の切替確認は同じCP内で行い、機能ごとにプレイをやり直さない。
対象のマージ途中で自動生成された票は準備中。まとまりの対象が揃うまでプレイ確認を依頼しない。結果は確認3点ごとにOK / NGと対象Issueを記録する。

## 確認3点

1. 開始地点と地形から研究・拡張の道筋を選べ、中盤で専攻が形になり終盤で使える（#81/#83/#84）。3開始地点で道筋が分かれることを確認する。
2. 領土を失っても研究・補給が止まらず、HQで守る/1拠点を取り返す判断ができる（#82/#84）。
3. NPCに対処する猶予があり、複数の前線を見ながら決着と再戦まで進める（#83/#84）。

## 既知の未検証

マージ済みとプレイ検証済みは別。未使用の専攻・開始地点・傾向・端末と、持ち越し機能は実際に確認した範囲だけ合格にする。自動検証の成功やCPの工程終了からプレイ合格を推定しない。
