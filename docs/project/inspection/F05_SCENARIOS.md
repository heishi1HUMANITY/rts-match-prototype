# F05 / Issue #17 画面確認手順

## 対象版

- ブランチ: `feature/f05-neutral-defense`
- commit SHA: 検査版のPR作成後に記録
- Build metadata: schema 10 / rules f05-v1。診断には適用RulesMasterの完全snapshotを含む。
- 起動: `npm ci` → `npm run build` → `npm run preview -- --port 5183 --strictPort` → `http://127.0.0.1:5183/`
- PCブラウザと横持ち900×420を確認し、各環境で確認した操作を記録する。

## 短時間シナリオ: 中立守備・制圧

1. シナリオから「検査：中立守備・制圧」を選び、試合を開始する。A部隊は中立のOUT-03近くに配置され、NPC B/Cの自動命令は停止している。
2. OUT-03を選び、守備HPが表示されることを確認する。守備が生存している間は拠点HPが減らず、守備はA部隊へ反撃する。
3. 守備HPが0になると、次のtickから拠点HPが減る。拠点HPと守備HPが別に表示される。
4. 拠点HPが0になるとAの制圧進捗が始まる。Aだけが制圧半径にいる状態を維持すると所有がAへ変わり、拠点HP30から稼働する。収入表示へ反映する。
5. 停止/再開し、進捗が固定tickで保たれることを確認する。

目安は開始から約9秒。マスタを編集している場合は守備値が変わるため、初期値で一度確認する。短時間シナリオは通常設定とは別の検査fixtureである。

## 通常対戦でのNPC確認

通常設定で開始し、B/Cが公開地点の中立拠点へ進軍した場合、守備を倒して拠点HPを削り、制圧することを確認する。守備は順位・陣営数に含まれず、追加の無料生産や報酬はない。画面内で未確認なら未検査のまま記録する。

## 情報境界と復活

- 未観測の中立拠点では守備HPが表示されない。視界を離れると最後に観測したHPとtickの表示になる。
- 拠点所有者が破壊されると中立へ戻り、守備HPと拠点HPが全快する。
- 守備撃破後、制圧可能部隊が半径内に300tick（30秒）いないと守備と拠点HPが全快する。
- 二陣営が同じ制圧半径にいると進捗が止まり、どちらかが離れても進捗は0から始まる。
