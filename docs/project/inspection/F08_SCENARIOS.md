# F08 画面・ルール検査シナリオ

このscenarioは兵種解放・領域差の短時間検査用であり、standard対戦のバランスや全体完成を示さない。基点とseedを固定し、同じcommand履歴をreplayできること。

## F08 unit domains

1. 検査設定から `f08-unit-domains` を選び、seed 42でリセットする。人間Aの補給・研究は各新兵種の生産/研究を確認できる値で、NPC B/Cは同じ初期状態のまま停止する。通常設定と同じNPC挙動はstandard scenarioで確認する。
2. 研究パネルで「自走砲」「対空車両」「攻撃ヘリ」「哨戒艇」の解放状態を確認する。研究前に各生産カードが無効で、前提研究名が表示される。
3. `artillery-1`、`air-defense-1`、`aircraft-1`、`naval-1`を順に完了し、同じ研究充填方式で解除されることを確認する。解放後の各カードに領域・生産時間・費用を確認する。
4. HQから陸/空部隊を、PORT-Aから哨戒艇を生産する。港なしscenarioまたは無効siteでは水上生産が拒否され、資源とIDが変わらないことを診断で確認する。
5. 自走砲を川越し陸路で命令し、渡河設備なしでは停止理由が出る。ヘリは障害地形を直線で越える。哨戒艇は河川から出ず、同一水路の外へ抜けない。
6. 対空車両と航空敵が可視・射程内の短時間scenarioで、対空優先と同時ダメージを確認する。自走砲の対空不可、全兵種の移動中射撃、対象優先順をscenario fixtureで確認する。
7. ヘリまたは哨戒艇が中立拠点を攻撃しHP0にしても所有は中立のまま。陸上の制圧可能兵種が来たときだけ既存時間で所有が移る。
8. 哨戒艇から視界内の完成渡河設備を攻撃し、HP0で中立の予定地へ戻ることを確認する。
9. 戦闘でHPを減らした陸/空/水部隊をHQ近傍で停止し、非戦闘時に毎秒4%回復、HP上限、戦闘中/攻撃被弾中に回復しないことを確認する。
10. 各兵種撃破のticket減少、終了・再戦、pause/resume、診断保存→replay一致を確認する。

## Layout / visibility

- PC表示で生産siteと6兵種の状態/無効理由、研究解除、盤面記号、選択部隊のHP/領域が判別できる。
- 900×420横向きでplayfieldが隠れず、6兵種カードと選択siteへ44px以上のタップ領域で到達できる。横スクロール時に誤ったsite/兵種commandが送られない。
- FactionViewとNPC判断は不可視敵の座標/種類/HP/生産/研究状態を参照しない。

## マスタ設定

- マスタ編集で各兵種の攻撃対象Entity種別を複数選択し、制圧可否を個別に設定できる。設定を保存して新規試合を開始すると、その試合のルールsnapshotに反映される。
- 既定のヘリは部隊・守備・拠点・現地勢力本拠を攻撃でき、渡河設備は攻撃できない。拠点をHP0にしても制圧せず、陸上の制圧可能兵種が到着した後に所有が移る。
- 制圧効率は兵種ごとに編集できる。100%の部隊は標準時間、200%は半分の時間で進捗し、同じ陣営の部隊が複数いれば値を加算する。
- ヘリの制圧フラグを有効にして新規試合を開始した場合は、制圧条件を満たした時に所有が移る。攻撃対象から「拠点」を外した場合は、拠点を攻撃対象として選ばない。
- 既に始まっている試合は保存後も元のsnapshotを使い、設定変更は新規試合から適用される。

## 自動境界

未研究/港なし/queue満杯/資源不足のcommandがstate同一で拒否される。air直線とwater河川のroute、陸橋通行許可、速度差と再指示、target damage matrix/対空優先、移動中射撃、制圧資格、回復順序/上限、unit-loss ticket、JSON往復と固定tick replayを検査する。
