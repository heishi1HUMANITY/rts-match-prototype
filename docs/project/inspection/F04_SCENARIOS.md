# F04 / Issue #16 画面検査

対象: 橋・索道の建設、停止と再開、通行、奪取、解体。F04設計値はF16調整前の暫定値。

## 検査シナリオ

起動後、上部の「検査設定」を開き、シナリオで「検査：橋の建設」を選んで「適用してリセット」を押す。seed 42を使う。通常設定はNPC B/Cが動き、予定地と敵設備の一部は視界外になる。

1. 「開始」し、下の部隊カードでA-01強襲を選ぶ。「渡河」を開く。CROSS-RING-Nに「未建設」、費用60、建設18.0秒と表示され、隣接中の「建設」が有効であることを確認する。
2. 「建設」を押す。補給が60減り、盤面ラベルに「A建設中」、パネルに進捗が表示されることを確認する。建設ボタンを繰り返し押しても費用が二度引かれない。
3. A-01を予定地から離し、建設tickが増えないことを確認する。A-01を予定地へ戻し、合計180 tickで完成することを確認する。完成設備はA所有・HP180/180で表示される。
4. 完成後、A-01を橋の片岸から反対岸へドラッグする。経路が橋上を通り、移動が完了する。
5. 斥候で索道Iのセルを通れること、強襲では通行できず経路が拒否されることを確認する。索道II/橋II/橋IIIは必要な研究が未完了の間、建設できず理由が表示される。
6. 敵部隊を自軍橋の視界内へ移動させ、交戦で耐久を0にする。設備が攻撃陣営へ移り、耐久30%で再稼働し、所有者に応じて通行権が変わることを確認する。複数陣営の同tick同率最大攻撃では中立になる。
7. 所有者の強襲を橋端点へ隣接させ、「解体」を開始する。解体中は通行でき、完了すると未建設に戻る。被弾後10 tickが経つと、所有設備の耐久が毎tick回復する。
8. NPC B/Cの部隊が予定地へ移動し、共通の建設commandで着工することを確認する。敵設備の情報が視界外では最後に観測した状態のままになり、現在HPや作業状態が先読みされない。

## 画面サイズと範囲

PCと横持ち900×420で操作する。地図、渡河パネル、部隊カード、無効理由が同時に読めることを確認する。タッチでは部隊のドラッグ、HUDボタン、盤面操作の誤発火がないことを確認する。

HUD・盤面ラベル・シナリオ切替・開始・建設命令はChromeのローカルブラウザで確認済み。横持ち900×420、タッチ操作、建設完了後の実移動、戦闘による奪取、解体、NPC建設、画面外記憶の手動確認はユーザー検査に残す。自動テストは地形アンカー、橋/索道の通行権、建設費、停止/再開、NPCの自軍工事再開、schema/replay契約を検査する。
