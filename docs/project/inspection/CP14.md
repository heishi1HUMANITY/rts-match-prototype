# CP14: プレイ検査票

## 通常設定で1試合

#90〜#93がマージされ自動検証が通ってから、まとめて通常1試合プレイする。別マップ・傾向の必要な追加確認もこのCPにまとめ、全機能を1試合で検証済みとは扱わない。
対象のマージ途中で自動生成された票は準備中。まとまりの対象が揃うまでプレイ確認を依頼しない。結果は確認3点ごとにOK / NGと対象Issueを記録する。

## 確認3点

1. 研究・戦力・逆転・試合時間がつながり、操作の巧さに頼らず配置と研究で判断できる（#90）。
2. 開始地点と陣営傾向から道筋を選べ、2枚の地形で違う拡張や戦い方が成立する（#91/#92）。
3. PC/900×420で開始・研究・2戦線・結果・再戦を説明役なしに操作できる（#93）。

## 既知の未検証

マージ済みとプレイ検証済みは別。未使用の専攻・開始地点・傾向・端末と、持ち越し機能は実際に確認した範囲だけ合格にする。自動検証の成功やCPの工程終了からプレイ合格を推定しない。
