# F06 / Issue #18 現地勢力の実装契約

2026-10-12時点のmain `609b9ae`（F03/F04/F05/F17反映済み）を基点とする。F08の新兵種とF16の時間/再建再調整は未実装のため、現行の陸上強襲/偵察、通行、戦闘、制圧、5分標準試合を使って動く区切りを作る。最終調整はF16へ残す。

## 体験と暫定判断

- 現地勢力はA/B/Cの順位参加者ではない独立combatantとする。A/B/Cの`FactionId`、チケット、NPC操作権、勝敗順位を拡張しない。
- 5分の現行標準試合で接敵・奪還・討伐を試せる時間を確保するため、本拠と初期守備は30秒（300 tick）に出現し、同時に初期陸上部隊を配置する。これは旧2分出現を5分試合へ移すための暫定値で、ユーザー確認対象とする。
- 初期本拠は公開地形上の中央島に置き、中央の既存大拠点配置と重ねない。初期所有地は本拠を含めて明示し、チケット圧力には加えない。兵力が中央島から出る移動は通常の陸上通行と、実際に有効な渡河設備を使う。
- 現地勢力は橋の建築・所有をしないため、現在有効な完成済み渡河設備は兵種の通行許可に従って使える。A/B/Cが知っている渡河設備だけを使う既存経路情報の規則は変えない。
- 旧「視界なし」「地形無視」「無償生産」は採用しない。通常の視界・地形・通行・同時戦闘を適用する。生産はF06用の決定的スケジュール/上限を持ち、NPC固有値としてRulesMasterに保存し、A/B/Cの生産費用や命令を変更しない。
- F08の攻撃ヘリ等を先取りせず、現行の強襲/偵察のみを初期ロスターに使う。強襲=前線、偵察=視界・制圧を担い、capability照会を通す。

## 状態と所有境界

- MatchStateへJSON化可能な`LocalFactionState`を追加する。出現/壊滅、本拠ID、予定出現tick、次回spawn tick、roster index、成長段階、部隊上限、初期/現所有地の追跡に必要な値を全て保存し、wall-clockや暗黙カウンターを使わない。
- 部隊/拠点の所属は`CombatantId = FactionId | 'local'`、操作actorとランキングは引き続き`FactionId`とする。通常コマンドからlocalを操作できず、local部隊は共通移動・攻撃・制圧・被害計算の対象としてだけ参加する。
- 収入、チケット、脱落、陣営平均、選択/command actor、NPC B/C方針の各集計はA/B/Cのみ。local部隊の撃破で失うticketは、既存規則に従い攻撃されたA/B/Cだけに適用する。
- 本拠HP、初期陸上部隊、成長/生産間隔/上限、奪還報酬、本拠討伐報酬はRulesMasterの`localFaction`項目で管理する。値は単位・上限・理由を付けて検証し、新規試合のsnapshotに固定する。
- 現行の`localFaction`設定はマスタ管理画面で個別に編集でき、部隊成長は既存のHP・攻撃力計算に反映する。F06では既定の強さを変更しない。兵種別の現地勢力専用性能、編成やAIの強さ調整・比較検証は[F19 / Issue #42](https://github.com/heishi1HUMANITY/rts-match-prototype/issues/42)で拡張する。

## 戦闘・侵攻・制圧

- localの自律判断はMatchStateのみから決定的に生成する。視界内の敵が自軍拠点を攻撃中なら救援を優先し、次に自軍へ接近する敵、最後に通常通行で到達可能な最寄りの非local拠点を選ぶ。対象は距離/id順で固定する。
- local部隊のdamageは通常の同一tick snapshotで集計する。localは他陣営に敵対し、守備/拠点/部隊への有効攻撃と、現行capabilityで許された制圧を使う。施設・渡河設備の攻撃/建築は初期対象外。
- local所有の前哨地も通常どおり部隊・拠点から攻撃され、破壊後に中立守備が適用される。A/B/Cが通常制圧を終えて奪還したとき、一回だけ研究充填式と供給へ奪還報酬を加える。
- 本拠が0HPになったtickにlocalを壊滅扱いとし、local部隊を取り除き、local所有の通常拠点を中立化してF05守備設定に従う。本拠討伐報酬は同時与ダメージをA/B/C別に集計し、単独最大の陣営だけに一回付与する。同率最大は報酬なしとし、配列順に左右されない。

## 視界・UI・検査

- FactionViewの公開概況は生存/壊滅、可視の本拠HP、可視のlocal部隊数/位置/HPに限定する。未観測の現在位置、HP、生産、AIの標的を出さない。拠点ownerは可視/記憶/所有の既存契約で扱う。
- local本拠と部隊にはA/B/Cと区別できる中立系の灰緑色と記号/「現地」ラベルを併記する。選択や命令UIには混ぜず、通常の拠点操作でlocal所有地へ攻撃・奪還する。
- 通常シードではlocalが必ず出現する。短時間fixtureでは本拠/初期部隊を開始時に配置し、救援・侵攻・奪還・討伐をNPC B/C停止で短く試せる。通常設定とfixtureをHUDで区別する。
- 検証: localの順位/ticket非参加、視界情報境界、同時被害とkill credit、spawn上限/次回tick保持、奪還/討伐報酬の重複防止、壊滅時の拠点中立化と守備再配置、JSON/replay一致、pause/reset/restart。
- MatchState schema 12 / rules `f06-v1`、RulesMaster schema 6へ更新し、旧schema診断の暗黙replayは拒否する。
