# F19 制圧後HP率の設定契約

Issue #40。制圧後の再稼働HPは `capture.restoredHpPercent` を用い、Lv1最大HP×百分率を切り捨て、最低1HPにする。整数1〜100、標準30。既存30%の丸めを維持し、F10の強化/所有喪失と守備復活は変更しない。

RulesMaster schema12へ移行し、schema11以前の保存済み設定を保持して不足フィールドだけ30で補う。進行中snapshotは保存操作で変えず、新規試合へ適用する。状態JSON形状はschema17を維持、rulesVersionはf19-v1。旧AI/旧ルール診断は拒否する。

`f19-capture`は中立の小/中/大拠点へAの部隊を配置する自動検査fixture。対戦NPC/現地勢力を停止し、標準の制圧処理を使う。通常設定の初期配置やバランスは変えない。HQは制圧対象外。

F19-01/02はcapture-hp.spec.tsで30/50%・3規模の実制圧結果を診断で判定する。回復による差を混ぜないよう検査マスタの回復待ちだけ10000tickへ延ばす。F19-03は入力/JSONの拒否と保存値/snapshot不変、F19-04は再読込/新規試合/別draft保存後の旧snapshot/replay一致を検証する。境界101HP×30%=30、最低1はユニットテスト。
