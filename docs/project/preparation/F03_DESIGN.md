# F03 / Issue #15 地形・拠点設計

2026-10-12時点のmain（PR #34、schema 7 / rules f17-v1）から開始する実装契約。F04の橋・索道、F08の航空/水上兵種、F16の最終時間/再建判断は未実装であり、本設計はそれらを先取りしない。

## 体験と依存の扱い

- 対戦人数・陣営はA/B/Cの3陣営、盤面は40×40、4方向セル移動を維持する。既存の標準5分はG3の暫定時間として今回は変えず、F16で再評価する。
- 初期陸上部隊から自陣首都・自陣小拠点・自陣港まで、川や山を越えずに到達できる。中央島と中立中規模拠点への陸上アクセスはF04で渡河設備を完成するまで閉じ、盤面・previewで渡河予定地と到達不能を示す。
- 地形、港、渡河予定地、拠点の種類/位置は全陣営に公開する。所有・HP・制圧状態は既存FactionViewの可視性契約に従う。
- 未観測拠点の所有・HPラベルは出さず、公開済みの規模別マーカーとミニマップで種類/位置を示す。視界マスクは地形の読み取りを妨げない濃さにする。
- 移動照会は陣営、領域（land/air/water）、現在有効な渡河の所有者を受け取れる純粋関数にする。現行のunitは全てland。air/waterは後続F08で接続し、F03だけで兵種を追加しない。

## 決定的な盤面生成

- `GridMap`に各セルの地形IDと川/山の等級を保存し、マップ全体をJSON往復可能にする。旧`blocked`配列は互換用の派生ミラーとして保持し、通常の陸上障害判定は共通通行照会へ集約する。
- seed付きの決定的な幾何生成で、川は中心島を囲う環状1級川と3陣営間の放射状2/3級川、山は環の外側に置く。主要地形と港は3方向に配置し、ランダム障害物を含む各seedで配置の通行性と自陣初期資源までの経路長を検証する。
- 渡河予定地は川岸の対向する陸セルのペア。F04が同じ安定ID/端点を参照する。F03では予定地自体を渡河可能にはしない。
- 建物/部隊/地形の重複配置を拒否し、スポーン近傍、自陣首都、自陣小拠点、自陣港への陸上経路を必ず確保する。中央島の陸地は通常の陸上グラフから孤立してよい。
- 自陣資源は各陣営に対し1拠点ずつ置き、初期部隊からの最短陸路を全seedで同じ長さに保つ。中規模拠点は放射状の境界近くに置き、中央島には大規模拠点を置く。拠点値はF17 RulesMasterへ保存し、simulation/economy/view/visibility/ticketsへ接続する。

## 暫定調整値

- 既存値はsmall/outpost=HP100、補給2/秒、研究1/秒、ticket重み1を維持する。
- mediumはHP180、補給3/秒、研究1.5/秒、ticket重み2。largeはHP300、補給4/秒、研究2/秒、ticket重み3。各値はF17 master編集可能で、正式バランスではなくF03の初期値。
- HQの既存値は変更しない。捕獲時間/半径はF17共通設定を使い、拠点サイズごとの特例を設けない。

## 通行照会

- `canTraverse(map, cell, {factionId, domain, crossings})`をland/air/waterで共有する。landは平地/岸のみ、airは盤内全域、水は川のみを通る。山と川はlandを遮る。
- crossingは両端cell・種別・所有陣営を持つ。建設中/破壊済みは通行不可。F03の予定地に構造物がないときは全陣営通行不可。
- 既存`findPath`と全ての移動/追跡/AI/previewは現在の陸上通行照会へ委譲する。将来領域への契約引数を設けるが、利用兵種の導入はF08で行う。
- 経路拒否は`BLOCKED`を維持し、UIは地形/領域から「川・山・渡河設備が必要」を解決して表示する。

## 検証と画面

- 複数seedで同一seed再現、主要地形の三方向配置、同陣営のセル重複なし、全配置の盤内/地形適合、自陣経路、港と川の接続、渡河前後のアクセス差を検査する。対称性を崩す既存のG1孤立セルfixtureは通常地形から除き、障害境界のユニットテストへ移す。
- 各陣営の自陣資源・首都/港までの距離、中立拠点までの最短距離を複数seedで比較する。海路/空路と完成橋を仮定した将来アクセスを通行照会テストで確認する。
- Three.js盤面では草地、川岸/川、山を色・形で区別し、港と渡河予定地には記号ラベルを付ける。地形は公開情報で常時表示する。
- HUDに盤面全体が見える簡易ミニマップを加え、地形/港/渡河予定/公開拠点と可視部隊を更新する。PCと900×420で確認する。
- 短時間fixtureを通常設定と区別し、最低限「自陣拠点へ移動」「川越しの指示を拒否して理由表示」「中央渡河予定地と港を見分ける」を画面検査する。

## 状態・診断

地形/拠点スキーマが変わるためMatchStateをschema 8、rulesを`f03-v1`へ上げる。過去schemaの診断は暗黙に読み込まず、診断snapshotのRulesMaster content IDと完全snapshot検証を維持する。
