# F11 防御施設

Issue #23 / CP1 / gate:play。必要研究を完了した陣営が所有する稼働拠点・完成渡河をアンカーとして施設を建てる。位置は公開地形と自軍施設だけから固定順に決定し、敵の不可視占有で拒否結果を変えない。施設は移動を塞がない。

- 5種: 砲座（陸/水）、対空陣地（空）、地雷原（陸への一度の攻撃）、観測塔（視界）、妨害塔（敵視界低下と自軍隠密）。陣営6基、アンカー2枠。種類の重複・研究不足・費用不足・強化中拠点・未完成/解体中渡河・禁止地形を拒否しstateを保持する。
- commandは`build-facility {kind,anchor:{kind:'base'|'crossing',id}}`。支払は成功時1回。完成tickから効果を適用。建築中も枠とHPを持ち攻撃可能（敵地雷は常に非公開）。アンカー喪失・破壊で除去、返金なし。採番は陣営の単調job serialを共有する。
- 暫定の費用/秒/HP: 砲座150/30/300、対空150/30/250、地雷100/20/1、観測120/25/200、妨害180/35/220。砲座射程3・陸25/水20、対空射程4・空50、地雷射程1・陸120、観測視界10、妨害半径7。すべてmaster編集可能、最終バランスは#28で調整する。
- 戦闘は同じ攻撃前stateから同時集計。通常部隊はfacilityを標的にできる。現地勢力の施設攻撃は従来対象仕様を保持する。地雷は移動後の範囲内陸部隊から距離/IDで一つ選び除去。妨害は完成した敵塔の範囲内視界源を半減、重複は乗算、自軍隠密は最低視認半径を保持する。敵妨害下の観測塔は視界を失う。
- viewは所有/可視/記憶だけを公開、敵地雷は記憶にも載せず、妨害警告は自軍に発生した事実のみ表示する。不可視の妨害源位置を渡さない。
- 研究効果`facility-unlock`（facilityKind指定）と`facility-build-speed-percent`を登録。標準5解放と建築速度+100%研究を追加する。任意IDの登録効果から人間/NPC共通に判定する。NPCは既存経済判断枠のfallbackで補給を残し最大2基、既存判断周期/命令上限を維持する。
- state schema18/master13/f11-v1。schema12以前の既存値・任意研究・削除済み研究を保持し、新施設定義/新施設研究だけ補う。旧state診断は拒否、新版は完全snapshotで再現する。

通常対戦は研究→「施設」→所有アンカー→施設種を選ぶ。短時間`f11-facilities`は高補給・施設解放済み・NPC停止で、通常のcommand/建築/戦闘処理を使う。検証は[F11_SCENARIOS](../inspection/F11_SCENARIOS.md)、施設/戦闘/視界/移行unit、`e2e/facilities.spec.ts`。CP1では通常1試合の操作・表示をユーザーが確認する。
