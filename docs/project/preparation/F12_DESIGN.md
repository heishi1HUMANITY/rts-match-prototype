# F12 補給線

## 接続判定

- 生存し元の陣営が所有する首都セルから、4近傍の陸地を探索する。移動部隊の経路・空路/水路は使わない。
- 所有・完成・HPが正の橋/索道だけが、予定地の陸岸間を接続する。工事中、解体済み、奪取済み、破壊済みは通行辺にならない。
- 各tickの現在状態からpureに再計算し、基底状態へcacheしない。制圧、首都/渡河点の喪失、所有変更を次の定義tickから反映し、診断replayと同じ結果にする。
- 人間/B/Cは同じ`RulesMaster`と接続判定を使う。NPCはFactionViewが返す自軍の接続集合と公開地形/観測渡河点だけを使う。敵資源・未観測渡河状態を公開しない。

## 暫定機能低下

切断された所有拠点は補給収入50%、拠点と渡河点の自然回復0%、拠点砲座と付属施設攻撃50%。研究収入、部隊攻撃、所有/制圧、守備、観測塔・妨害塔の非攻撃効果は変えない。接続した次の定義tickから標準値へ戻す。各係数はF17のマスタ画面で0〜100%に調整できる。

値はF12実装の初期提案であり、最終バランスとして承認済みとは扱わない。時間/強さの調整は後続#28で行う。

## UIとNPC

- 自軍の所有拠点に「首都と接続/切断」と実際の補給収入を表示する。切断理由は未接続の自軍陸路/渡河網と説明する。
- 自軍の渡河設備には接続状態を表示する。他陣営の現在接続状態は開示しない。
- NPCは可視の候補渡河点を建設する際、接続を回復する所有拠点数を優先し、次に移動距離で決める。

## 互換性

接続集合は保存せず、MatchStateと公開地形から導出する。新規パラメータのみmaster schema14へ追加し、旧版の保存設定には標準値を補完する。ルール版はf12-v1。現在進行中のstateはルールsnapshotを維持する。
