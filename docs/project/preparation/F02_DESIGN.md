# F02 対象への進軍・追跡

対象: Issue #14。ユーザー合格・マージ済みF01の集団操作を維持し、固定地点に加えて敵部隊・拠点のIDを目的として扱う。操作感の細かな調整は後続で検討する。

## 操作

自軍の選択済み部隊を可視の敵へドロップすると追跡、拠点へドロップするとその拠点へ進軍する。複数選択にも同じ操作を使う。ドラッグ中は対象名と部隊ごとの経路、命令後は自軍カードの矢印と選択欄の対象・状態を表示する。地面へのドロップ/タップは固定地点への移動へ戻し、停止は追跡を解除する。

敵のタップは敵を操作する選択にはならない。拠点のタップは従来の情報表示を維持する。HUD、盤外、Esc、二本指、試合終了、リセットによる取消を維持する。

## ルール

- `march` commandは部隊IDと `{kind:'unit'|'base',id}` を取る。所有権、試合状態、形式、初期経路を共通検証する。不可視敵と存在しない敵は同じ拒否理由で返す。自軍部隊を追跡対象にしない。
- 各tickの移動前に同じsnapshotから対象の観測と経路を更新する。半セル移動中の辺は完了させ、セル中心で次の経路へ接続する。
- 可視の敵は現在の位置から目的セルを求め、未来の経路・目的地を参照しない。射程に入ると停止して交戦する。可視で射程内の指定対象を優先し、対象に撃てないときは既存の自動交戦を使う。
- 敵を見失うと最終確認セルへ進み、そこで保留する。再び見えれば追跡を再開する。視界外の移動・撃破・現在座標を命令状態や表示に反映しない。戦闘時点で見えた撃破のみ追跡を解除する。
- 拠点の位置は公開情報なので未観測でも進軍先にできる。所有・HPは観測できたときだけ判断する。敵拠点には攻撃、中立拠点には制圧、自軍拠点・破壊済み首都には到着して待機する。敵前哨拠点の破壊後は既存ルールに従って制圧へ進む。
- 経路がなくなった場合は次のセル中心で停止して保留する。新規命令の到達不能は元の命令を壊さず拒否する。集団指示の一部拒否は他部隊へ影響させない。

初期の到達判定は目的セルへの経路を要求する。射程内でも別の連結領域にある対象は進軍を拒否する。射撃可能位置の探索は今回追加せず、既存の自動交戦は維持する。

## 状態と責務

`UnitState.marchOrder`に対象、最終確認セル・tick、状態（tracking/searching/blocked/arrived）を保持する。通常の固定地点移動はnull。生成・生産はnullで初期化する。

simulationが対象検証・追跡・戦闘・解除を担い、runtimeが単体/集団命令・純粋preview・履歴を扱う。AIも陣営別FactionViewから同じmarch commandを出し、同じ指定を毎秒上書きしない。render/UIには自軍の命令状態と現在可視の敵だけを渡す。

永続的な命令状態と新commandを追加するためschema6/rules f02-v1へ更新する。旧schema/rules診断の読込は提供せず、不一致は拒否する。同じseed/scenario/履歴/tickでNPC判断も再生成する。

## 検証

移動対象の経路更新、射程、半セル、撃破、視界喪失/再発見、不可視状態の非干渉、拠点の所有変更/破壊/制圧、到達不能、地面/停止による解除、複数指示の部分受理、AIと診断replayを自動テストする。通常設定と追跡用fixtureを区別し、[画面確認手順](../inspection/F02_SCENARIOS.md)を用意する。

今回含まないもの: 隊形、ユニット同士の衝突回避、建築、マスタ管理、完成版の3D表現。F17のマスタ管理を次の基盤タスクとして残す。
