# F10 拠点強化・回復・砲座

2026-10-12の実装契約。旧仕様3.12の値は試合内に変換した暫定値で、F16で再調整する。

## 強化データと研究

- 全拠点はLv1で開始。Lv2は「拠点整備」、Lv3は「要塞化」の完了を必要とし、研究効果 `base-upgrade-max` が解放上限を表す。
- 費用・所要時間は `RulesMaster.baseUpgrades.kinds` で拠点規模/対象レベル別に編集可能。補給支払いは開始時に一度だけ行い、同じ拠点の並行強化を拒否する。
- 所有権、稼働HP、首都の元所有者、必要研究、次レベル、残高を同じ `upgrade-base` command で検証する。B/Cもこのcommandを通す。
- 旧表の補給費/秒を現行centi値/tickへ換算する。時間は0.1秒固定tick。Level2/3の最大HP・補給/研究収入倍率・砲座値もすべて保存masterに含める。

## Tick契約

- tick順は交戦→制圧→強化進捗/完成と拠点回復→経済。完成tickの制圧成功・破壊・所有喪失が先に処理され、失った拠点の強化は完了しない。
- 強化完了時はHP比率を保って最大HPを更新する。制圧・中立化はLv1の最大HPへ戻し、制圧後HPはLv1最大HPの30%。未完了の強化ジョブは消去し、返金しない。
- 所有中で稼働している拠点は、最後の被弾から規定tickを過ぎると毎tick回復する。回復量と停止時間はマスタ編集可能。
- Lv2以上の砲座は固定間隔で、射程内の最も近い敵部隊1体を同時攻撃snapshotから撃つ。同距離は部隊ID順。航空部隊へのdamageは半分（端数切り上げ）。中立拠点・構造物は撃たない。

## 暫定値

| 拠点   | Lv2 補給/時間 | Lv3 補給/時間 |      HP倍率 | 補給・研究倍率 | 砲座damage/射撃 |
| ------ | ------------: | ------------: | ----------: | -------------: | --------------: |
| 首都   |    600 / 60秒 |   1200 / 90秒 | 130% / 160% |    125% / 150% |         25 / 50 |
| 小拠点 |    300 / 45秒 |    600 / 75秒 | 130% / 160% |    130% / 160% |         12 / 25 |
| 中拠点 |    500 / 60秒 |   1000 / 90秒 | 130% / 160% |    130% / 160% |         20 / 40 |
| 大拠点 |    800 / 60秒 |   1600 / 90秒 | 130% / 160% |    130% / 160% |         30 / 60 |

旧モデルの砲座距離は現行40×40セルへそのまま移植できないため、初期射程を6セルとしている。射撃間隔は10tick。回復は1HP/tick、被弾後10tick停止。

## 検査シナリオ

`f10-base-upgrades` はAの研究2種完了・十分な補給・自軍所有のLv1小拠点を用意し、対戦NPCと現地勢力を停止する。通常試合におけるB/C投資は別途検証する。

1. 拠点パネルでLv1、HP、収入を確認し、Lv2へ強化する。
2. 所要時間後にLv2、最大HP、収入倍率を確認する。
3. Lv2砲座の射撃とLv3強化を確認し、同じ拠点の二重開始が拒否されることを確認する。
4. 拠点を攻撃して回復が止まり、被弾停止時間後に回復することを確認する。
5. 強化拠点を制圧してLv1へ戻り、強化中の制圧ではジョブが失われることを確認する。

マスタ項目の調整と診断replayはF17の保存snapshot契約を使用する。通常試合のNPC行動・全体バランス、および実タッチ端末の操作感は検査版のユーザー確認が必要。
