# 拠点・守備・施設

## 採用仕様（2026-10-16・一部未実装）

- 領土はチケット倍率・部隊上限・足場へ作用する。拠点種別・強化の補給/研究収入効果を耐久・視界・上限寄与・足場機能へ置き換える。定額収入と逆転不変条件の正本は[補給・生産・研究](ECONOMY.md)とする。
- 自陣HQに基礎上限の部隊を駐留させた防衛を計算し、駐留可能数・砲座・耐久・回復等の具体値と代表攻撃条件を定める。現在の駐留枠や強化効果のままで防衛条件を満たしたとは扱わない。
- #87の兵站stage4専攻は所有する非HQ拠点を前線生産地点として共通キューへ接続し、その拠点から半径3以内にいる停止部隊を、攻撃・被弾の両方から50tick静穏後に最大HPの2%/秒回復する。専攻なしは従来どおりHQ/港キューのみ。
- #87の工兵stage4専攻は敵地雷への通常発見半径を地上部隊2・偵察4セルにし、工兵所有地雷は1/2セルへ縮小する。発見地雷は120damage後に速度50%で40tick減速する。通常の視界や全域観測は地雷を公開しない。隠密・自由渡河は未実装。

採否の根拠は[決定記録](../DECISIONS.md)と[Issue #79](https://github.com/heishi1HUMANITY/rts-match-prototype/issues/79)。この節は採用された変更と未確定の範囲を示す。以下は現在のコードの動作であり、上記の変更が実装済み・検証済みという意味ではない。

## 現行実装

### 中立守備と制圧

- 中立守備は拠点に紐づくHPプールで、順位に参加する陣営ではない。守備が残る間は拠点本体を守る。守備撃破後に本体HP0とし、非首都の中立拠点を制圧する。
- 半径内の生存部隊から `canCaptureBase` と効率を集計する。同一陣営の効率を加算し、`requiredTicks × 100` 到達で所有を変更する。
- 他陣営が半径内にいる間は進捗を保留。制圧可能部隊がいなくなると進捗を解除、単独候補が変わると新候補の効率から開始する。首都は制圧対象外。
- 制圧時はLv1へ戻し、`capture.restoredHpPercent` で最大HPに対する再稼働HPを設定する（切捨て、最低1）。強化途中のjobは破棄する。
- 守備復活が有効なら、撃破後に制圧可能部隊がいない連続tickが規模別 `respawnTicks` に達すると守備と拠点HPを全回復。無効でも初期守備は存在する。
- 所有拠点の破壊による再中立化時は設定に従い守備を再配置する。陣営脱落時の中立化は別処理で、現行実装は守備を配置する。詳細は [試合進行・決着](MATCH.md)。

### 拠点強化

- 自所有の稼働拠点をLv1→2→3へ強化する。対応研究、補給、同拠点のjobなしを確認し、開始時に支払う。
- 固定tickで完成し最大HP変更時にHP比を維持する。レベルごとのHP/補給・研究収入倍率と砲座性能を適用。所有喪失でLv1へ戻し、途中jobを返金せず破棄する。
- 砲座は範囲内の敵へ決定的に射撃し、航空対象へのdamageを半減・切上げ。拠点自身は被弾後の待ち時間を経て自動回復する。

### 防御施設

- `turret`、`antiAir`、`mine`、`watchtower`、`jammer`。自拠点または完成済み自渡河設備をanchorに、研究・補給・枠・陣営上限を確認して建築する。拠点強化中や渡河工事中は拒否する。
- 配置は公開地形と固定候補順で決まり、不可視の敵占有を受付可否へ使わない。建設中は効果なし。工兵研究で工期を短縮する。
- 砲塔/対空施設は射撃、地雷は一度だけ起動、監視塔は視界拡大、妨害施設は敵視界を縮小し味方部隊を隠しやすくする。重複妨害は倍率を乗算。妨害範囲内の敵監視塔の視界源を無効化する。#87工兵専攻は地雷探知と地雷被害を追加するが、妨害施設の方式・重ねがけは変更しない。
- HP0、anchor喪失、所有陣営脱落で施設を除去する。地雷は敵viewで常時公開せず、探知半径内の自部隊がいる間だけ現在位置を表示する。現地勢力部隊は現在施設を攻撃対象としない。
