# 兵種・戦闘・回復

## 採用仕様（2026-10-16・未実装）

- 戦力は配置・研究・相性・増援・防衛をモデル化して計算する。平地の静的火力比較だけで専攻の価値や非対称地形の公平性を決めない。公開情報による判断と実戦闘ルールは人間/NPCで共通にする。
- HQ駐留と上限の逆転不変条件は[補給・生産・研究](ECONOMY.md)、地上/航空/水上の経路評価は[地形・渡河設備](WORLD.md)に従う。駐留上限・防衛能力の現行値を新条件の合格値とは扱わない。
- #85: 攻撃ヘリが1機以上いる間、移動/展開を問わず対空車両だけを識別するAA専用視界を設ける。通常の視界マスク・非AAの位置情報は増やさず、最後に観測した対空位置と射程を保持し、初発見で通知する。通知ボタンでカメラを移動する。
- #85: 通常30tick、妨害中10tickの初発見猶予を、対空射程・相対移動速度・斜め移動・視界研究から認知半径として計算する。最速通常/研究条件の対空横断でも初発見から初被害までを固定tickで検査する。移動対空は射程50%/対空火力25%、20tick停止で展開完了して通常値へ戻る。数値は試作中の調整値で、CP13プレイ未検証。
- #85: 攻撃ヘリに最大8か所の経由地を設定できる。NPCは自陣営が観測した対空記憶と交差する航空経路だけを迂回候補にする。
- #86: `specialization-power`完了済みの停止中自走砲が地点を指定する。発射時に観測済みなら準備10tick後に発射し着弾30tick後・散布半径0.5、未観測なら着弾50tick後・散布半径2。射程8、通常攻撃と周期80tickを共有し、初弾準備・待ちはF17マスタで調整する。観測状態/散布/着弾tickは発射時に固定し、移動/停止/命令切替で待ちを消さない。発射済み弾は射手の撃破後も着弾する。
- #86: 爆風半径1、兵器100/施設150ダメージ。着弾tickの全対象スナップショットから同時にダメージを集計し、複数弾の損害を合算、撃破ticket損失は対象ごとに一度だけ計上する。敵の予告は着弾地点が自軍視界内のときだけ位置/時刻を表示し、射手・未観測の着弾/損害/撃破結果を出さない。NPCも自軍viewで観測中の敵地上部隊/拠点/施設だけを狙う。
- #86: 妨害は既存の割合視界減衰と塔の乗算スタックを維持し、地点砲撃の観測判定へ発射時点の視界を使う。対空のF23最低猶予計算は#85の契約を維持する。作戦指令の砲撃と兵種の地点砲撃は別機能として扱う。
- 旧相談の移動速度・対空展開・ヘリ視界・地点砲撃の候補値は、確定値として採用しない。研究補正後の速度関係や猶予を新マップと実ルールで再計算する。
- 前線回復等の非火力専攻は後続検討で、具体値と併用条件は未確定。態勢・自動退避・練度を自動復活させない。

採否の根拠は[決定記録](../DECISIONS.md)と[Issue #79](https://github.com/heishi1HUMANITY/rts-match-prototype/issues/79)。CP13の数値と挙動は#85〜#89がマージされるまで通常試合で未検証。

## 現行実装

### 兵種

| ID         | 表示名   | 既定移動領域 | 主な特徴                             |
| ---------- | -------- | ------------ | ------------------------------------ |
| assault    | 強襲     | land         | 初期解放、制圧・渡河工事             |
| scout      | 斥候     | land         | 初期解放、索道通行、高視界           |
| artillery  | 自走砲   | land         | 研究解放、長射程、移動中攻撃不可     |
| antiAir    | 対空車両 | land         | 研究解放、航空対象優先               |
| helicopter | 攻撃ヘリ | air          | 研究解放、地形を無視、既定で制圧不可 |
| patrolBoat | 哨戒艇   | water        | 研究解放、港生産、既定で制圧不可     |

これは既定プロフィール。性能・領域・制圧・駐留・攻撃対象は試合へ適用された `rules.units` を読む。

### 戦闘

- HP、射程、視界、移動速度、領域別ダメージ、構造物ダメージ、損失チケットを兵種ごとに持つ。Entity集合 `attackTargets` と対象領域のdamageが両方許可する場合に攻撃できる。
- 部隊、守備、拠点、渡河設備、現地勢力本拠、施設を区別する。射程/視界/所有/対象制約で選び、距離・IDによる決定的な選択を行う。
- 共通攻撃プロフィールは `windupTicks`、`intervalTicks`、`canAttackWhileMoving`。構え・発射・待ちを固定tickで進め、同じsnapshotから被害を予約して同時解決する。配列順による先制撃破を与えない。
- 中立守備・駐留守備・首都保護・施設・作戦指令はそれぞれの対象条件を通す。対戦NPCも共通ルールを使う。
- 部隊が失われると兵種別チケット損失を反映する。補給0だけで部隊を自動消滅させない。

### 回復

生存する自首都からマンハッタン距離3以内、経路なし、当tickに被弾なしの部隊を10tickごとに最大HPの4%切上げ（最低1）、最大HPまで回復する。全領域共通。この距離・頻度・率は現在 `step.ts` 内の固定値で、マスタ編集対象ではない。自動退避命令や練度上昇は提供しない。

実装: [combat.ts](../../../src/simulation/combat.ts)、[unit-capabilities.ts](../../../src/simulation/unit-capabilities.ts)、[step.ts](../../../src/simulation/step.ts)。検証: [combat.test.ts](../../../src/simulation/combat.test.ts)、[unit-domains.test.ts](../../../src/simulation/unit-domains.test.ts)。関連: [拠点・守備・施設](BASES.md)、[作戦指令](TACTICS.md)。
