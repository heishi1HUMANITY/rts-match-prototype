# 補給・生産・研究

## 採用仕様（研究構造・費用は#81、定額経済・拠点/部隊上限は#82実装済み）

研究構造と費用は#81、定額経済・拠点/部隊上限は#82で実装済み。標準研究収入は12 centi/tick (1.2pt/s)、基礎補給収入は120 centi/tick (12pt/s) で、戦時経済専攻時は156 centi/tick。#87後の研究は全候補29、段4は6択から1つだけ取得できるため一試合の取得可能数は24。同一実行列は12,000tick中11,384tickで10/24件（41.67%）、専攻完成は6,731tick（56.09%）。CP11の532秒1試合を20分基準へ置換しない。

### 定額収入と領土の役割

- 研究・補給収入は所有拠点数に依存しない定額とする。旧「基本研究収入＋所有拠点ごとの加算」を置き換える。補給線研究は定額へ加算し、維持費軽減は部隊ごとに適用する。拠点数を通じた収入増加はない。
- 維持費・支払い・生産枠の共通検証を維持する。領土が効くのはチケット倍率・部隊上限・足場（生産位置・駐留・視界・渡河）のみ。拠点種別・強化の収入効果は耐久・視界・上限寄与・足場機能へ置き換える。代替効果の具体値は未確定。
- 標準上限は `baseUnits=5`, `maxUnits=9`, `unitsPerOwnedBase=1`。`2 × baseUnits > maxUnits` をルール検証で保証する。HQ駐留上限を5、HQ Lv3砲座ダメージを120、射程を6にする。砲兵射程5なのでHQ砲座の射程内に入る。実ルール戦闘ハーネスは双方に専攻を除く同じ8研究（開発1/2、砲兵、対空、航空、火力1〜3）を完了させる。5/9の標準混成は140tickで攻撃側全滅・守備側1残・HQ全快、砲兵偏重は150tickで攻撃側全滅・守備1残・HQ全快、航空偏重は220tickで攻撃側全滅・守備側も全滅するがHQは1101/1920で生存する。HQ Lv3未達は180tickで破壊される。20分時系列では、標準初期補給から始め、4非HQ拠点（5/9上限に必要な最小数）を既に確保した時点を起点に、実コマンド/収入/研究/生産/HQ強化を進めるとtick9094に8研究・混成9部隊・HQ Lv3がそろう。領土確保時間は起点以前なので含まず、専攻は未取得。NPC/ユーザー公平性と実プレイの防衛成功は保証しない。
- 比較候補4/7も同じ非専攻8研究・攻撃編成比で計測する。砲座120では120tickで攻撃側全滅・HQ1907/1920、140ではHQ全快・攻撃側全滅、160ではさらに守備側1残。7上限を排除できる差は現時点で確認できず、標準5/9は既存値を維持する暫定選択であり、ユーザープレイ未検証/7案未採用とする。最大隊数での前線配分は9=`4+4+予備1`、7=`3+3+予備1`。ただしこれは2戦線分配の例で、HQに5駐留した防衛状態とは同時に成立しない。
- 標準100×100地形（seed0、A南西）の通常ルートで、AのHQから12セル先の敵側HOME-A（通常HP300、駐留守備1）を奪還する。HQ駐留の5 assaultが実コマンドで移動し、敵守備を倒し、拠点を破壊して制圧するまで159tick。開始チケット30,000centiから28,104が残る。同一stateから無行動でstepMatchした場合は1620tickでticket枯渇・敗北、奪還は約10.2倍速い。このケースは橋なしの南西通常陸路で、地形改変なし。別の最大圧力上限計算は360centi/10tick、30,000centiで833tickだが、実測シナリオと混同しない。
- 部隊生産はHQの直列キュー。assault 1体は12,000centi/200tick。4体分は48,000centi/800tick (80秒)、3体分は36,000centi/600tick (60秒)。#82の実sim再補充テストでは、前線喪失後・補給在庫0から残存5 assaultで4体を作り直すのに972tick (97.2秒)、残存4 assaultで3体を作るのに750tick (75秒)。`applyCommand`の生産受付・queue3上限、`stepMatch`の定額収入/維持費/生産進行を使用し、前線移動・研究解放・HQ強化待ちは含まない。
- 同じルールの代表編成を9=`5 assault+2 artillery+helicopter+antiAir` (維持費104centi/tick)、7=`4 assault+artillery+helicopter+antiAir` (維持費84centi/tick) とする。補給120centi/tickで完全編成時に残る値は16/36centi/tick。HQ Lv2/Lv3強化費用合計180,000centi/工期1,500tick。上記到達テストは最低4非HQ拠点を初期確保済みとして標準初期補給から始め、資源支払とqueueを実コマンドで検証する。開始から領土を確保する戦略時間、2戦線維持、実プレイは未検証。
- 防衛ハーネスで代表編成・同一研究・位置・継戦時間・終了理由を明示する。砲座120は#82の暫定バランス値。HQを全編成に対して永久無敵にする意味ではなく、HQ Lv3前は特に脆弱。領土喪失だけで既存部隊を削除しない。

### 研究の希少性

- 戦力・兵站・情報・工兵の4分野、段1〜4。段1〜3は排他なし。同分野の前段のいずれかを前提にするOR条件。段4候補は戦力1、兵站2、情報2、工兵1の計6つから全体で1つだけ取得する。
- 完了数に応じた必要量増加はマスタ係数4.5%/完了、必要量は基礎値×(1+完了数×係数)を切り上げる。stage1基礎は通常7,200 centi (火力1のみ9,600)、stage2は15,600、stage3は21,600、stage4は27,600。全候補29件のうち一試合で取得可能なのは24件。標準20分/開始時収入1.2pt/sで、火力1→2→3→戦力専攻→砲兵→対空→航空→海軍→補給線→整備の10件を完了する実tick計算は11,384tick (94.87%)、10/24=41.67%。専攻は6,731tick (56.09%)に完成する。
- 各研究の必要量は初めて正の充填が発生した時点の完了数で算定し、次ノード選択だけでは安値を予約しない。以後は別研究の完了や切替でもその研究の必要量を固定する。段1〜3は同分野の直前段のいずれかを前提とするOR条件、段4は全4分野から1専攻のみ。
- 比率分母は一試合で取得可能なノード数。排他stage4は選択した1候補だけを数え、残りのstage4候補は分母へ加えない。必要量は最初の正の寄与時に固定し、別研究完了後も既存進捗/確定量を保持する。
- 充填式、未指定バンク、研究別進捗保持、完了時の指定解除、次研究を自動選択しないことを維持する。専攻完成だけ全陣営へ通知し、その他の敵研究は非公開。
- 研究は使える兵種・進出先・戦い方・対抗手段を変える。stage4各分野の効果は現在実装済み効果から選ぶ。未実装の効果を登録だけして利用可能と扱わない。旧コスト80/160/280/450・研究収入3.3/秒は確定値ではない。

### 陣営傾向と生産位置

- 陣営傾向は最終成果物に必須。先にマスタへ枠を定義し全陣営を中立にする。中立地形の公平性と3開始地点の道筋を確認した後、道筋の初速を与える傾向を導入する。
- 傾向はA/B/C固定にしない。人間が選ぶかseedで割り当てるかは導入時の採否事項。帯域逸脱は地形でなく傾向値を直す。導入前提の地形評価は[地形・渡河設備](WORLD.md)を参照する。
- #87で前線展開（兵站stage4）は所有する非HQ拠点から陸上部隊を共通キューへ入れ、同拠点の近くで静穏50tick後に回復する。戦時経済は補給収入+30%、生産時間−20%。他の専攻候補は段4の選択肢として維持し、通常の生産場所・研究入力・自動補正を増やさない。

採否の根拠は[決定記録](../DECISIONS.md)と[Issue #79](https://github.com/heishi1HUMANITY/rts-match-prototype/issues/79)。この節は採用された変更と未確定の範囲を示す。研究構造/費用は#81、定額経済・上限・戦闘比較は#82で実装済み。最小4拠点を確保後の9部隊/HQ強化/8研究の20分到達性と、標準100南西の奪還はルール時系列で確認済み。開始から領土確保する戦略時間、3開始地点の形状、2戦線プレイ、実プレイは未検証。

## 現行実装

### 経済と生産

- 資源はCenti整数（100で1ポイント）。生存陣営へ定額の研究12centi/tickと補給120centi/tickを与え、部隊ごとの維持費を引く。補給は0未満にせず、赤字時に部隊を自動除去しない。拠点種類/強化による収入はない。基地強化は耐久・砲座火力/射程へ寄与する。
- 自首都で陸/空部隊、自港で水上部隊を生産する。研究解放、資源、キュー、部隊上限を同時に検証。生産予約時に費用と部隊枠を確保し、IDを予約する。
- 上限は `min(maxUnits, baseUnits + 稼働する自非首都拠点数 × unitsPerOwnedBase)`。標準は5/9/1。現存部隊＋予約数で新規受付を判定。領土を失っても既存部隊を削除せず、現存数が上限以上なら生産進行を止める。拠点は上限・駐留・視界・渡河足場を与える。
- 陣営ごとの直列キュー。tick開始時にactiveだったjobだけ進み、完成時は首都/港へ出現、次jobをactiveにする。取消は支払済み全額を返す。作戦「緊急増産」は [作戦指令](TACTICS.md)。

### 研究充填

- 選択対象へ既存バンクを直ちに充填し、その後の収入も必要量まで充填する。必要量到達で即完了し、余りはバンク。研究未指定なら全量バンク。
- 指定解除・切替でも研究ID別進捗を保持し、返金・移し替えはしない。同選択の再入力で二重消費しない。完了時は選択解除し、次研究を自動選択しない。
- 研究は戦力/兵站/情報/工兵の4分野。安定ID、段階、必要量、前提ID集合、対称排他ID集合、登録済み効果の集合を定義する。
- 完了済み、前提未達、完了済み研究との排他は拒否。効果はdamage、vision、補給収入、維持費軽減、渡河/兵種/拠点Lv/施設解放、施設工期短縮のみ。自由記述の任意コードを実行しない。
- 経済後に充填完了した効果は、そのtickの既に終わった戦闘へ遡及しない。pauseでは収入も研究も停止。resetでバンク・選択・進捗・完了を初期化。

### 研究定義編集

研究定義編集はマスタ上で研究IDの追加・削除・変更、前提/排他/登録済み効果の接続を提供する。重複・存在しない参照・循環・不正な効果等を検証し、不正な定義を試合へ適用しない。保存済み定義の変更は進行中試合へ反映しない。
