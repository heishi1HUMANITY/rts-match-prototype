# 対戦NPC・現地勢力

## 採用仕様（2026-10-16）

- NPCの道筋はseedだけで専攻を固定せず、開始地点の公開マップ特徴から選ぶ。公開地形・港距離を採点し、得点が近い候補からseedで選択する。同seed・同定義・同マスタで選択を再現する。
- 道筋はマスタ定義とし、各開始地点に候補を2つ以上用意する。地形に合う研究順で軍事研究を挟む。CP12ではcrossing-first/field-firstの2列を使い、解放研究を共通研究commandで進行する。
- 二段階で導入する。第1段は地形による道筋選択と難度。第2段は専攻完成の全陣営通知とHUDの首位・チケットから中盤の標的と研究順を変える。偵察・観測への対応は戦闘予測の情報境界が整った後に接続する。
- 標的は首位優先と隣接する弱い相手への機会攻撃を組み合わせ、人間を特別扱いしない。使用情報は公開マップ定義・自視界と記憶・全陣営通知・HUD公開情報のみ。未観測部隊・敵資源・非公開研究・命令を参照しない。
- CP13第2段は、公開ticket首位の変更と専攻通知を難度別遅延後に反映する。首位の75%以下のticketで自軍から12セル以内に新鮮な既知拠点がある相手を機会候補にし、同じ#88静止戦推定を最大90tick・1回/判断だけ使う。予測が利用不可/未決着/不利なら既定標的へ戻る。可視局所防衛は即時対応する。
- 専攻通知は適格研究の短い対抗順を次の研究選択に使い、進行中研究は中断しない。可視航空脅威は対空研究/生産、可視地雷はsurvey研究を優先する。既知拠点記憶は最後の観測から弱/標準/強=150/300/600tickで期限切れし、現在の隠れた状態で補完しない。
- 難度は能力値でなく判断の質と速さで制御する。判断間隔・命令数・通知反応遅延・次善手確率・標的切替猶予・偵察活用を、弱め/標準/強めのマスタプリセットにする。同じ費用・視界・command制約を守る。
- 標準で人間がやや勝ち越す目安40〜60%はプレイ検査で調整する。NPC同士の開始地点勝率から人間の勝率を推定しない。マップの公平性は[地形・渡河設備](WORLD.md)の条件で評価する。
- 現地勢力は標準無効、追加徘徊NPCなしを維持する。現地勢力の互換性・専用難度は後続保留で、主試合への有効化は別の採否が必要。

採否の根拠は[決定記録](../DECISIONS.md)と[Issue #79](https://github.com/heishi1HUMANITY/rts-match-prototype/issues/79)。この節は採用された変更と未確定の範囲を示す。

## CP12実装済み・プレイ未検証

- FactionViewに公開開始地点・開始点・地形・港だけを含め、各開始点周囲の地形から研究道筋を採点する。マスタの川/山係数・港近接・近似候補幅、seedで同条件を再現する。各開始点に異なる2研究列を登録し、軍事解放とその前提順を保証する。
- 弱/標準/強は判断間隔・命令枠・次善候補率・公開通知反応遅延・標的切替猶予・survey活用率を変える。資源・視界・能力・共通command検証は変えない。近距離の可視防衛は通知遅延を受けない。
- 自動試験は同seed再現、公開地形変更、非公開敵部隊の不変、研究解放列、難度命令枠まで。開始地点別の実試合勝率は#84の地図監査（[地形・渡河設備](WORLD.md)）で評価し、人間勝率はNPC対戦結果から自動推定しない。
- 可視敵の位置は盤面寸法で丸め、哨戒艇の待機水域は盤面中央から選ぶ（#84で40×40固定値の名残を修正。40×40では従来と同値）。
- 再現監査 `npx tsx scripts/audit-npc-policy.ts` は同じ100×100 seed 23を各難度1200tickまでruntimeで進める（終了なし）。B/Cの研究道筋は全難度でcrossing/field。弱/標準/強はsurvey提案0/2/2、補給生産10/11/13、march12/15/17、共通検証通過37/48/60（地図版6・上記修正後）。資源不足拒否0/0/2で、強の増加分を無料命令とは扱わない。これは短時間の命令履歴で、勝率/長時間の偵察・研究/生産・増援の有効性は未検証。

## CP13第2段実装・プレイ未検証

- NPC policy memoryは自陣営FactionStateへ保存し、公開ticket首位・通知とFactionView記憶だけを保持する。decision境界にB/Cを同じ命令前snapshotから計画し、両memoryを保存した後に共通commandを適用するためreplayで再現できる。
- 専攻別対抗は既存の適格研究から選び、完了済みIDを飛ばす。公開ID→優先列はpower→施設対空/survey-1、戦時経済→firepower/artillery/turret、前線展開→artillery/turret/firepower、全域観測→air-defense/watchtower/survey-2、封鎖→naval/bridge-3/ropeway-2、情報戦→air-defense/施設対空/artillery。可視航空と地雷の応答は現在viewだけから追加する。
- 機会候補の戦闘予測は1回/陣営/判断、master上限90tick。観測拠点の保持TTLは弱/標準/強で150/300/600tick。実試合勝率、CP13プレイ、ブラウザでのmaster値編集は未検証。

## 現行実装

### 対戦B/C

- 人間と同じ資源・視界・研究・生産・command検証を使う。選択方針は `ai`、ルールは `simulation`。不可視敵位置・敵資源・敵研究・敵キューを判断入力へ渡さない。
- `npc.decisionIntervalTicks` ごとにB/C両方を同じ命令適用前snapshotの陣営別viewから判断。`maxCommandsPerDecision` を上限に共通commandで実行する。
- 防衛、領土確保、研究、生産、建設、強化、駐留、作戦指令を判断する。検査scenarioではNPCを停止する場合がある。難度はマスタの判断間隔・命令数・戦略選択品質で変わり、兵種性能は変えない。

### 中立守備・現地勢力

- 中立守備は拠点の防衛HPプール。[拠点・守備・施設](BASES.md) を参照する。独立して生産・侵攻しない。
- 現地勢力は `local` combatant。本拠 `LOCAL-HQ`、初期拠点 `OUT-02`、部隊、補給、周期生産、侵攻を持つ。A/B/CのFactionId・順位・チケットには追加しない。
- 現在の標準マスタは `localFaction.enabled = false`。機能自体は存在し、有効時に指定tickで出現する。旧資料の「標準で30秒出現」をそのまま現行体験と扱わない。
- 追加部隊は専用補給を支払い、上限と周期を守る。視界を考慮して侵攻先を決め、完成済み渡河経路を兵種制約に従い利用する。成長率は出現後の経過分に応じた生成部隊の性能へ反映する。
- 現地勢力からの拠点奪還報酬は拠点ごとに一回、本拠討伐報酬も一回。同率討伐に報酬を与えない。
- 現地勢力の命令判断間隔はruntimeで10tick固定。マスタ画面で出現・生産・成長・報酬等を編集できる。現地勢力だけの兵種別性能と編成AIの編集は提供しない。
- 徘徊NPCの別出現ループはない。独立して移動・侵攻するNPCは、現在は上記の現地勢力のみ。
