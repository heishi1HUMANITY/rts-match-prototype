# 実装エージェントへの指示

親が記入して担当へ渡す。未記入のまま実装を開始しない。
内部タスクの担当はユーザー検査・外部Issue編集・マージを行わない。

- 対象: G** / T\_**
- 作業場所・ブランチ:
- 基点commit:
- 目的（利用者に見える結果）:
- 前提タスク・採用済みの型/API:
- 読むもの: AGENTS.md、SCOPE、ARCHITECTURE、DECISIONS、WORKFLOW、TASKSの対象行、関連mock
- 編集可能なファイル/ディレクトリ:
- 共有ファイルの担当と変更を依頼する相手:
- 対象外:
- 完了条件:
- 検証コマンド・再現シナリオ:
- 判断してよい事項 / 親へ戻す事項:
- 報告してほしい内容: 変更、実際の検証、未検証、仕様判断、変更ファイル、既知の問題

通常の実装判断は範囲内で進め、疑問だけを理由に停止しない。
契約変更や対象外ファイルの編集が必要な場合、親へ影響を報告して調整する。
旧コードやmockの疑似処理を正として移植しない。ユーザー合格を代行しない。
