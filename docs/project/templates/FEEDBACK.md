# 検査・修正記録 G** / R**

ユーザーは自由な文章で指示してよい。親が情報を補いIssueコメントへ記録する。
G内でR01、R02…を採番し、未解決の指摘を見失わないようにする。

- 指摘元: ユーザー / 技術検証 / レビュー
- 対象の検査回・commit:
- 関連する検査ID:
- 種別: 不具合 / 使い勝手 / 仕様変更
- 優先度: 検査不能・進行不能 / 完了条件を満たさない / 任意改善
- 操作・seed・画面サイズ:
- 実際の結果:
- 期待する結果・希望:
- ユーザーがまだ確認していない範囲:
- 対応方針・完了条件への影響:
- 修正commit:
- エージェントの再検証と影響範囲:
- ユーザーへ依頼する再検査:
- 状態: 未対応 / 対応中 / 再検査待ち / ユーザー確認済み / 合意して後続へ移動

受け取っていないユーザー確認を記入しない。任意改善を後続へ移す場合も、その扱いを明示する。
ゲート合格のコメントには対象G・検査回・commit・ユーザーの回答を記録する。
