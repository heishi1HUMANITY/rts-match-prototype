## 2026-10-11: 実装とユーザー検査の運用

- D011: ユーザー確認により、検査は内部タスクごとではなく「動く区切りごと」。G1〜G4の4区切りと18タスクへ分割する。
- D012: 各GのGitHub Issueを進捗の正とし、仕様・完了条件はTASKS、指示/検査/修正はWORKFLOWにまとめる。
- D013: 技術検証とユーザー合格を分離する。対象commitの明示合格後にマージし、変更した版は再検査する。
- D014: 各Gの必須操作UIと検査シナリオを同時に実装する。生産・研究UIや視界の契約を最終段階へ先送りしない。
