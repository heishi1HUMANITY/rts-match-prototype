# P0 アセット案 05: 攻撃ヘリ

状態: 形状検討案。ゲームへの反映前。

## 役割と形状

航空部隊で、地形を越えて移動できる一方、拠点を制圧できない。細い胴体と長いテールブームで、地上車両や哨戒艇と明確に分ける。

- 角面で構成した小型胴体と前面キャノピー
- 主ローター1基、テールローター1基、細いテールブーム
- 短い直線翼と一体感のある小型兵装ポッド
- 2本のスキッドを独立した支持構造として見せる
- 白・冷灰・濃灰の大きな幾何学迷彩、控えめな青と小さな橙色標
