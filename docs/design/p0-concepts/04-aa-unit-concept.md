# P0 アセット案 04: 対空車両

状態: 形状検討案。ゲームへの反映前。

## 役割と形状

陸上の対空部隊。偵察より幅広く重い六輪車体に、左右一対の角形ミサイルポッドと中央の薄型レーダーパネルを載せる。砲塔や円盤レーダーではなく、この3要素で識別させる。

- 幅広の装甲車体と左右3輪ずつの六輪構成
- 明確に分かれた左右一対の角形ミサイルポッド
- 短いマスト上の平たいレーダーパネル
- 白・冷灰・濃灰の大きな面、控えめな青の幾何学迷彩、小さな橙色標

## 既存モデルとの整合

形状案は [revision-04 の兵器案](../p0-approved/revision-04/02-angular-unit-designs.png) の対空車両を基準にした。現行の `packages/client/src/game/models.ts` は履帯と縦置きランチャー4本の試作形状。ゲームへ反映する段階で、今回の車輪・ポッド・薄型レーダー案と揃える必要がある。
