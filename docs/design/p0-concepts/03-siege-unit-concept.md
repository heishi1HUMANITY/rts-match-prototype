# P0 アセット案 03: 自走砲

状態: 形状方向は承認済み。ゲームへの反映前。

## 役割と形状

陸上の長射程・対構造物向け部隊。装甲強襲より低く長い履帯車体に、前方へ長く伸びる角断面の砲身カバーと後部駐鋤を設ける。装甲強襲との違いを砲身の長さ、車体の低さ、後部支持部で読ませる。

- 低く長い履帯車体と直線的な側面装甲
- 小型の角形砲塔と、車体より長く見える直線的な砲身カバー
- 車体後部の左右に一基ずつ、対称に展開する駐鋤アームと接地パッド
- 白・冷灰・濃灰を軸にした大きな幾何学迷彩と小さな橙色標
