# P0 アセット案 01: 装甲強襲

状態: 形状検討案。ゲームへの反映前。

## 役割と形状

装甲強襲は、陸上を移動し拠点を制圧できる初期部隊。ユーザーの指示により、旧デザイン案の履帯式・直線的な近未来兵器の方向を採用する。

- 低く幅広い装甲胴体と、左右の連続した履帯ユニット
- 履帯を覆う直線的な側面装甲
- 胴体中央の低い角形砲塔と、前方を向く角断面の砲身カバー
- 白・冷灰・濃灰の大きな装甲面、控えめな青の幾何学迷彩、小さな橙色の識別標
- 胴体、砲塔、砲身、履帯の接続とクリアランスが読み取れる構造

## 既存モデルとの整合

形状の基準は [revision-04 の兵器案](../p0-approved/revision-04/02-angular-unit-designs.png) の左上にある装甲強襲。なお、[機能仕様書](../../機能仕様書.md) と `packages/client/src/game/models.ts` の現行記述・実装には6本脚の試作形状が残っている。ゲームへ反映する段階で、この設計方針に揃える必要がある。
