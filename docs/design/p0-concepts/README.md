# P0 部隊アセット形状案

各兵種のシルエットと構造を個別に照合する三面設計資料。共通の方向は旧兵器デザイン案の、直線的な装甲面、白・冷灰・濃灰の配色、大きな幾何学迷彩、控えめな青差し色。

いずれも形状検討案で、ゲームへの反映前。現行モデルとの差分は個別メモに記録する。

自走砲の形状方向はユーザー確認済み。その他の個別案は旧兵器デザイン方向に揃えた形状検討資料。過去の不採用出力は [archive](archive/README.md) に移動し、採用候補と区別している。

## 生成指示の共通項

旧デザイン案の兵器シルエットを基準に、同じ機体を斜め前方・俯瞰・側面の三方向で構造が一致するよう描く。白・冷灰・濃灰の近未来装甲に、大きく控えめな青系幾何学迷彩を配する。高周波の細部、余分な装備、画面UI、文字、ロゴ、人物、戦闘背景は含めない。

兵種ごとの形状差分は個別メモに記載。
