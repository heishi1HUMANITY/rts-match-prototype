# P0 アセット案 02: 偵察

状態: 形状検討案。ゲームへの反映前。

## 役割と形状

偵察は陸上部隊の中で高速・高視界、低耐久の軽量ユニット。ゲーム内の役割に合わせ、装甲強襲より小さく軽い六輪装甲車とし、センサーマストで兵種を識別できる形にする。

- 細身のくさび形車体と、左右それぞれ前・中・後の3輪
- 装甲強襲より薄く小さい装甲面、軽快な車高と短い後部車体
- 屋根中央寄りの小型センサーマスト
- 大砲や大型レーダーを付けず、偵察車としての軽さを維持
- 白・冷灰・濃灰の大きな装甲面と控えめな青の幾何学迷彩。橙色の識別標は小さく使う

## 旧デザイン案との整合

形状と塗装は [revision-04 の兵器案](../p0-approved/revision-04/02-angular-unit-designs.png) の上段中央にある偵察車を基準にする。三面資料で車体、6輪、センサーマストの位置を揃えた。

現行の `packages/client/src/game/models.ts` と [アセット一覧](../../アセット一覧.md) は4輪としている。画像案はユーザー指定の旧デザイン方向に合わせた6輪案であり、ゲームへ反映する段階で既存モデルの記述・実装と揃える必要がある。
