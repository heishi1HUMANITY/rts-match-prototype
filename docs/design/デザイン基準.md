## 世界とエンティティ

| 対象 | 基準 |
| --- | --- |
| 近景・操作対象 | 大きな面と色の整理を保つ。窓・入口・橋の構造など、用途と材質が伝わる箇所にディテールを置く |
| 遠景 | 建物の塊、輪郭、色面、空気遠近を中心にする。個別の窓、配管、屋上設備を描き込まない。抽象化版程度の密度を目安とする |
| 街の表現 | 都市として連続した空間と縮尺を保ち、大きな舗装面・窓帯・橋・植栽の塊で抽象化する。葉、舗装目地、配管、水面反射などの細部を描き込みすぎない |
| 兵器 | 兵種を識別できる成立した構造を保ち、直線・装甲面・角形の砲身カバー・まとまった側面装甲で近未来化する。現代兵器の忠実な再現や細かな装備の追加は行わない |
| 迷彩 | 白・灰・濃灰を軸とする大きな矩形・三角形などの幾何学パターン。控えめな青の差し色。自然な軍用迷彩や細かなピクセルノイズではなく、人工的なデジタル迷彩の印象を出す |
| 縮尺 | 街に対して兵器を不自然に巨大化しない。見つけやすさは選択表示・番号・シルエットで補う |
| SF感 | 工業的な形、材質、控えめな使用感、都市の空気で表現。機械パーツの過密化や光沢の強い玩具風の表現を避ける |
| 色・光 | 中間版の落ち着いた暖色の光と寒色の影を基準に検討。チーム識別は色と形・文字を併用する |

近景も細部を一律に増やさず、操作対象を読むために必要な情報へ配分する。遠景から操作対象へ近づいたときに、同じ世界として見える形・色・材質を保つ。

## クレヨンとUI

画面共通の詳しいUI方針は[UIデザイン方針](UIデザイン方針.md)を参照する。

| 対象 | 基準 |
| --- | --- |
| 移動経路 | 粒状の顔料、かすれ、筆圧のむら、わずかな線の揺れを持つクレヨンモチーフ。所属色を使い、移動方向が読める矢印にする |
| 紫の線 | 夢の侵蝕の痕跡として通常の命令経路と区別。余白だけの飾りにせず、盤面との関係を設計する |
| 情報保護 | クレヨンが文字、重要な状態表示、タップ対象を覆わない。画像中の線の方向や位置は実装時に移動経路へ合わせる |
| UI | 白基調の面、浅い凹凸、細い区切り、読みやすい濃色文字。画面の機能に応じて密度を決める。中間版の最小HUDは全機能の仕様ではない |
| タイトル | 仮置きのため大きく出さない。作品名が不要な画面では表示しない |

| UI・マップの凹凸 | 白・薄灰の面を軸に、浅い浮き出し・押し込み、短く柔らかな影、細い冷灰色の境界を使う。マップは道路・建物・橋の面の段差として控えめに適用する。濃色文字でコントラストを保ち、シアンとオレンジは状態表示や経路などに絞る。丸く膨らむボタン、濃色のガラス風パネル、強い発光を避ける。[方向確認用のRevision 06](p0-approved/revision-06/README.md)を参照。 |

### メイン画面の追加条件

メイン画面は街並みの低い観察視点ではなく、地面を上から見下ろす戦術的な俯瞰とする。空や地平線を表示せず、部隊・拠点・経路を建物が隠さないようにする。都市の中間版は材質・形・ディテールの基準であり、カメラ角度の基準にはしない。

指導者はメイン画面の通信窓に常時表示する。参照キャラクターの顔と肩が読めるバストアップを用い、名前・通信状態・字幕とまとめる。無線アイコンや字幕だけでキャラクター表示を代替しない。盤面を圧迫しないコンパクトな窓とする。
