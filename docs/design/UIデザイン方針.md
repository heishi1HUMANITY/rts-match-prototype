# UIデザイン方針

## 目指す印象

白い試験施設を思わせる、無機質で精密な近未来感を軸にする。Portalのような規格化された建築、静けさ、機能に徹した空間構成を参考にするが、固有の造形・ロゴ・画面を再現しない。

UIは白基調のニューモーフィズムでまとめる。柔らかな凹凸は素材感を補うために使い、丸く膨らんだ玩具のようなボタンや、影だけに頼った曖昧な操作表示にしない。清潔感と軍事指揮システムの緊張感を両立させる。

方向確認の基準画像は[Revision 06](p0-approved/revision-06/README.md)。本書は画面共通の指針で、個々の画面は操作内容に合わせて情報量を調整する。

## 色

| 用途 | 方針 |
| --- | --- |
| UI面 | 白・磁器色・薄い冷灰色。全面を真っ白にせず、面の差で階層を作る |
| 文字・主要アイコン | 濃いグラファイト。小さい文字も背景に埋もれない濃度を保つ |
| 境界・影 | 細い冷灰色の境界と短く柔らかな影。強い黒影や太い縁取りを避ける |
| シアン | 技術状態、情報フォーカス、味方側の選択表示などに限定する |
| オレンジ | 命令、選択中の部隊、クレヨンの移動経路など、プレイヤーの行動を示す |
| 紫 | 夢の侵蝕など、通常の戦術情報と区別する特別な現象に使う |

色だけで状態を伝えず、形・アイコン・ラベル・線種を組み合わせる。装飾のためにアクセント色を増やさない。

## 面と凹凸

- パネルは整った矩形を基本とし、角丸は小さく抑える。
- パネル、ボタン、選択タイルには浅い浮き出し、または浅い押し込みを使う。影は短く控えめにし、面の色差と細い境界線も併用する。
- ニューモーフィズムの影を重ねすぎない。要素が背景から浮いて見える大きなドロップシャドウ、ぼってりした厚み、光沢、ガラス風の透過を避ける。
- 操作できる要素は、凹凸に頼らず、ラベル・アイコン・選択状態で操作対象だと分かるようにする。

## 文字と情報の階層

- 数値、部隊名、状態、操作ラベルは短く明瞭にする。濃色の文字を使い、白面上のコントラストを保つ。
- 資源・タイマーなど常時確認する情報、盤面上の部隊・経路、選択対象の操作、チュートリアルや通信内容を、それぞれまとまりとして配置する。
- パネルは盤面の要所、部隊、目的地、移動経路を隠さない。説明は短く区切り、必要なときに視線が移る位置へ置く。
- 仮タイトルは小さく扱い、戦術情報より目立たせない。

## マップと盤面

- マップもUIと同じ白・薄灰・濃灰の設計言語を使い、道路・建物・橋・拠点を大きな面と浅い段差で表す。
- 都市は詳細なジオラマではなく、見通しのよい戦術盤として抽象化する。道路の交差、橋の接続、遮蔽物、拠点の位置がひと目で分かる形を優先する。
- 建物や道路は面の高さ・色・影で控えめに区別する。細かい舗装目地、配管、窓、葉、汚れ、水面反射を増やして情報を散らさない。
- 道路は落ち着いたグラファイト色、水面は抑えた青灰色を基本にする。白い建築面との明度差を確保しつつ、盤面全体が白飛びしないよう中間色を残す。
- 地面を上から見る戦術的な俯瞰を保ち、空や地平線を入れない。部隊や目的地の縮尺は街に対して自然にする。

## 部隊と経路

- 兵器は盤面に対して小さく現実的な縮尺にする。見つけやすさは過度な拡大ではなく、シルエット、番号、選択枠で補う。
- 選択中の部隊や目的地は、明確な輪郭・番号・アクセント色で示す。影や凹凸だけで選択状態を伝えない。
- 移動経路はクレヨンの顔料感を持たせ、直線的で精密な盤面に対する人間らしいアクセントとして使う。経路と矢印は部隊の進行方向が分かる太さ・形にする。
- 紫の侵蝕表現は通常命令のオレンジ経路と混同しないよう、線の形や動きも変える。

## 状態の表現

| 状態 | 表現の考え方 |
| --- | --- |
| 通常 | 白・薄灰の面と濃色文字で落ち着かせる |
| 選択中・推奨操作 | アクセント色、明確な輪郭、番号やラベルを併用する |
| 無効・未生産 | 明度と文字で一段弱めるが、読める濃度は保つ |
| 危険・破壊的操作 | 確認文、対象、損失や所要時間を具体的に示し、色だけで警告しない |
| 特殊現象 | 紫など専用の色と形を用い、通常の部隊命令から視覚的に分ける |

## 避ける表現

- 暗いガラス風パネルを画面に重ねる
- 丸く膨らんだボタンや、強い影で浮遊して見えるパネル
- すべての要素へグラデーション、発光、縁取りを加える
- 軍用ダッシュボードのように細かな目盛り・警告・小文字を過密に並べる
- マップを高密度のミニチュア都市として描き込む
- 大きすぎる部隊やキャラクターで盤面を圧迫する
- 色やニューモーフィズムの凹凸だけで操作可能・選択中・危険を示す

## 画面ごとの適用

メイン画面では、盤面と移動経路を主役にし、通信中の指導者、チュートリアル、部隊操作を補助情報として整理する。確認ダイアログでは対象と結果を読みやすくし、研究画面では分野・前提条件・進捗を線と階層で示す。どの画面でも、白基調と控えめな凹凸を保ちながら、機能に必要な情報を優先する。
