# アセット・画面・ダイアログの制作優先度

2Dデザインの見た目は [デザイン基準](design/デザイン基準.md) を参照。都市戦場の中間版をベースに、遠景は抽象化版程度まで簡略化する方針でユーザー確認済み。

2026-10-05 時点の確認結果。対象は [アセット一覧](アセット一覧.md) と [画面とダイアログ一覧](画面とダイアログ一覧.md)。[機能仕様書](機能仕様書.md)、M5-2 の進捗報告、クライアントの実装も照合した。

次の目標を「初見の人が説明役なしでボット戦を始め、移動・制圧・橋の建設・研究を理解し、結果を確認してもう一度遊べるプレイテスト」と置く。公開日・課金開始日は未定として、公開向けの項目は着手条件を付ける。これは制作順の提案であり、新機能の実装や公開を決定するものではない。

**先に必要なのは、導入、接続失敗からの復帰、重要操作の確認、盤面の情報を正しく読める表示。既存の模型・生成テクスチャ・CSS演出は継続利用し、画面の分割や大量の絵の制作は、その必要性がテストで分かってから進める。**

## 1. 優先度の基準

| 区分 | 時期 | 判断基準 |
| --- | --- | --- |
| P0 | 次のプレイテスト前 | 操作が分からない、待機から戻れない、誤操作でチームに損失が出る、判断情報が誤っている問題を防ぐ |
| P1 | 継続テストで改善 | 読みやすさ、状態変化の分かりやすさ、キャラの魅力、繰り返し遊ぶ導線を改善する |
| P2 | 外部公開・商用化の準備 | 認証・運営・販売など、公開形態や採用機能に応じて必要になる |
| P3 | 拡張段階 | 人口、継続率、コンテンツ量に応じて追加する |
| 保留 | 着手条件が未成立 | 現行の対象外、仕様と矛盾、必要な仕組みが未決定。制作発注に含めない |

「既存で充足」は新規制作しないという判断。「P0で検証」は現行の表示や操作を試し、問題が確認された箇所を修正するという判断。元一覧の「高・中・低」は企画上の旧分類として残すが、今から着手する順序は本書を優先する。

## 2. 最初に着手するもの

| 順 | 対象 | 最小範囲 | 完了の目安 |
| --- | --- | --- | --- |
| 1 | 一覧の仕様・参照の整理 | 6部隊、4分岐の研究、開始時から存在する拠点に記述を合わせる。ダイアログの詳細表と対応表を分離する | 制作担当が旧仕様の部隊・研究・出現演出を作らずに済む |
| 2 | S08 / D41 導入 | 現行ボット戦と「次の目標」「操作ガイド」を利用し、移動→小拠点制圧→生産→橋→研究を段階案内。飛ばす・再表示も用意 | 初見のテスターが説明役なしで一連の操作を完了する |
| 3 | D42 接続エラー | 接続中・再接続中に待機状況、再試行、戻る操作を表示。保存済みセッションを消す操作は区別する | 接続先停止・試合中切断・復帰失敗で操作不能にならない |
| 4 | D29 / D30 / D31 重要操作 | 離脱、再建、解体で影響を説明し確定する。再建は共有チケット150、解体は通路への影響を明示 | キャンセルで通信要求が送られず、確定後に結果が分かる。未実装の罰則は表示しない |
| 5 | S05 / S05a と判断用アセット | 部隊6種、所属、練度、到達可否、建設中、補給線、妨害を区別。研究画面でも試合が進むことを明示 | 色だけに頼らず文字・形でも読める。表示同士が重なって操作を妨げない |
| 6 | D24 戦闘予測の情報精度 | 敵練度を無視している現行制限を解消するか、未反映要素と概算であることを明示。視界外の情報は使わない | 未反映要素を含む予測を確実な勝敗として見せない |

現行の操作ガイドは実装済みなので、ゼロから別の案内を作る必要はない。D24の情報精度は絵の制作より前に扱う。改善には計算や通信上の制約の確認も必要。

P0の確認は静止画だけで完了とせず、対象スマホの横持ちでタップ領域、文字やポップの重なり、描画速度と入力への応答も確認する。

## 8. 推奨する制作順と依存関係

1. **P0の導入・復帰・重要操作・判断情報**を整える。既存の絵と模型で初見プレイテストを行い、詰まった箇所を記録する。
2. **P1の識別・フィードバック**を改善する。必要なアイコン、最小の効果音、通信窓のポートレートを制作。物語やホームの画面分割はまだ行わない。
3. **公開範囲を決めてP2を選ぶ。** 識別・データ保持方針→S07、公開対戦→D39、無効試合判定と返却→D53、停止/更新判定→S28。表示だけを先に作って機能があるように見せない。
4. **販売採用を別に判断する。** 外観所持・装備→S14、決済・商品・在庫→S15/D33、抽選と重複→S16/D34。販売を採用しないなら関連アセットも作らない。
5. **P3の独立画面・世界観素材・大型演出**は、継続率、参加人口、コンテンツ量を見て追加する。

最初の制作単位は「段階案内、接続エラー、離脱/再建/解体の確認、判断表示の見直し」。美術の制作単位は、そのテスト結果に応じたアイコンと通信窓の顔絵から始める。
