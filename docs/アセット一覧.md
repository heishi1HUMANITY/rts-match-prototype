# アセット一覧(現行 + 将来)

今から着手する制作順は [アセット・画面・ダイアログの制作優先度](制作優先度.md) を参照。将来項目の「高・中・低」は企画上の旧分類で、既存で充足するもの・条件付きのものを含む。

2026-10-05 時点でクライアント(`packages/client`)が使っている視覚アセットの一覧。画像ファイルは `public/art/` の6枚だけで、それ以外はすべてコードで生成している(Three.js の低ポリ模型、Canvas で描くテクスチャ、CSS/SVG の図形)。「状態」列: **完成** = このまま使える、**仮** = 見た目の方針は満たすが差し替え前提のプレースホルダ、**モック** = 開発用。

## 1. 3D モデル(Three.js、コード生成)

生成元は `game/models.ts`(拠点・部隊・橋・索道・プレート)、`game/terrain.ts`(川・山)、`game/render.ts`(床・装飾・霧)。ジオメトリとマテリアルは種類ごとに共有し、チーム色は「accents」に登録したパーツのマテリアル差し替えだけで行う。箱と円柱には CAD 風の輪郭線(EdgesGeometry、#3b4752 α0.55)が付く。ポリゴン数は三角形の概数(輪郭線を除く)。
