- **指名代理組織:**

- **公的中立介入:** 調停執行監察隊（AEC）第4監査班（公開任務：海峡水門施設の物理保全監視）
- **独立判定機関:** IMCO調停審判院（Tribunal System）

### 1. 深度3の日常と承認ログ

「……バイタル安定。神経同調率、八十二パーセント。おい設計士、聞こえてるか」

冷たいホログラム作戦卓の左端、黒いベゼルに縁取られた通信ウィンドウに、男のバストアップが投影された。
画面の向こうのアレクセイ・ヴォルコフは、顎の無精髭を乱暴に撫で回しながら、不機嫌そうに合成タバコをくわえていた。彼の首元で、擦り切れた旧軍時代のドッグタグが鈍く光っている。

「クリアに聞こえている、アレクセイ。接続状態は良好だ」

「相変わらず、耳が痛くなるほど若い声だな」
アレクセイは煙を吐き出しながら目を細めた。
「首筋の冷却端子の調子はどうだ？ ガキの頭にはちと重すぎる仕事だと思うがね」

「問題ない。アルプスを出てから今日で四十二日目だ。標準稼働限界までは、まだ時間がある」

「……四十二日、ねえ。チッ、つまらん冗談を言うな。で、今日の戦場の値踏みは済んだのか？」

「ああ。係争対象はヴェルナ海峡の通航権だ。相手は南岸共和国が雇ったV-TACの自律ドローン部隊。それと、海峡水門の物理保全を名目にAECの監査部隊が中立介入している。独立審判院への事前登録条項に基き、水門主構造の損壊率が五パーセントを超えた時点でAECの電磁拘束が発動する。主堤防の爆破は厳禁だ」

「中立インフラの保全ねえ……」
アレクセイは小さく鼻を鳴らした。通信の背後から、スレートグレーに塗られた重装甲車両のアイドリング音と、履帯が軋む無骨な金属音が漏れ聞こえてくる。

「また地図のどこにあるかも知らん国の、泥水みたいな海峡のために頭痛薬を飲む仕事だ。だが安心しろ、契約は契約だ。定時までに終わらせて全員生きて帰る。設計図を降ろしてくれ」

設計士は小柄な指先で、成人規格の作戦卓「TIS-Aegis」を滑らせた。
卓上に展開された展開データツリーの深層、南岸軍の「海峡封鎖配置計画および交戦規定認可書」の最下部に、現行の承認暗号ログが小さく光っていた。

`［AUTH_SIGN: Matthias Brant, Gen.(Ret.) / Senior Advisor, Nat-Def Council］`

マティアス・ブラント退役大将（71）。南岸国防最高評議会顧問。かつて観測体01の奪取作戦に関わり、現在も強硬派の有力な後ろ盾である。彼の名は、現行CASEの最高承認者として刻まれていた。南岸議会ではすでに防衛予算の凍結を求める動議が提出されており、強硬派は支持を失いつつあった。

設計士がホログラムを展開すると、製図用紙のような白い余白――未確定因果の霧（Fog of War）の向こうに、青白い光を放つ送電塔と、海峡を跨ぐ巨大な水門施設が抽象化された幾何学トポロジーとして浮かび上がった。

試合開始のカウントダウンがゼロを示した。

### 2. 幾何学の戦場と実力の勝負

「第1小隊、セクター02の送電ハブへ前進。マラ、補給線のアンカーを打て。設計士、資源の配分はどうなってる？」

「順調だ。V-TACの林晨（リン・チェン）が北側の鉱区へドローンを先行させているが、足が速いぶん装甲が薄い。中央ルートから圧力をかければ、相手の生産ラインは止まる」

「了解だ。おい野郎ども、無人機なんぞにビビるな！ キャタピラで踏み潰してやれ！」

アレクセイの咆哮とともに、ATFの重装甲部隊が泥濘を切り裂いて突進していく。
だが、南岸側も引かない。V-TACの高精度な集中射撃がATFの前衛を削り、作戦卓の端に表示された北岸側の継戦能力指標（Capacity）が冷酷に減算されていく。

『北岸軍：Capacity残り二十八パーセント』
『南岸軍：Capacity残り三十一パーセント』

作戦開始から十八分。戦況は完全な消耗戦へと突入していた。
海峡の中央水門西岸をV-TACの防衛ドローン群が固め、中立特区の境界線ではAECの監査官ヴェラが率いる垂直の白銀部隊が、冷徹にシールドを展開して双方の火線が主堤防に及ぶのを遮断している。

「……クソが、本国の国防省から通信だ！」
アレクセイの通信ウィンドウにノイズが走る。
「『これ以上損耗を出したら本国議会の予算委員会が持たん、即時撤退要求が過半数に迫っている』と喚き散らしてやがる！ 南岸の砲撃も止まらねえ。設計士、水門の装甲を吹き飛ばすしかねえぞ！」

「ダメだ、アレクセイ！ 主堤防を壊せばAECの規律介入を招き、即座に失格敗退になる！」
設計士の細い指先が、目にも留まらぬ速度で作戦卓の幾何学トポロジーを解体・再構成していく。
首筋の冷却端子がシューと蒸気を吹き、大脳新皮質が焼きつくような熱を帯びる。1日14時間、託児所の寮で兄弟たちと指し続けた無数のチェス譜が、少年の直観の中で一つの細い光の筋となって収束した。

「見えた……！ 水門基部の点検用バイパス回路だ！ 主装甲の裏、地下3メートルの排水溝を通れば、堤防を傷つけずに中央管制室へ直結できる！ 第3小隊をそこへ突入させろ！」

「排水溝だと！？ キャタピラが泥に埋まるぞ！」

「信じてくれ、アレクセイ！ 僕が水圧バルブの開閉シーケンスを逆算して同期する。君たちなら通れる！」

アレクセイは一瞬、眉間を歪め――そして獰猛に笑った。
「……乗ったぜ、クソガキ！ 野郎ども、泥を喰らってでも潜れ！ 水門の裏口をこじ開けるぞ！」

ATFの車両が泥煙を上げて岩礁地帯の隘路へ滑り込んだ。
設計士が割り出したミリ秒単位のバイパス開閉に合わせ、泥まみれの装甲車が水門の管理棟へ突入、制御コンソールを物理制圧する。
中央水門のインフラ損壊率は0.0%のまま、海峡の管制権インジケーターが一気に北岸側のスレートグレーへと反転した。

その瞬間、通信回線にAECの冷徹な声が響いた。
『……所見：交戦規定違反なし。水門構造の保全目標を達成。AEC第4班、現場任務を終了する。CASEの勝者は審判系の判定を待て』
監査官ヴェラは静かに白手袋を整え、部隊とともにシールドを収容して後退を開始した。

続いて、中立の調停審判院から全世界へ向けて無機質な電子判定が公告された。

```text
［IMCO調停審判院（Tribunal System）公告］
CASE NO: 4092-B ―― 調停完了
判定：ヴェルナ海峡通航権は『北岸自由連邦』へ正式帰属
勝者：アイギス・タスクフォース（ATF）
調停時間：21分14秒 / 主席審判官：エリアス・ラハル
```

「……勝ったぞ！ 泥水すすった甲斐があったぜ、設計士！」
アレクセイの歓声が響き、作戦卓のユニット群が光の粒子となって霧散していく。

### 3. 紫の因果照準

だが、勝敗が決したまさにその瞬間。

*――チッ。*

設計士の側頭部の奥、神経同調端子を直接引っ掻くような、乾いた擦過音が知覚に響いた。
物理的なスピーカーからではない。同調インターフェースを通じて大脳に直接投射された、**同期知覚のエラー音**。

白く平滑な待機状態へと戻りつつあった「TIS-Aegis」のディスプレイ上、先ほど展開されていた展開ログの残影――南岸国防最高評議会顧問、マティアス・ブラントの電子署名コードの上に、**鮮烈な紫色の擦過痕**が走った。

紙にクレヨンを力任せに押し付けたような、ざらついた筆圧のムラを持つ、一本の細い紫の線。
その線は、ブラントの暗号署名コードを黒々とした『×印』で静かに穿ち、消え去った。

「……設計士？」
回線の向こうでアレクセイが訝しげに声を漏らした。
「おい、お前のバイタルが跳ね上がったぞ。大丈夫か？」

「……なんでもない、アレクセイ。演算の負荷だ」

設計士は震える手でディスプレイを見つめた。
盤面の勝敗は、自分たちの実力で掴み取った。水門も無傷だ。
だが――彼女は、この試合のログを通じて、現実世界にいる「かつて自分を奪った男」の存在を正確に補足したのだ。
あの紫の線は、戦術の介入ではない。
現実世界において、彼女が低確率事象を傾ける対象として認識したことを示す**「因果の照準（ロックオン）」**だった。

### 4. 三日後の現実収束

調停戦の決着から三日後。
現実世界のスイス・ジュネーブ、IMCO第7育成特区の管制室において、設計士の個人端末「TIS-Aegis」に一通の暗号化公文書が届いた。

```text
======================================================================
【国際夢境調停機構（IMCO）公式判決執行報告書】
CASE NO: 4092-B / ヴェルナ海峡事案

主文：
本案件に関する夢境調停の確定判決に基づき、ヴェルナ海峡の管轄権は
北岸自由連邦への帰属が確定した。南岸共和国政府は本日未明、同海峡
沿岸部隊に撤退を命じ、撤収を開始した。

［現実収束事由の概要］
調停終了から数週間後、南岸共和国軍の強硬派を支えるマティアス・ブラント
退役大将（71）の搭乗するヘリコプターが移動中に墜落した。事故調査の
暫定所見はテールローターの整備不良による金属疲労破断。同氏は重傷を負い、
顧問職を離れて療養に入った。事故原因の確定調査は継続中である。

ブラント顧問の離脱は、すでに支持を失いつつあった軍部強硬派閥の
調整力を弱めた。一方、議会では以前から海峡防衛予算の凍結が審議され、
補給負担とCASE判決をめぐる政治的圧力も強まっていた。数週間にわたる
審議の末、予算凍結が可決され、統括司令部は沿岸部隊への補給を段階的に
縮小、政府は撤退命令を出した。北岸政府との通航権移管の実務協議は
続いており、正式な条約批准にはなお時間を要する見込みである。
======================================================================
```

判決の権利帰属は確定していたが、現実側の撤退と条約手続きには摩擦が残っている。冷徹な官僚機構の報告書を、設計士は息を詰めて読んだ。
テールローターの微細な金属疲労。日常の点検で見落とされたのか、別の要因があったのか、調査はまだ終わっていない。
少女はミサイルを撃ち込んだのではない。彼女が低確率の不運を傾けたのだとすれば、その結果もまた、事故報告書だけから証明することはできない。
ブラントの離脱だけで撤退が決まったわけではない。積み重なっていた予算・補給・判決の圧力が、政治の手続きを通じて現実の海峡に作用した。

ディスプレイをスクロールした設計士の指が、ふと止まった。

電子公文書原本の最下部、IMCO事務総局のデジタル公印が押された余白。
その文書をTIS-Aegisで表示した画面上に、署名欄と同じ座標で薄いノイズのような**紫色の小さな染み**が重なっていた。公文書原本のデータではなく、端末のローカル描画異常だった。
拡大すると、それはクレヨンで描かれた、**折れた一本の銃**の輪郭に見えた。

サーバー上の公文書データには何も記録されていない。
それは、少女と同調した設計士端末「TIS-Aegis」のローカル診断レンダリングバッファにのみ焼き付いた、不揮発性の例外エラーだった。

管制室の空調が、冷たく唸りを上げている。
首筋の冷却端子がじくじくと熱を持ち、側頭部を鋭い鈍痛が貫いた。標準的な稼働限界まで、残りはおよそ五十五日だった。

ARC-Lot.01は静かに息を吸い、端末の深層ローカルパーティションを呼び出した。
AECの定期監査スクリプトはこの描画例外を「単なる表示バグ」として見過ごしている。
少年は、この紫の染みの座標を目印にして、託児所の寮生活で弟たちと指し合った「変形チェス譜」の暗号アルゴリズムを走らせた。

次期ロットとして、いずれこの席に座るであろう「弟（Lot.02）」へ向けて。

*――もし僕の脳が焼き切れた後、この端末を受け取るロットがいるなら。*
*画面の紫の染みを見ろ。それはバグじゃない。*
*公文書の数字の裏にある因果を読め。*
*彼女は――泣いているんじゃない。*

エンターキーを押すと、暗号メモはローカルの深淵へと静かに格納され、端末の画面は何事もなかったかのように清潔なマットホワイトの待機状態へと戻った。
