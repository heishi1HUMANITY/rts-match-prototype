# 01_世界構造と歴史

本書は、世界を支配する「因果の法則」、国際秩序を規定する「調停制度」、および現在に至る歴史的経緯を定義する。

---

## 1. 根本原理：因果律の傾斜と「辻褄合わせ」

この世界における戦争は、現実の領土ではなく**「眠り続ける一人の少女の夢の中」**で行われる。
国家がこの不条理なルールに従うのは、宗教的崇拝や国際協定の理念によるものではなく、**「逆らっても夢で決まった通りの結末になり、無駄に現実の死傷者が増えるだけだ」**という絶対的かつ血塗られた歴史的事実が存在するためである。

```
［夢境での戦争結末（確定）］
       │
       ▼（数日〜数週間の時間差）
［現実世界での「辻褄合わせ」］
  ・軍の突発的燃料枯渇・機械故障
  ・閣僚の突発的スキャンダル・総辞任
  ・金融市場の急落・戦時国債の暴落
  ・局地的な土砂崩れや異常気象
       │
       ▼
［結果：夢で敗北した側が、現実でも撤退・降伏せざるを得なくなる］
```

### 1.1 辻褄合わせ（Convergence / 収束）のメカニズム
夢境で決着がついた瞬間、現実の物理空間および人間社会において**「因果律の傾斜」**が発生する。
夢で勝利した陣営に有利な事象の発生確率は跳ね上がり、敗北した陣営には不可避の不運が連続する。大国の強力な師団が進軍しようとしても、補給列車が脱線し、司令官が急性心筋梗塞で倒れ、本国議会で反戦派が突如多数派を握る。

現実世界は、夢の中で刻まれた結果へ向かって、自らの歴史を力づくで「辻褄合わせ」する。
このため、現代の軍事・安全保障における最重要事項は「現実の軍備拡張」ではなく、**「夢境の代理戦で確実に勝利をもぎ取ること」**へと完全にシフトした。

## 2. 国際秩序と傭兵資本主義

少女の身柄を巡る世界大戦を回避するため、国際社会は彼女を不可侵の「国際管理資産」として中立特区へ隔離した。それを管理・運用する超国家機関が**国際夢境調停機構（IMCO: International Oneiric Mediation Commission）**である。
しかし、調停の現場で実際に戦うのは国家の正規軍ではなく、**適性者を独占した強大な民間組織たち**である。

```
                  ┌──────────────────────────────┐
                  │ 国際夢境調停機構（IMCO）      │
                  │  ・観測体01の独占隔離・維持  │
                  │  ・案件（CASE）の受理と裁定   │
                  │  ・調停盤面の提供とルール管理│
                  └──────────────┬───────────────┘
                                 │
         ┌───────────────────────┼───────────────────────┐
         ▼                       ▼                       ▼
  ［依頼国家 A］          ［依頼国家 B］          ［利害介入国 / 機構 C］
  （莫大な予算で委託）    （莫大な予算で委託）    （権益監視・中立介入）
         │                       │                       │
         ▼（代理調停契約）      ▼（代理調停契約）      ▼（直属部隊派遣）
  ［民間潜行会社 (PMC)］  ［大企業潜行事業部］    ［機構直属部隊 (AEC)］
  （適性者を囲い込む）    （先端ドローン部隊）    （秩序維持の名目で参入）
         └───────────────────────┴───────────────────────┘

                                 ▼
                     【 夢 境 調 停 盤 面 】
             （2〜4勢力によるリアルタイム戦術対戦）
```

### 2.1 潜行適性者の民間独占と「雇われ戦争（傭兵資本主義）」
現実の軍隊や核兵器は、夢の中では一切役に立たない。そして、少女の脳波に同調できる「潜行適性者（ダイバー）」は、全人類の中で数万人に1人という**極めて希少な生体資源**である。

- **力関係の逆転（国家の従属）:**
  制度の黎明期、高い報酬と先端研究施設を持つ民間企業（メガコングロマリット、PMC、医療財団）が世界中から適性者を買い集め・囲い込んだ。結果として、**「現実の軍備ではなく、夢に潜れる人間をどれだけ抱えているかが世界の安全保障を決める」**という歪な構造が成立した。国家は自前で潜行部隊を維持できず、莫大な国費を払って民間組織に「代理調停契約」を結ばざるを得ない。
- **国家が適性者を強制徴募・買収できない理由（利敵行為の恐怖）:**
  夢境での戦闘判断は、オペレーター本人の精神の深層に完全に依存している。国家が武力で潜行組織を脅迫したり強制国有化しようとすれば、オペレーターは夢の中で**「故意の利敵行為（サボタージュ）」**を行い、自国を簡単に敗北させることができる。その結果、国家は現実の辻褄合わせで破滅するため、国家側も民間に頭を下げ、高額な報酬で機嫌を取るしかない。
- **例外としての国家統制・機構直属陣営:**
  自由主義国家が民間に依存する一方、徹底した思想統制と非人道的人体実験を行う一部の全体主義国家や、IMCO直属の「調停執行監察隊（AEC）」のみが、自前で直属の潜行部隊を組織している。

### 2.2 紛争の多極化（状況に応じた多勢力戦）
代理戦の盤面は、固定されたオカルトルールではなく、**現実の国際政治の利害関係がそのまま反映された多極戦**となる。

- **なぜ多勢力の三つ巴・四つ巴になるのか:**
  現実の紛争と同じく、ある海峡や油田を巡る争いには、当事者2国だけでなく「通航の自由を主張する大国」「中立監視を掲げるIMCO」「周辺の権益国」「裏で雇われた違法組織」が介入してくる。
- **柔軟な調停形態:**
  案件（CASE）の規模や外交的思惑に応じて、シンプルな2国間対戦から、三つ巴（3チーム戦）、あるいは四つ巴（4チーム戦）まで、多極的な同盟と裏切りの戦場が形成される。短編で描かれたヴェルナ海峡事案（CASE 4092-B）は、南北の当事国に機構が監視介入した結果の3勢力戦であった。

### 2.3 生体相互確証破壊（BMAD）と「空白の42秒」
国家が少女の生命維持装置を破壊して現実の戦争に戻ろうとしないのは、倫理のためではない。**「少女が死ねば、世界が道連れになる」という絶対的な実証（血の教訓）**が存在するためである。

2038年、ある大国の強硬派諜報機関が、代理戦制度の固定化を嫌い少女の暗殺（毒殺）を実行した。彼女の心拍は停止し、脳波は**42秒間**完全にフラットライン（平坦化）に落ちた。
そのわずか42秒の間、因果のアンカーを失った現実世界では、確率論の崩壊による天文学的大災害が同時多発した。

- 稼働中だった原子力発電所の制御棒が突如誤脱落し、メルトダウン寸前の危機に陥った。
- 世界3大メガバンクの量子乱数が「0」に固定され、国際金融ネットワークが麻痺した。
- 飛行中だった数十機の航空機で油圧系統の多重故障が突発し、世界中で数千人が事故死した。
- **そして何より、暗殺を指示した大国の軍首脳が集う極秘司令地下要塞に、自国の格納庫から誤発射された巡航ミサイルが直撃し、首謀者全員が即死・壊滅した。**

現場医療班の決死の除細動により43秒目に心拍が再開した瞬間、まるで奇跡のように原子炉の冷却水が循環し、暴発ミサイルの弾頭が沈黙した。
各国の物理学者と軍事顧問は戦慄と共に結論を出した。
**「彼女の生命活動は、地球規模の因果エントロピーを繋ぎ止める杭である。彼女が完全に死亡した場合、全球の核弾頭の誘爆と大災害により、人類文明は15分以内に地上から消滅する」**

この**生体相互確証破壊（BMAD: Biological Mutually Assured Destruction）**の実証以降、暗殺という選択肢は地球上から永久に消滅した。IMCOのサンクタムが多重防護されている真の理由は、少女を守るためではなく、**「彼女の心臓が止まることによる全地球の道連れ（滅亡）を防ぐため」**である。

## 3. 現実社会の日常と空気感

戦争が血の流れない夢境に代替された結果、現実の市民社会は一見すると高度に洗練された平和を享受している。しかしその内実は、不条理と冷笑に満ちた日常である。

- **CASEニュースの日常化:**
  テレビや街頭スクリーンには、天気予報や株価と並んで「CASE NO: 4092 ヴェルナ海峡通航権 判定確定」といったニュースが流れる。市民はそれをスポーツ中継のように消費し、あるいは関連企業の株価の乱高下に一喜一憂する。
- **潜行者（ダイバー）という労働階層:**
  莫大な報酬を得るスター潜行者がメディアを飾る一方、現場の潜行者の大半は「他国の国境のために神経をすり減らす使い捨ての会社員」である。潜行回数が重なるにつれて精神の摩耗（ブレイン・ブラー）が進み、引退後は味覚や感情を失う者も少なくない。
- **闇市場と未来インサイダー:**
  夢境で決着がついてから現実に辻褄が合うまでの「数日〜数週間のラグ」は、世界で最も価値のあるインサイダー情報となる。未登録の違法組織が危険を冒して夢境にハッキング潜行するのは、この未来の情報を盗み出して市場で巨利を得るためである。
