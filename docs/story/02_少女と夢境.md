# 02_少女と夢境

本書は、世界の運命を握る核心的存在「観測体01（少女）」の身体的実態、心理、および彼女が夢境を通じて世界に行使する「静かな加害」の構造を定義する。

---

## 1. 観測体01（少女）の実態

### 1.1 現実の姿：奪われた時間
現実世界の彼女は、スイス中立特区地下深くに建造されたIMCO中央クリーンルーム「サンクタム」の生命維持ポッド内に横たわっている。

- **肉体年齢:** 20代半ば。しかし十数年間にわたり医療的昏睡を強いられてきたため、筋力は衰弱し、肌は光を知らず青白い。
- **伸び続ける髪:** 脳波測定用電極がびっしりと貼り付けられた頭部から、切り落とされることのない黒髪が無重力培養液の中に漂っている。
- **「少女」という欺瞞の呼称:**
  世界は今なお彼女を公式にも非公式にも**「少女（The Girl）」**と呼び続けている。彼女が肉体的に成人した事実を認めてしまえば、国際社会は「一人の成人女性を十数年間監禁し、国家の都合で薬物昏睡させ続けている」という人道に対する罪と直面せざるを得ない。世界は自らの倫理的罪悪感を麻痺させるため、彼女を「無垢な子どもの象徴」として記憶の檻に閉じ込めている。

### 1.2 夢境の中の姿：凍結された10歳
潜行者が戦う夢境の深層において、彼女は最初に眠らされた**「10歳当時の子どもの姿」**で現れる。

- **外見:** 地方療養施設の簡素な薄青いスモック。その上から、身体に対して明らかに大きすぎる大人のトレンチコートを羽織っている。
- **大きすぎるコートの主:** かつて小国で彼女を最初に発見し、のちに大国への引き渡しに反対して「事故死」に見せかけて粛清された情報局中尉の形見である。彼女はこのコートを決して脱がない。
- **手元の一本のクレヨン:** 彼女の右手には、いつも一本のクレヨンが握られている。その顔料の色は、戦術UIや軍事コードのどれとも一致しない、鮮烈で冷徹な**「専用バイオレット（紫）」**である。
- **視線と表情:** 泣き叫ぶことも、可哀想に怯えることもない。極めて平坦で感情の読めない、冷たい双眸で戦場を、そして盤面を俯瞰する設計士（プレイヤー）をじっと凝視する。

## 2. 加害の意志（Silent Retaliation）

少女は決して、理不尽な運命に耐えるだけの聖女や無力な被害者ではない。彼女は明瞭な自己意識を保っており、同意なく自分を消費し続ける世界に対して**「冷酷かつ計算された加害」**を行っている。

```
［盤面の勝敗］ ─────── 完全中立・公平
  （戦術設計士と潜行者の腕前により決着）
       │
       ▼
［現実の辻褄合わせ］ ─── 【少女による意図的な介入】
  「A国の勝利」という大枠の結末は変えずに、
  現実へ収束する因果のルートを彼女が選別する。
       │
       ▼
［特定の標的に対する「たまたまの破滅」］
  ・彼女の管理・延命に署名したIMCO高官が突発的脳卒中で倒れる
  ・代理戦ビジネスで私腹を肥やすメガコーポの最新工場が炎上する
  ・彼女を国家の道具として売り渡した元軍閥が汚職で逮捕される
```

### 2.1 なぜ試合の勝敗は歪めないのか？
彼女は夢境の勝敗そのものを書き換える力を持っているが、**絶対に試合の結果を不正に曲げることはしない**。
理由は極めて現実的かつ冷徹である。もし彼女が勝敗を露骨に操作すれば、国家群は「夢境調停は公平ではない」と判断し、再び現実世界で銃を取り、本物の血を流す戦争を始めてしまう。彼女はその愚かな破滅を避けるため、戦術盤面のルールだけは厳格に公平に保ち、プレイヤーたちに勝敗を委ねている。

### 2.2 辻褄合わせのルート選択
彼女が手を下すのは、**「勝利が決まった後、現実がその結果を受け入れるための理由作り（因果のルート）」**である。
ある国家が敗北した際、その撤退理由は「穏便な外交的妥協」であってもよいはずである。しかし彼女は、あえて「自分を虐げてきた人物の破滅」を撤退のトリガーとして現実世界に発生させる。

- 辞任、暗殺、原因不明の航空機事故、金融破綻、不正の内部告発。
- 現実のニュースでは「悲劇的な偶然」として片付けられる事象の数々は、すべて彼女の手によって紡がれた個人的な復讐の執行である。

### 2.3 少女が全能ではない「3つの構造的制約」
彼女は世界を意のままに操る全知全能の神ではない。彼女の復讐が十数年かけても終わらないのは、以下の3つの絶対的な構造的限界が存在するためである。

1. **導線の制約（官僚機構・署名の壁）:**
   彼女は現実世界を直接見渡す千里眼を持たない。彼女が因果の糸を伸ばせるのは、**「夢境に持ち込まれた前線部隊の通信ログや公文書に、責任者として署名された人物」**というデータ（導線）が存在する場合に限られる。
   大国の首脳や軍需産業の黒幕たちはこの法則を熟知しており、前線の契約書から自分の名前を徹底的に消し、ダミー会社や身代わりの現場将校を何重にも挟んで保身している。そのため、少女は本当に殺したい黒幕たちになかなか手が届かず、手前のトカゲの尻尾ばかりを切らされている。
2. **微細な綻びの制約（バタフライ・エフェクト）:**
   彼女が起こせるのは、落雷や即死のような物理法則を無視した大奇跡ではない。彼女ができるのは、**「現実の確率論の範囲内にある、ごく些細な綻び（整備不良のネジを1本緩める、議会資料の誤字を見落とさせる、急ぎの連絡を5分遅らせる）をそっと突くことだけ」**である。その小さな狂いが現実世界のドミノ倒しとなって破滅へ収束していくため、露骨な超常現象を起こすことはできない。
3. **覚醒の抑制（息を潜める必要性）:**
   彼女が未来を観測し因果に触れられるのは、**「深いレム睡眠の底」**にいる時だけである。強い怒りを爆発させたり、盤面を無理やり塗り替えようとすると、脳波が急激に覚醒側へ跳ね上がり、**夢境の空間そのものが強制シャットダウン（暗転・切断）**してしまう。
   夢が醒めれば、彼女はただの昏睡患者に戻り、国家は現実の戦争を再開してしまう。そのため彼女は、IMCOの生体監視モニターを刺激しないよう、**「目覚めてしまわないよう息を潜めて、ごくわずかに細い線を引くことしかできない」**。

## 3. 未帰還者（The Lost Divers）

この「不自然すぎる偶然の連鎖」に気づく人間は、これまでにも存在した。
優秀な戦術設計士、あるいは何十回もの潜行を生き延びたベテランの同期オペレーターたちである。

```
［疑問の発生］ 
  「なぜ特定の政治家や軍需企業の役員ばかりが、調停後に死ぬのか？」
       │
       ▼
［夢境深層での調査］
  戦術盤面の境界を越え、夢境のシステム深部へアクセスを試みる
       │
       ▼
［少女との接触 / 排除］
  画面に突如走る「紫のクレヨン線」。通信の途絶。
       │
       ▼
［現実での結果：未帰還事故］
  ダイブポッド内で激しい脳波異常（フラットライン）。
  肉体は生存するも意識は永久に覚醒しない「植物状態」として病棟へ送られる。
```

- **機構による隠蔽:**
  IMCO上層部は、この未帰還事故の多発を「潜行深度の限界超過による精神神経衰弱症」として処理している。「少女が意図的に潜行者を排除している」という事実が公になれば、世界中の潜行組織がボイコットを起こし、調停制度そのものが崩壊するためである。
- **夢の底に残る意識:**
  排除された潜行者たちの意識は完全に死んだわけではない。彼らの思念の残骸は、夢境の索敵不能領域（霧の最深部）に「残存する亡霊」として漂っており、時折、盤面のノイズやNPCの不可解な行動として現れる。

## 4. 紫のクレヨン痕（侵蝕の記号）

ゲーム盤面や公文書UIに突如として現れる「紫のクレヨン線」は、単なるビジュアルエフェクトではなく、**少女の意識がその因果を直接掴み取った痕跡**である。

| 発生箇所 | 現象 | 作中での意味 |
| :--- | :--- | :--- |
| **移動指示線の上書き** | オペレーターの部隊移動ルートが、紫のクレヨン線で荒々しく曲げられる | その進軍ルートが、現実世界で誰かの死へと直結しているサイン |
| **制圧拠点の×印** | ホログラムの拠点模型の上に、黒々とした紫の×印が殴り書きされる | そのインフラが現実で「事故」によって喪失することを予告 |
| **CASE公文書の余白** | 試合終了後の判決レポートの片隅に、小さな落書き（折れた銃、閉じた目）が滲む | 少女による「執行完了」の受領印 |

彼女は沈黙の底から、一本のクレヨンで世界を塗り替え続けている。
戦術設計士（プレイヤー）がその線に気づいたとき、物語の歯車が静かに動き出す。
