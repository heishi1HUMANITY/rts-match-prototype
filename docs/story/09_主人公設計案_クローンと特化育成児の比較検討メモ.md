# 09_主人公設計案：クローンと特化育成児の比較検討メモ

本書は、課題04（主人公の特権階級化・ご都合主義の排除）および「1シーズンごとの交代・使い捨て感（ZombiU型バトン）」を実現するために検討された、**主人公（戦術設計士）の2つの造形パターン（パターンA：クローンロット制／パターンB：特化育成児制）**を詳細に記録した比較検討メモである。

---

## 1. コアコンセプト：少女との鏡像関係（ダブル・プロタゴニスト）

どちらのパターンを採用した場合でも、本作の最大の強みは**「眠り続ける少女（観測体01）」と「盤面を組む主人公（設計士）」が、大人たちに人生と尊厳を搾取される【鏡像（合わせ鏡）】になる点**にある。

```
［少女（観測体01）］ ────────────── ［主人公（戦術設計士）］
  ・10歳で眠らされ、道具にされた          ・幼少期から育成/培養され、道具にされた
  ・夢の中で未来を観測させられる          ・作戦卓で因果を計算させられる
  ・大人になることを奪われた              ・大人になる前に脳を焼かれて廃棄/交代される
          │                                       │
          └───────────【 鏡 像 関 係 】───────────┘
               「……あなたも、私と同じ檻の中にいるのね」
```

少女が設計士に目を止めるのは「天才だから」でも「プレイヤーだから」でもない。
**「世界中の大人たちが自分を都合よく利用する中で、目の前で命を削って盤面を動かしているあなただけが、自分と同じ生贄の子どもだから」**という、哀切と共鳴の動機が成立する。

## 2. パターンA：【培養クローン・ロット制】（ハードSF・冷酷美）

### 概要
主人公は、IMCO極秘生体ラボ（または特定のメガコーポ）で培養・量産されている**「戦術因果演算特化型のクローン人間」**。単一の優秀な素体から生み出されたシリアルナンバー個体。

- **コードネーム形式:** `ARC-Lot.01`、`ARC-Lot.02`、`ARC-Lot.03`……
- **寿命と交代サイクル:**
  高次ホログラム作戦卓を通じた因果演算は、人間の大脳皮質を限界まで過熱させる。**およそ1シーズン（数ヶ月）の過密稼働で脳神経細胞が不可逆的に壊死**するため、シーズン終了とともに現行ロットは「医療廃棄（解体・処分）」され、地下コールドスリープ室から「次期ロット」が解凍される。

### ゲーム仕様との同期
- **強さ・メタ進行の引き継ぎ:**
  前任ロットの戦闘演算データ・組織クリアランス・所持アドオンが、次期ロットの脳へ機械的にフラッシュ（データ同期）されるため、プレイヤーのアカウントデータがリセットされずに引き継がれる。
- **シナリオ上のサスペンス（記憶消去のバグ）:**
  本来は戦闘データのみが同期され、個人的な記憶や感情は初期化されるはずだった。
  しかし、**少女が引いた「紫の線」に触れたロットの記憶だけはシステムで消去できず、次期ロットの脳裏に「前任者が最後に見た絶望と少女の姿」がバグノイズとして焼き付いてしまう**。

### 演出・トーン
- 「また自分と同じ顔をした死骸がダストシュートに落とされた」という、極限まで無機質で乾いたディストピア感。
- 主人公自身も自分の命に執着がなく、ただ淡々と任務をこなすが、少女の紫の線に触れることで「感情のバグ」が発生していく。

## 3. パターンB：【特化育成児（デザインド・チルドレン）】（切なさと群像劇）

### 概要
主人公はクローンではなく、幼少期に特異な空間把握・直観演算の適性を見出され、孤児院や貧困地帯から国家・機構の育成機関に集められた**生身の少年・少女たち**。

- **育成環境:**
  人権も名前も剥奪され、認識番号だけで呼ばれる。一般教育は一切受けず、幼少期から「戦術盤面のシミュレーション」だけを一日十数時間叩き込まれて育った、歪な超エリート戦術児。
- **寿命と交代サイクル:**
  10代半ばで現場に実戦投入されるが、過酷な神経同調により、**約1シーズンで脳の言語野や記憶野が焼き切れ、戦術判断が不能（ニューラル・バーンアウト）**となる。
  任期を終えた個体は「退役病棟（実態は隔離ホスピス）」へ送られ、同じ施設で育った後輩（同期生）が次の席に着く。

### ゲーム仕様との同期
- **シーズン交代の演出（先輩から後輩へのバトン）:**
  シーズン1の主人公は、自分の脳が焼き切れる寸前、次にこの席に座るであろう後輩のために、端末の奥深くに「生き残るための裏コード」や「公文書の死者リストの矛盾」を暗号化して遺す。
  シーズン2の新主人公は、支給された端末を開き、**「……あの優秀だった先輩も、この席で壊れたのか」**と独白しながら戦いに身を投じる。

### 演出・トーン
- ドライな軍事・官僚社会の中で、**「使い捨てにされる子どもたち同士の無言の連帯と哀愁」**が前面に出る。
- 現場のオペレーター（アレクセイ等）も、最初は「生意気な若造の設計士」として接しているが、彼らが1シーズンで壊れて消えていく事実を知っており、「……おいガキ、無理して脳を焼くんじゃないぞ」という大人の痛切な眼差しが生まれる。

## 4. 両パターンの比較マトリクス

| 比較項目 | パターンA：クローン・ロット制 | パターンB：特化育成児制 |
| :--- | :--- | :--- |
| **ジャンル性** | ハードSF、サイバーパンク、無機質 | ジュブナイル・ミリタリー、群像劇、切なさ |
| **プレイヤーの感覚** | 「同じ素体が何度も死んでリスポーンする不気味さ」 | 「前任の先輩の遺志を引き継ぐバトンタッチの熱さ」 |
| **少女との対比** | **同一の檻:** どちらも「量産・冷凍される生体部品」 | **境遇の共有:** どちらも「大人に名前と自由を奪われた子ども」 |
| **メタ進行の納得感** | **極めて高い:** 脳データのフラッシュ転送で説明 | **高い:** 施設の同期・後輩へのデータ引き継ぎで説明 |
| **現場オペレーターとの関係** | オペレーターは「相手がクローンであること」を知らない（または薄気味悪がっている） | オペレーター（大人）が「子どもを前線で使い潰す罪悪感」を抱く |

## 5. ハイブリッド案（折衷案）

「パターンAのSF的冷酷さ」と「パターンBの人間的エモーション」を融合させる案：

> **【素体固定型クローン × 意識育成教育】**
> 初代の「伝説的な天才戦術児」の遺伝子から作られたクローンたち（パターンA）。
> しかし、彼らは単なる肉体ではなく、同じ養成施設で幼少期から「兄弟」として競い合わされ、1ロットずつ順番に前線へ出荷されている（パターンB）。
> 「先に逝ったロット01の兄さん」の遺した端末を、「ロット02の弟」が受け取り、同じように脳を焼かれていく。
