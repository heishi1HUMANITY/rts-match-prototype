# 05_キャラクター定義

本書は、本作のストーリー、ボイス演出、およびガチャ・LiveOps展開の中核となる主要キャラクター（戦術設計士、各組織の同期オペレーター、少女、機構幹部）の詳細プロフィール、性格、セリフ、および背景設定を定義する。

---

## 1. 主人公（プレイヤー）

### 戦術設計士（シリアルコード：ARC-Lot.XX / アーク兄弟）
**「……兄さんが座っていた席だ。僕の脳が保つのは、あと何日だろう」**

- **属性:** プレイヤーの分身。シーズンごとに世代交代するクローン少年兵（特化演算個体）。
- **身分:** IMCO直轄の極秘施設「第7育成特区（託児所）」で培養・育成された特級戦術設計士。単一の優秀な素体から生み出されたクローン兄弟であり、1シーズン（約100日）の過密演算で脳細胞が不可逆的に焼き切れ、退役・交代となる。
- **能力:** 幼少期から1日14時間の盤面シミュレーションを叩き込まれており、常人を遥かに凌駕する超絶的な空間認識能力と確率計算力を持つ。
- **物語上の特異性（端末の継承とバグ）:**
  代々のARC兄弟に受け継がれる戦術端末「TIS-Aegis」を使用する。通常は初期化されるはずのログが、少女の「紫のクレヨン痕」によって汚染され、**前任の兄たちが命を削って遺した「不自然な公文書の暗号スクラップ」が次期ロットの脳へフラッシュバックとして焼き付いてしまう**。
- **少女との関係:**
  「大人になることを奪われ、国家の道具として消費される」という点で、少女（観測体01）と完全な鏡像（合わせ鏡）の関係にある。

## 2. 初期主要オペレーター（指導者キャラクター）

### 01. アレクセイ・ヴォルコフ（Aleksei Volkov）
**「おい設計士、今日の依頼主はどこだ？ ……また知らない国の海峡か。残業代が出るなら付き合ってやるよ」**

```
・所属: アイギス・タスクフォース（ATF）
・年齢 / 性別: 38歳 / 男性
・肩書: 第3機動潜行隊・現場指揮官（元東欧連邦軍中佐）
・担当文明: ATF（民間潜行会社 / 重装甲・兵站型）
```

- **外見・ビジュアル:**
  - **現実（Version A）:** 伸びかけた無精髭に疲労の滲む鋭い目元。広い肩幅。機能性を最優先したスレートグレーのテックウェアジャケットに、レスキューオレンジの止血バンド。首元には旧軍時代の擦り切れたドッグタグ。
  - **夢境（Version B）:** 輪郭線がかすれ、軍用装甲の胸元に少女のバイオレットクレヨンで殴り書きのような上書きが施されている。
- **性格・背景:**
  皮肉屋で口は悪いが、現場の部隊や相棒（設計士）を決して見捨てない叩き上げのプロ。国家の掲げる大義を一切信用しておらず、信じるのは契約金と部下の命のみ。
  かつて自分の副官だった優秀な若手潜行者が「潜行事故（未帰還）」として植物状態にされた事件に強い疑念を抱いており、独自に機構の裏を調べている。
- **代表セリフ:**
  - *「指示を受信した。無茶を言ってくれるぜ……だが、筋は通ってる。野郎ども、前線拠点を死守しろ！」*（試合中・拠点防衛時）
  - *「ふん、勝ったか。これで依頼主の閣下方はシャンパンで乾杯、俺たちは泥水のような合成コーヒーで残業報告書だ」*（試合勝利時）
  - *「……おい設計士。さっきの第3セクター、妙な紫の線が見えなかったか？ ……気のせいならいいんだがな」*（試合後・異変察知）

### 02. 林 晨（リン・チェン / Lin Chen）
**「感情はノイズです。勝敗とは、投じた資本と因果の収束率で99.8%定義できます」**

```
・所属: ヴォストーク重工・未来戦術局（V-TAC）
・年齢 / 性別: 26歳 / 女性
・肩書: 経営戦略本部・特命潜行執行官
・担当文明: V-TAC（メガコングロマリット / 経済・ドローン量産型）
```

- **外見・ビジュアル:**
  - **現実（Version A）:** 黒髪のシャープなショートボブ、細身のシルバーフレーム眼鏡。無駄のないスノーホワイトのビジネススーツに、薄型のホログラム通信バッジ。
  - **夢境（Version B）:** ネオンシアンの幾何学バイザーを装着した純白の流線型パワードスーツ。自律ドローンが周囲を周回する。
- **性格・背景:**
  ヴォストーク・グループの最年少執行官。あらゆる紛争を「投資対効果の計算」として冷徹に処理するエリート。しかしその内面には、少女の「辻褄合わせ」によって実家の老舗中堅企業が不自然な連続リコールで倒産に追い込まれた過去を持つ。彼女が完全な合理主義を貫くのは、世界を支配する「不条理な因果の神（少女）」に二度と人生を狂わされたくないという防衛本能の裏返しである。
- **代表セリフ:**
  - *「リソースの配分を確認。設計士、あなたの建設プランは理論値通りです。生産ラインを最大出力へ移行します」*（内政展開時）
  - *「市場予測を上回る効率でした。これより調停結果を本社取締役会へ報告します。お疲れ様でした」*（試合勝利時）
  - *「なぜ……計算と合いません。あの拠点の喪失確率は0.02%だったはず。……この紫のノイズは一体何なの？」*（不可解な敗北・異変時）

### 03. 監査官ヴェラ（Inspector Vera）
**「IMCOの天秤は絶対です。調停を歪める不純物は、すべて観測ログから抹消されなければなりません」**

```
・所属: 調停執行監察隊（AEC）
・年齢 / 性別: 20代後半（戸籍記録抹消済み） / 女性
・肩書: 第1監査室・主席執行官
・担当文明: AEC（機構直属 / 電磁シールド・コントロール型）
```

- **外見・ビジュアル:**
  - **現実（Version A）:** 陶器のように色素の薄い肌、氷のような白銀のストレートロング。隙のない純白のIMCO制服軍服に白手袋。胸元には黄金の天秤徽章。
  - **夢境（Version B）:** 表情を完全に遮断する銀鏡のバイザーヘルメット、無機質で神聖な幾何学的重装甲。
- **性格・背景:**
  IMCO上層部の意向を具現化した冷酷無比なマシーンのような女性。「調停制度こそが現実の流血を止める唯一の秩序」と狂信しており、制度を脅かす違法潜行者や、少女の秘密を嗅ぎ回る者を容赦なく粛清してきた。設計士（主人公）に対しても、最初は優秀な駒として利用しつつ、その調査が核心に近づくにつれて冷徹な監視の目を光らせる。
- **代表セリフ:**
  - *「執行命令を受理。規律に従い、防壁を展開します。これ以上の領域侵犯は即時排除の対象となります」*（防壁展開時）
  - *「調停終了。判決は正しく執行されました。設計士、あなたのクリアランスを超えるログの閲覧は控えるよう警告します」*（試合終了時）

### 04. カイ（Kai）
**「お行儀のいい大人たちの戦争ごっこなんて、虫酸が走るんだよ。全部バグらせてぶっ壊してやる」**

```
・所属: 零区（Zone-0）
・年齢 / 性別: 21歳 / 男性
・肩書: フリーランス・クラッカー / 闇潜行者
・担当文明: Zone-0（違法シンジケート / 電子戦・ゲリラ型）
```

- **外見・ビジュアル:**
  - **現実（Version A）:** やせぎすな体躯、乱れたプラチナブロンド。首筋には非正規の神経端子を強引に埋め込んだ痛々しい手術痕。アシッドイエローのボロボロの特大フーディー。
  - **夢境（Version B）:** 体の輪郭が常にブロックノイズのようにグリッチしているワイヤーフレームアバター。手持ち武器は巨大なハッキング端末。
- **性格・背景:**
  皮肉と毒舌に満ちたアンチヒーロー。国家や機構の欺瞞を心底嫌悪している。金と破壊衝動だけで動いているように振る舞うが、真の目的は、かつて正規オペレーターとして潜行し「未帰還」となって昏睡状態に陥った双子の妹の意識の破片を、夢境の最深部から救い出すことである。
- **代表セリフ:**
  - *「へへっ、回線ジャック成功だ。設計士さんよ、お前が敷いた綺麗なレール、俺のやり方でメチャクチャにしてやるから見てな」*（戦闘開始時）
  - *「おい……今、霧の向こうに『あいつ』がいた。……妹のコードだ。間違いない、まだ生きてやがる！」*（深層探索時）

## 3. 世界の核心

### 観測体01（少女）
**「……また、私のところで戦争をするの？ ……いいよ。結末を決めて。……辻褄は、私が合わせてあげるから」**

- **肉体実態:** 24歳前後（推定）。IMCO中央地下クリーンルームで生命維持装置に接続され、十数年間昏睡。
- **夢境の姿:** 10歳前後の少女。薄青い療養施設のスモックに、大人用の擦り切れたトレンチコート。手にはバイオレットのクレヨン。
- **人物像:**
  喜怒哀楽の感情が極限まで希薄化している。かつて自分を道具として扱い、身柄を奪い合い、薬物で無理やり眠らせた大人たちを深く憎悪しているが、その憎しみはヒステリックなものではなく、**「凍りついた絶対零度の静かな報復」**として現れる。
  プレイヤー（設計士）を「自分を道具として使う数多の人間の一人」として観察しつつ、やがて設計士が世界の歪みに気づいたとき、夢の最深部で直接接触を図ってくる。
