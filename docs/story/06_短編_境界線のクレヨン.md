# 06_短編小説：境界線のクレヨン

---

### CASE NO: 4092-B
**調停事案：ヴェルナ海峡通航権および関連沿岸インフラの管轄権**
**依頼主：北岸自由連邦政府**
**指定代理組織：アイギス・タスクフォース（ATF）第3機動潜行隊**
**担当戦術設計士：ID: ARC-Lot.01（第7育成特区 / クリアランス：Class-S）**
**担当同期オペレーター：アレクセイ・ヴォルコフ中佐（契約潜行者）**

---

### 1. 深度3の日常

「……バイタル安定。神経同調率、八十二パーセント。おい設計士、聞こえてるか」

冷たいホログラム作戦卓の左端、黒いベゼルに縁取られた通信ウィンドウに、男のバストアップが投影された。
画面の向こうのアレクセイ・ヴォルコフは、顎の無精髭を乱暴に撫で回しながら、不機嫌そうに合成タバコをくわえていた。彼の首元で、擦り切れた旧軍時代のドッグタグが鈍く光っている。

「クリアに聞こえている、アレクセイ。接続状態は良好だ」

「相変わらず、耳が痛くなるほど若い声だな」
アレクセイは煙を吐き出しながら目を細めた。
「首筋の冷却端子の調子はどうだ？ ガキの頭にはちと重すぎる仕事だと思うがね」

「問題ない。アルプスを出てから今日で四十二日目だ。規定の稼働寿命までは、まだ時間がある」

「……四十二日、ねえ。チッ、つまらん冗談を言うな。で、今日の依頼主はどこのどなた様だ？」

「北岸自由連邦。係争案件はヴェルナ海峡の通航権だ。相手は南岸共和国側に割り当てられたヴォストーク（V-TAC）、それと調停監視名目で介入してきた機構直属（AEC）の三つ巴だ」

「ヴェルナ海峡ねえ……」
アレクセイは小さく鼻を鳴らした。通信の背後から、重装甲車両のアイドリング音と、金属が擦れ合う無骨な機械音が漏れ聞こえてくる。

「また地図のどこにあるかも知らん国の、泥水みたいな海峡か。他人の国境線のために頭痛薬を飲む生活にも飽き飽きしてきたが……まあいい。勝てばボーナスが出る。設計図を降ろしてくれ、設計士。定時までに終わらせようぜ」

設計士は無言で指先を動かした。
清潔なマットホワイトの作戦卓の上に、無数の幾何学ブロックが音もなく展開していく。
製図用紙のような白い余白――まだ誰も観測していない未確定因果の霧（Fog）の向こうに、青白い光を放つ送電塔と、海峡を跨ぐ巨大な水門施設が抽象化された立体模型として浮かび上がった。

試合開始のカウントダウンがゼロを示した。

### 2. 幾何学の戦場

「第1小隊、セクター02の送電ハブへ前進。第2小隊は補給線のアンカーを打て。設計士、資源の配分はどうなってる？」

「順調だ。ヴォストークの林晨（リン・チェン）が北側の鉱区へドローンを先行させているが、足が速いぶん装甲が薄い。中央ルートから圧力をかければ、相手の生産ラインは止まる」

「了解だ。おい野郎ども、無人機なんぞにビビるな！ キャタピラで踏み潰してやれ！」

アレクセイの咆哮とともに、スレートグレーに塗られたATFの装甲車両が、未観測の霧を切り裂いて突進していく。
部隊が損耗し、拠点を奪われるたびに、作戦卓の端に本国政府からの警告ログが雪崩のように積み上がっていく。
『第4兵站区の補給物資、払底寸前』『本国議会にて緊急安保委員会が招集――反戦デモ激化につき即時撤退要求が過半数に迫る』
夢の中での敗北の足音は、血の匂いではなく、国家財政と民意が音を立ててすり減っていく冷たいシステム警告として突きつけられていた。

試合開始から十八分。
戦況は泥沼の膠着に陥っていた。
南岸側のヴォストークは無人機の大群で中央水門の西岸を固め、中立を装う機構直属（AEC）の監査官ヴェラは、冷酷な電磁シールドで両陣営の通信を妨害しながら機を窺っている。

「……クソが、本国の国防省から通信だ！」
アレクセイの通信ウィンドウに激しいノイズが走る。彼の側頭部に貼り付けられた神経端子が赤く点滅し、疲労の色が濃い顔を歪めた。
「『これ以上部隊をすり減らしたら本国が持たない、議会が白旗を上げる寸前だ』と喚き散らしてやがる！ 南岸の重砲も止まらねえ。設計士、何か手はないのか！？」

「待て、アレクセイ。水門のバイパス回路の解析がもうすぐ終わる。そこを押さえれば――」

その時だった。

### 3. 紫の侵蝕

*――ピシッ。*

ガラスに爪を立てたような、耳障りな甲高い軋み音が管制室に響いた。
ホログラム作戦卓の端、完璧な直線でレンダリングされていたはずの中央水門模型の上に、**異常なノイズ**が走った。

「……なんだこれ？」

それは、デジタルなバグではなかった。
ベクターデータでも、テクスチャのエラーでもない。
紙の上に固い芯を力任せに擦り付けたような、筆圧のムラと微細な顔料の粉を散らした、生々しい**「手描きの線」**。

鮮烈で、凍りつくような、一本の紫（バイオレット）のクレヨン線。

その線は、水門の防衛ラインを乱暴に横断し、敵陣営の後方に位置する無名の通信中継所を、黒々とした『×印』で塗り潰していた。

「おい、設計士！ 通信機の座標データが勝手に書き換わったぞ！？」
アレクセイの叫びで作戦卓に意識が引き戻される。
「第3小隊の自動進軍ルートが曲がった！ なんだこの進路は……水門を無視して、裏の岩礁地帯に突っ込んでる！」

「アレクセイ、止めるな！」
設計士は直感的に叫んでいた。理由は分からなかった。だが、その紫の線が描かれた場所には、抗いがたい因果の絶対的な「重力」が宿っていた。
「全隊、第3小隊のルートに追従させろ！ 総攻撃だ！」

「冗談だろ、そんな死地に――チッ、どうにでもなりやがれ！」

ATFの全装甲車両が、少女のクレヨンが引いた歪な紫の軌跡に沿って突進した。
次の瞬間、信じられない事象が発生した。
南岸陣営の後方で、突如として大規模な弾薬誘爆の光柱が上がったのだ。ヴォストークの無人機ネットワークが一斉にリンクを喪失し、無防備になった中央水門の管制権が、雪崩を打つように北岸側の色へと塗り替わっていく。

南岸軍の全通信回線から、悲鳴のような『即時停戦・全軍撤収コード』がブロードキャストされた。補給線と司令部を同時に断たれ、継戦能力を完全に喪失した敵部隊が、白く輪郭を崩しながら雪崩を打って瓦解していく。

```
［CASE NO: 4092-B ―― 調停完了］
［判定：ヴェルナ海峡通航権は『北岸自由連邦』へ帰属］
［調停時間：23分42秒 / 勝者：アイギス・タスクフォース］
```

無機質なシステム音声が鳴り響き、盤面全体が白いノイズへと還元されていく。

「……は、ははっ。勝っちまったぞ」
通信ウィンドウの向こうで、アレクセイがシートに深く背中を預け、荒い息を吐いた。
「おい設計士……今の爆発は何だったんだ？ 敵の弾薬庫のデータなんて、お前の作戦図には載ってなかったはずだぞ」

設計士は答えられなかった。
消えゆくホログラムの残光の中、先ほどまで紫の線が引かれていた座標の空間に、**誰かが立っていた**ように見えたからだ。

簡素な薄青い療養着。大きすぎる大人のトレンチコート。
そして、冷たく感情のない目でこちらを見つめる、10歳ほどの少女の幻影。
彼女は手に持ったクレヨンを懐に収めると、霧が晴れるようにスッと消え去った。

### 4. 三日後の公文書

調停戦の終了から三日後。
現実世界のスイス中立特区、設計士の個人端末に、IMCO事務総局から一通の暗号化公文書が届いた。

```text
======================================================================
【国際夢境調停機構（IMCO）公式判決執行報告書】
CASE NO: 4092-B / ヴェルナ海峡事案

主文：
本案件に関する夢境調停の結果に基づき、海峡の管轄権は北岸自由連邦へ
移管された。これに対し、南岸共和国政府は本日未明、海峡沿岸からの
全軍撤退を正式に表明した。

［現実収束事由の概要］
調停終了の翌日、南岸共和国軍の最高実力者であるマティアス・ブラント
退役大将（71）の搭乗する自家用ヘリコプターが、海峡上空において
原因不明のテールローター故障を起こし墜落。同氏は即死した。
ブラント大将の急死に伴い、同氏が主導していた強硬派閥が瓦解。議会に
おける対立激化および海峡防衛予算の否決を受け、南岸政府は紛争の
継続が不可能であると判断、撤退条約の締結に至った。
======================================================================
```

冷徹な官僚機構の文章を、設計士は息を詰めてスクロールした。
「マティアス・ブラント退役大将」。
その名に見覚えがあった。十数年前、ある東欧の小国で「予知夢を見る少女」が発見された際、その身柄を療養施設から強奪する極秘軍事作戦を指揮した、当時の特殊作戦群司令官の名だ。

夢の中の勝敗は、確かにフェアに決まった。
だが――彼女は、自らの手で「結末へ至る道筋」を選び取ったのだ。
かつて自分を檻に閉じ込めた男の首を、三日後の空の上で、静かにへし折るという道筋を。

端末の画面を閉じようとした設計士の手が止まった。
電子公文書の最下部、機構事務総局のデジタル公印が押された余白の片隅。

高解像度のディスプレイの上に、かすかな汚れのような、指先大の小さな紫色の染みが残されていた。
拡大すると、それはクレヨンで描かれた、**折れた一本の銃の落書き**だった。

冷え切った管制室の中に、空調の低い唸り声だけが響いていた。
首筋の冷却端子がじくじくと熱を持ち、側頭部を鋭い頭痛が刺し貫く。残された稼働可能時間は、おそらくあと五十日も保たないだろう。

ARC-Lot.01は震える指先で、端末「TIS-Aegis」の深層ローカルパーティションを呼び出した。
初期化プロトコルを欺くための独自暗号を走らせ、次のシーズンにこの席に座るであろう「弟」へ向けて、短いメモを打ち込む。

*――もし僕の脳が焼き切れた後、この端末を受け取るロットがいるなら。*
*公文書の数字を信じるな。敵と味方の境界を疑え。*
*彼女は――泣いているんじゃない。*

エンターキーを押すと、暗号ログは紫の染みの奥深くへと沈み込み、画面は何事もなかったかのようにマットホワイトの待機状態へと戻った。
