# 協議サマリー

## 目的

プレイヤーが使える人物と、物語上必要なNPCを分離し、スマートフォンゲームのキャラクターデザインに使える厚みのあるペルソナを設計する。プレイアブル人数は十分な規模とし、男性:女性を約2:8にする。既存の世界観資料は変更せず、資料12も正史へ統合しない。

## Codexが作成した設計案

- プレイアブル初期選択プールを20名（男性4名・女性16名）とした。女性は全員18〜29歳。
- 20名は複数のCASEや契約時期を横断する選択プールであり、一つのCASEへ同時に全員が出撃する設定ではない。
- 6勢力の内訳はATF 4、V-TAC 4、AEC 3、Therapia 3、Noct-Observers 3、Zone-0 3。
- 各人物に外見・シルエット・現実/夢境の衣装、仕事日の生活、趣味、思想、内的矛盾、戦術役割、物語フック、口調の軸を付与。人物同士の関係フックも7グループで整理した。
- 少女、ARC、審判官、機構幹部、ブラント、療養中の人物は物語NPCとして数から除外。
- 個人の超能力や専用同期機構を増やさず、各組織の技術・訓練・装備で戦術差を表現。AECの参加条件、Therapiaのデータ制限、Noctの解釈と通信の区別、Zone-0の違法侵入リスクを維持。

## 協業の実行結果

Gemini（agy）へ独立レビューを一度依頼したが、JSON応答に実質的な本文がなく、`denied_actions` に `RunCommand` が記録された。CLI上の `SUCCESS` 表示はあっても、作業フローが定める失敗条件に該当するため、Geminiのレビューは未実施とした。権限回避や同一操作の再試行は行っていない。

そのため、CodexとGeminiの議論・二者合意・共同承認は成立していない。Codex側の自己レビューと懸念点は `03_issue-register.md` および `04_codex-self-review-r01.md` に記録した。提案の内容は `final-proposal.md` と `01_codex-independent.md` に残したが、ステータスはCodex単独の条件付き提案である。
