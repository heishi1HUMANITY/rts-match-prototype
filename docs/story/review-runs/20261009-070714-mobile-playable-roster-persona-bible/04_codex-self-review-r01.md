# Codex自己レビュー Round 1

**対象:** `01_codex-independent.md` の20人プレイアブル案。既存設定資料は変更していない。

## 結論

20人（男性4・女性16）は、プレイ可能な選択プールの設計目標として十分な量があり、ユーザー指定の男女比に一致する。各人物に生活、余暇、思想、弱点、外見と戦術を持たせた。希少適性者の問題は「全員が同時に一つのCASEへ出る名簿」ではなく、別々のCASE/契約にまたがる選択可能プールであると明記した。

ただし、Geminiによる独立確認は成立していない。したがって本案は**Codexの条件付き設計提案であり、CodexとGeminiの合意案ではない**。共同レビューの受け入れ条件は満たさず、正史へ統合できる状態ではない。

## 残る制作上の注意

- 20名全員が同じ物語章に参加する演出を避け、CASEの依頼・契約・適性・組織の承認によって登場を分ける。
- 20名は設計プールとして妥当だが、初回配信日に全員を実装するかは運営/制作計画の問題で、世界観からは決められない。
- 各人のプロフィールは作画・ボイス企画の土台になる。最終アート発注では立ち絵・戦闘SDのシルエットテスト、ボイス台詞、相関イベント、スキン差分を別途作る必要がある。
- 一部の趣味は職能に近いため、親密度イベントでは仕事以外の人間関係・選択・休息を描く。
- 20人のスキル数値・レアリティ・排出率・実装順は未設計。
