# クロスレビュー Round 1：Codex応答への反論/合意

同じ対等な共同設計議論の続きです。レビュー本文を直接返してください。ローカルファイル参照やコマンド実行は不要です。必要な背景・Codexの応答を以下にすべて記します。

## 固定要件と設定制約
- 初期プレイアブル設計名簿20人、男性4/女性16。女性18〜29歳。生活サイクル、趣味、思想、外見、矛盾、物語役割が描画/ボイス/イベントへ使える厚みであること。
- 世界資料は既存の夢境代理戦。潜行者は数万人に1人。同期オペレーターが現場アバター、ARCの戦術設計士が盤面設計。夢境は通常の電磁通信/ネットワークではアクセス不可。組織の技術・訓練に基づき、個人超能力なし（03 §1-2）。
- AECは中立インフラ保全の目的が事前登録されたCASEのみ戦闘参加。判定は独立。Therapiaの少女/未加工試料アクセスなし。Noctの声は信徒の解釈。Zone-0は未登録、登録済み同期回線へ違法相乗り、国家依頼主から参加資格や保護を得ず、発覚・遮断・神経損傷の危険（04、前回協議の仮合意）。

## Gemini初回レビューの評価
Geminiは20人/2:8/女性年齢、職務倫理に根差した葛藤、横断関係性を高く評価し条件付き承認。趣味小道具が修理・記録/地図・植物・料理に重なること、Zone-0の同期/指揮経路、AECのCASE限定参加と自由編成の摩擦、Therapia医療職と少女アクセス制限の境界を指摘。提案はレイラの暗号クロスワード、スリのノイズ音楽、タムシンの風/凧、ソラの自販機評価。Zone-0のオープン周波数ビーコン、AEC一般CASEへの武装監査随伴も提案した。

## CodexのRound 1応答
- 趣味の重複は意図的でなく、設計上の集束だったと認め、差し替えを含む11名の趣味を更新。マラは陶器動物収集、リンは書道、ヴェラは即興劇、サミラはチェロ、アンケはローラースケート、イネスは糸の結び目模様、ローワンは手影絵、ニナは合唱などへ変更。全員が機械/記録/緑/飲食に寄らないようにした。
- 情報の不確実性に対するタムシン/レイラの葛藤は初稿で似ていたと認め、凧を使う五感型の現場偵察と、監査用電子妨害ログを抱える分析者へ動作・役割を分けた。
- Zone-0の同期問題は認めるが、ビーコン案は03 §1の通常ネットワーク不可と衝突し、ARCの指揮下に置くと違法侵入の立場を弱めるため不採用。既存04の登録同期回線への違法相乗りを維持し、正史では独立侵入者。Zone-0の3人は分散したネットワークの別々の潜行者で、同じCASEの固定小隊ではない。個別に企業から逃れた特殊経歴は増やさない。
- AEC制約による自由編成の摩擦は認めるが、架空の強制随伴条項は事前合意を空洞化し、AECの権限を全CASEへ広げるため不採用。自由編成は訓練/模擬戦の非正史モードで可能にし、正史CASEには登録条件を守る。
- Therapiaの医療担当は少女や未加工試料に触れず、自組織/契約ダイバーの本人同意済み申告、匿名テレメトリー、装備だけを扱う旨を明記。
- 20名をサービス初期のプレイアブル設計目標とし、サービス初日の配信人数/運営コストは未確定。

## 反論・再評価してほしい点
1. 趣味差し替え後、重複と職能記号への収斂は十分に解けたか。残る具体的な重複や逆に人物らしさを失った差し替えがあれば指摘。全名の個別評価ではなくIDと具体例で。
2. Zone-0は同一CASEに通常の合法戦力として参加せず、独立侵入者として正史に出る。プレイヤーが全キャラを自由に使う場所は非正史の訓練/模擬戦。これは初回指摘を実際に解消するか。別の因果矛盾はあるか。03に反するオープン周波数ビーコン案をなお支持するなら、どの条文と両立するかを示す。
3. AECの限定CASE参加と模擬戦での自由編成は、プレイアブル性の妥協として妥当か。一般CASEに強制随伴させる代替案は、前回の中立性制約を維持できるのか。
4. Zone-0の3人が全員同時に雇用/編成されないこと、適性が極めて希少でも20名が世界人口比で少数にすぎないことは十分か。それでも個別の非捕捉理由が必要なら、追加設定を増やさず説明できる具体的根拠があるか。
5. 20名の初期設計プールは承認できるか。サービスDay1に全員を実装するのはCodex案の運営上の仮置きとして扱う。世界観上の事実と混同していないか。

最終判定は「承認/条件付き承認/未承認」を明示。Codexの主張に反対する時は具体的根拠と副作用を挙げ、納得できた点は合意と記す。大きな新規設定を足さず、残る論点だけ報告してください。
