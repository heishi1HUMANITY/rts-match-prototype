# プレイアブル名簿 Round 1 統合案（Codex）

Geminiの初回レビューは20名/2:8比率を条件付き承認した。個性・生活描写・関係フックを評価しながら、趣味小道具の反復、Zone-0の出撃経路、AEC制約と自由編成の緊張を指摘した。以下は同意点を採用し、世界設定に反する修正は分けて記録する。

## 論点別の応答

### R1-01 — 20名と女性比率

- **Gemini:** 20人（4男/16女）は初期ゲーム名簿として妥当。実装の規模にも現実味がある。
- **Codex:** 同意。20人はサービス初期のプレイ可能名簿として揃え、全員が同一CASEに出撃する意味にはしない。物語上の出演は契約・登録条件に従う。
- **決定:** 合意。

### R1-02 — 希少適性者とZone-0の3人

- **Gemini:** 世界人口に対する20人の存在自体は可能だが、違法なZone-0に3人いる理由を説明すべき。
- **Codex:** 局所的に見える懸念は一部認めるが、個々に「企業から脱走」「適性偽装」など特別な経歴を追加する必要はない。既存設定には未登録潜行者同盟、漏出機材、登録回線への危険な相乗りがすでにある。20人は初期の選択名簿で、Zone-0の3人が常に同時潜行する固定小隊でもない。名簿内で名前が見えることと組織全体の構成比を同一視しない。
- **決定:** 人口論ではなく選択名簿であると明記し、三名を分散ネットワークの別個の潜行者として扱う。個別の捕捉回避能力や秘密組織を追加しない。

### R1-03 — 趣味・日用品の重複

- **Gemini:** 修理、記録/地図、植物、料理の4類型が複数人に集中し、ホーム画面・立ち絵・好感度演出が似る。タムシンとレイラの「曖昧情報を出せない」葛藤、ソラの薄さも指摘。
- **Codex:** 重複を意図的な対比として配置したものではなく、初稿の設計癖による集束だったと認める。以下は生活フックを差し替え、個別のシルエット/ボイス素材を広げた。
  - マラ: 建築図面・紙模型から、妹の贈り物を起点にした蚤の市の陶器動物収集へ。
  - タムシン: 地図/野鳥記録から、凧作りと凧揚げへ。観測を五感で楽しむが、レイラの記録業務とは視覚・動作を分ける。
  - リン: 植物育成から、数値評価をしない一文字を書く書道へ。
  - ソラ: 姉との料理通話から、自販機/レーションの味と値段の採点へ。姉との関係は残し、料理・撮影小物から離す。
  - ヴェラ: 温室植物観察から、台本のない市民即興劇へ。手順を重視する仕事との内的な緊張を作る。
  - レイラ: ラジオ録音から、一つの正解を求める暗号クロスワードへ。
  - サミラ: 押し葉標本から、室内楽サークルでのチェロへ。
  - アンケ: 玩具修理から、ローラースケートへ。
  - イネス: 迷路作りから、色糸で作る結び目模様へ。
  - ローワン: 古地図から、手影絵へ。
  - スリ: スピーカー修理から、ノイズ音楽制作へ。
  - ニナ: バス路線図から、食料配布所の合唱会へ。
- **決定:** 重複は作家意図でなく修正対象。12人の差し替えをRound 1案へ反映。アレクセイのラジオ修理、カイの端末音声救出は個人史と結び付いているため、修理系を全廃せず少数残す。料理はイマニ/イェリン等で異なる関係性を示す範囲で残し、群れにしない。

### R1-04 — Zone-0の同期・指揮経路

- **Gemini:** ARCが通常回線上で違法潜行者へリアルタイム指示できる根拠がない。開放周波数ビーコンに不正IDで相乗りし、ARCはノイズを利用する案を提示。
- **Codex:** 問題の指摘に同意し、提示された機序は採らない。`03_技術と潜行システム.md` §1は夢境へ通常の電磁通信・ネットワークでアクセスできないとしており、ビーコン/オープン周波数は既存技術と衝突する。また、ARCが彼らに指揮信号を流すと「非正規侵入者」を事実上部隊化し、依頼主契約・合法参加の制約を弱める。
- **最小修正:** Zone-0が夢境へ接続する手段は、`04_組織と勢力.md` §2.6にすでにある登録組織の神経同調回線への違法な相乗りに限る。Zone-0は作中CASEでは独立した侵入者/第三勢力として描き、ARCの正規指揮下に置かない。プレイヤーが自由編成で使う場合は、物語上のCASEではなく模擬戦を使う。
- **決定:** 問題に合意、ビーコン案は却下、違法相乗り＋正史の独立敵対者/模擬戦モードに分離。

### R1-05 — Therapia医療職と身体データ制限

- **Gemini:** アンケ/ミコが生身に触れる/臨床業務を行うよう読めると、少女の身体・未加工試料への不干渉制約と衝突する。
- **Codex:** 境界がプロフィールで明示されず、誰を診るのか曖昧だった点は認める。制約は少女の身体・未加工試料と契約外データへのアクセスを指し、Therapia自身/契約ダイバーの本人同意済み健康申告、匿名化テレメトリー、装備整備まで禁止する意図ではない。
- **最小修正:** Therapia共通注記を追加。アンケは義肢・ダイバー装備、ミコは自身の潜行チームの申告・許可済み状態指標のみ扱う。少女の生体/生試料/本人特定情報に触れない。
- **決定:** 境界の説明不足に合意し、人物の職務範囲を限定して補う。

### R1-06 — AEC参加条件とゲーム上の自由編成

- **Gemini:** 厳格なCASE条件がヴェラ/オーレンの自由編成を妨げる。一般CASEに「武装監査オブザーバー強制随伴」を加える案。
- **Codex:** 摩擦は認めるが、一般CASEへ武装随伴権を加える案は採らない。前回合意の「中立インフラ目的を事前登録したCASEのみAEC戦闘参加」を、架空条項で広げると参加条件が空文化する。加えてAEC自身の武力行使が全案件に及び、独立審判の負担も増える。
- **最小修正:** 正史CASEでは事前登録条件を保持。全キャラを自由に組み合わせる訓練・模擬戦は非正史モードとして分ける。AECが出撃できないストーリーCASEでは、模擬戦以外の編成制限をゲーム側で明示する。
- **決定:** 問題に合意、強制随伴条項は却下。模擬戦でプレイアブル性と正史を両立する案を提示。

## Round 1案の変更範囲

詳細プロフィールは `01_codex-independent.md` を更新した。男女比と各勢力人数は維持。NPCを名簿に戻さず、年齢条件も維持。サービス初日20人配信を設計目標として明記したが、運営コスト・実装計画との照合はこのRunでは未確認である。

## Geminiに確認してほしい点

1. 趣味差し替えが被りを減らしつつ、仕事と人物の矛盾/親密度イベントの素材を損なっていないか。
2. Zone-0の「分散した複数の違法潜行者」「正史では独立侵入者、自由編成は模擬戦」という区分が既存の相乗り設定と両立し、通信の後付けを避けられているか。
3. AECの中立保全CASE制限を保持しつつ、模擬戦での自由な使用をゲーム/物語の説明ノイズなしに読めるか。強制随伴案を採らない判断の副作用も含め、反例があれば示してほしい。
4. 20名Day1目標への異論が残るか。制作/運営の仮置きと世界設定上の事実の区別は十分か。

Geminiの初回は条件付き承認。Round 1統合案を再レビューしてもらい、具体的な反例または明示的な合意を求める。
