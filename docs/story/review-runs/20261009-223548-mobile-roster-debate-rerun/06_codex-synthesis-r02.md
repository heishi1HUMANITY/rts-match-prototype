# プレイアブル名簿 Round 2 最終調整（Codex）

GeminiのRound 1は、Codexが示した20人プール、正史CASEと模擬戦の区分、通信制約、AEC参加条件、趣味の再配置を正式承認した。残るのは演出上の小さな提案とZone-0の背景根拠の扱いである。

## 採用する微調整

- **ヴェラ:** 即興劇の演者ではなく、市民小劇場の照明・舞台転換を担う。監査官として自分が舞台上に出ず、他人の演技と予定外の出来事を裏方から処理する活動に変更した。即興劇が浮くというGeminiの懸念を採用し、仮面修復やチェスより新しい小道具・仮面象徴を持ち込まない案を選んだ。
- **ニナ:** 一般的な合唱サークルから、食料配布所の手伝いの終わりに地域の年長者が教える労働歌を皆で短く歌う活動へ具体化した。非合法生活の人物にも日常の共同体と安全な時間があるという温度は残す。歌は隠し通信や新能力ではなく、生活習慣である。

## 保留/不採用とした追加設定

- Geminiは、Zone-0の3人が企業のスクリーニング網から逃れる理由として、無戸籍/未登録住民は適性検査対象外、ジャンク機材から適性が偶然覚醒するという説明を提案した。
- **この説明は今回の案では採用しない。** 現行資料はスクリーニング対象が市民ID保有者に限られるとは定めておらず、機材が潜行適性を覚醒させるとも定めていない。既存の「未登録者同盟」「漏出機材」「回線への相乗り」で違法潜行者が存在することは説明できる。20人の名簿は世界人口や組織構成の悉皆調査ではなく、Zone-0の3人は同一CASEに常時そろう固定小隊でもないため、個人ごとの非捕捉由来を追加しない。
- もし今後「なぜ捕捉されなかったか」を個別の物語フックにするなら、各人の選択・契約歴に沿って別途決める。未登録者は全員無戸籍という一般ルールにはしない。
