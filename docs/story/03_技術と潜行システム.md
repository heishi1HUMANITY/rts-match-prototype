# 03_技術と潜行システム

本書は、夢境への介入を可能にする科学技術「神経同調（Synchro-Drive）」、現場における職能分担、および4Xストラテジーのゲーム仕様が世界観の中でどのように機能しているかを定義する。

## 1. 神経同調技術（Synchro-Drive）

少女の夢境は、通常の電磁通信やネットワークではアクセスできない。
IMCOと各組織は、生体神経パルスを量子変換して彼女の意識周波数に共鳴させる**「神経同調システム（Synchro-Drive System）」**を用いて戦場へ介入する。

### 1.1 潜行の2大職能：設計士とオペレーター
夢境での戦争は、単独の人間では成立しない。構造を構築する「頭脳」と、現場に命を吹き込む「心臓」の2名体制が不可欠である。

| 職能 | 作中名称 | 役割と立ち位置 | 精神的・身体的リスク |
| :--- | :--- | :--- | :--- |
| **プレイヤー** | **戦術設計士<br>（Tactical Architect / ARC-Lot.XX）** | 盤面を上空から見下ろす特化演算クローン少年兵。IMCO第7育成特区（託児所）が管理する**「公的貸与資産（規格化された戦術知性）」**として、案件ごとに各組織へ貸与・派遣される。どのインフラを建設し、どの技術を解放し、どの拠点を狙うかを決定する。 | 高次演算の過密負荷により、**約1シーズン（約100日）で大脳新皮質が不可逆的に焼き切れ（ニューラル・バーンアウト）**、強制退役・隔離病棟送りとなる。 |
| **指導者** | **同期オペレーター<br>（Sync-Operator / ダイバー）** | 組織に正社員または長期契約として所属するプロの潜行者。夢境の地上に実体化し、部隊の指揮・士気統率・現場判断を担う。通信コンソールを通じて設計士と常時会話する。 | 現場部隊の損耗や砲撃のショックが神経痛として逆流する。最深部での「未帰還（ブレインデス）」リスクを直接背負う。 |

> **【現場オペレーターの独白（ボイス案）】**
> 「……接続完了。バイタル安定、深度3。設計士、今日の依頼主はどこだ？ なになに、極東の漁業権争い？ はぁ、また知らない国の海のために死にに行くのか。まあいい、残業代が出るなら付き合うさ。設計図を頼むぜ」

## 2. 4Xゲーム仕様と世界観の完全同期

ゲーム内で発生するあらゆるシステムやルールは、すべて作中の物理・心理現象として必然的な理由を持っている。

| ゲーム仕様 | 作中での名称・実態 | 世界観上の必然性と背景 |
| :--- | :--- | :--- |
| **文明（Faction）** | **所属組織の技術ライブラリ** | 使用する部隊や建物の特性。これはプレイヤー個人の能力ではなく、契約した組織が保有する「夢境展開用モジュール」の規格差である。 |
| **文明研究（メタ育成）** | **クリアランス（信用承認度）** | 同じ組織の案件をこなすほど組織内での信用が上がり、より秘匿性の高い兵器・建物の設計図（永続アドオン）が解禁される。 |
| **永続アドオン** | **秘匿戦術プロトコル** | 組織が保有する特許技術や機密設計図。設計士のライセンス端末に同期して夢境へ持ち込まれる。 |
| **使い切りアドオン** | **現実での根回し・買収物資** | 依頼主国家が現実で用意した「裏工作」。現地の反乱勢力への裏金、事前偵察衛星データなどを意識パケットとして夢境に持ち込む。1試合で消費される。 |
| **毎試合ゼロから** | **因果の初期化** | 案件（CASE）ごとに戦場となる地域も歴史的文脈も異なるため、前回の資材や兵器を使い回すことは原理的に不可能。 |
| **索敵の霧（Fog）** | **未確定因果領域** | まだ誰も観測していない空間。未来が確定していないため、白い製図用紙の余白のように霞んでいる。部隊が進軍して「観測」することで因果が固定化される。 |
| **制圧拠点** | **現実インフラの概念核** | 現実に存在する発電所、水道橋、通信アンテナ、鉱山などの戦略拠点が、少女の認識を通して幾何学模型として具現化したもの。押さえることで現実の物資流通を夢の中で模倣できる。 |
| **研究資源** | **係争拠点の解析データ** | 先進技術を展開するための資源は自拠点では手に入らず、危険な中央の係争拠点を制圧して初めて抽出できる。 |
| **中央の大拠点** | **紛争の特異点（特級係争地）** | 海峡の制海権、首都防衛インフラ、巨大水門など、その戦争の勝敗を決定づける象徴的空間。 |
| **チケット制（陣営HP）** | **国家継戦能力指数（Capacity / 継戦限界）** | 単なる軍事力ではなく、依頼主国家の「民意・財政・補給能力」の残量。拠点を奪われて封鎖されると、国家の継戦意志が急速に削られていく。（※作中・ストーリー上ではゲーム用語「チケット」は使用せず、「継戦限界」「継戦リソース」「作戦余力」と呼称する） |
| **部隊損失でチケット減少** | **命の重みと民意の損耗** | 夢の中で失われた兵士は現実では死なない。しかし、「何千人もの若者が戦場で失われる未来のビジョン」を観測した本国の民意は激しく動揺し、戦争継続に反対するようになる。 |
| **チケット0で敗北** | **継戦能力の喪失（降伏）** | 国家が戦争を継続できない未来が確定した瞬間。現実世界でも数日以内に停戦命令が出される。 |
| **時間切れ判定** | **強制休戦協定（停戦）** | 国際調停の規定時間が切れた状態。その瞬間の優劣・占有率に基づいて講和条件が冷酷に決定される。 |
| **NPC / 第4勢力** | **現地武装ゲリラ / 違法侵入者** | 依頼主国家に従わない現地の反乱分子、あるいは未来のインサイダー情報を狙って闇回線から侵入してきた違法組織。放置すれば全陣営の拠点が荒らされるため、一時的な休戦・共闘の理由となる。 |

## 3. なぜ戦術設計士（プレイヤー）は消されないのか？

少女が加害に気づいたオペレーターを次々と「未帰還」にする中で、なぜ主人公である戦術設計士（ARC-Lot.XX）は排除されないのか。作中ではこの理由が、少女との残酷な共鳴として描かれる。

1. **技術的理由（接地していない）：**
   オペレーターは地上に肉体を模したアバターを置いているため、少女の手描き線による直接的な神経侵蝕を受ける。対して設計士は、はるか上空の作戦卓から幾何学コードを介して接続しているため、少女の手描き線の直接衝撃（即時脳死）を受けにくい。
2. **冷酷な現実（消す価値がない）：**
   少女から見れば、戦術設計士は**「放っておいても1シーズン（約100日）で自らの過密演算によって脳を焼き切られ、勝手に死んでいく使い捨ての少年」**にすぎない。わざわざ自身の貴重な因果の力（喀血と激痛を伴う）を使ってまで排除する価値がない。
3. **生贄同士の鏡像哀切（同じ檻の同胞）：**
   大人たちに幼少期から自由を奪われ、国家の都合で命をすり減らされているARC少年兵たちの姿は、十数年眠らされ続ける少女自身の姿そのものである。少女は目の前の作戦卓に座る少年に対して、憎悪ではなく**「同じ檻の中にいる生贄の子どもに対する、痛切な哀悼」**を抱いている。
