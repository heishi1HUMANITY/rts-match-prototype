# 04_組織と勢力

本書は、夢境代理戦において国家から戦争を委託される「組織（文明）」の3層構造（合法・グレー・違法）、および初期展開における6大主要組織のバックボーン、理念、戦術思想、デザイン規定を定義する。

---

## 1. 組織の3層構造

潜行組織は、IMCOとの関係性および法的位置づけによって3つの層に分類される。
ゲームバランス上、どの層の組織も基本性能は公平に揃えられており、違いは「ビジュアル」「思想」「戦術特性（プレイスタイル）」にある。

```
［合法層 (Legal)］ ───── 機構に正式登録し、国選割り当てと国際法を厳格に遵守する組織
       │
［グレー層 (Gray)］ ──── 表向きは登録組織だが、裏で違法契約や独自の禁忌目的を持つ組織
       │
［違法層 (Illegal)］ ─── 未登録。流出機材や「相乗りハッキング」で夢境へ不法侵入する組織
```

## 2. 初期6大主要組織

### 01. アイギス・タスクフォース（Aegis Task Force / ATF）
**「他人の引いた国境線のために、今日も残業手当を稼ぐ」**

```
・所属層: 合法
・組織種別: 民間潜行会社（PMC）
・シンボルカラー: スレートグレー × レスキューオレンジ
・本拠地: 旧東欧中立地帯・第4セクター
```

- **組織概要:**
  退役軍人や正規軍の生き残りが設立した実力派PMC。IMCOからの割り当て案件を堅実にこなす「現場の労働者集団」。高額な大型案件をこなして給与と機材維持費を稼ぐことを至上命題とする。
- **戦術思想（プレイスタイル）:**
  **【重装甲・兵站維持・火力制圧】**
  突出した奇抜さはないが、部隊の耐久力が高く、補給線が維持されている限り前線基地が絶対に崩れない。正面突破と拠点防衛を得意とする王道スタイル。
- **ビジュアル規定:**
  現実では使い込まれたテックウェア、擦り切れたカーゴパンツ、機能的なアーマー。夢境では角張ったキャタピラ車両、無骨なコンテナ前線基地、武骨な実体装甲兵器。

### 02. ヴォストーク重工・未来戦術局（Vostok Tactics / V-TAC）
**「戦争とは、最も洗練されたリソースマネジメントである」**

```
・所属層: 合法
・組織種別: メガコングロマリット潜行事業部
・シンボルカラー: スノーホワイト × ネオンシアン
・本拠地: 環太平洋経済圏メガフロート都市
```

- **組織概要:**
  エネルギー、通信、先端重機を独占する世界的大複合企業「ヴォストーク・グループ」の潜行部門。本業の国際特許や資源採掘の許認可を維持するため、機構への登録と義務的な代理戦を忠実に遂行している。現場は株主総会と納期に追われる企業戦士たち。
- **戦術思想（プレイスタイル）:**
  **【高規格インフラ・高速資源抽出・無人機量産】**
  拠点の発展速度が全組織中随一。最先端のAIドローンと多脚車両による圧倒的な生産・経済力で盤面を制圧する。
- **ビジュアル規定:**
  現実では洗練されたビジネススーツにスマートな通信端末を合わせたコーポレートスタイル。夢境では光る幾何学的なビルディング、クリーンルームのような白磁のドローン兵器。

### 03. 調停執行監察隊（Audit & Enforcement Corps / AEC）
**「中立と秩序を乱す不確定要素は、すべて観測ログから抹消する」**

```
・所属層: 合法（機構直属）
・組織種別: IMCO直属の治安・監査執行部隊
・シンボルカラー: ピュアマットホワイト × コールドシルバー
・本拠地: 観測都市エデン・第1司令タワー
```

- **組織概要:**
  IMCO上層部が直轄する軍事組織。表向きは「公平な調停の監視」と「違法潜行組織の取り締まり」を任務とするが、その実態は機構の暗部。少女の加害に気づいた潜行者を「事故」に見せかけて未帰還に追い込むなど、制度維持のための汚れ仕事を担う。
- **戦術思想（プレイスタイル）:**
  **【電磁シールド・索敵妨害・規格防衛】**
  相手の通信やレーダーを封じるジャミング技術、強固な防壁の即時展開。相手のミスを誘い、冷酷に息の根を止めるコントロール型戦術。
- **ビジュアル規定:**
  現実では隙のない純白の詰襟軍服に白手袋。夢境では完全な左右対称の幾何学要塞、無機質な鏡面仕上げの無人兵器。

### 04. アカデミア・テラピア神経医学財団（Therapia Foundation）
**「我々が求めているのは領土ではない。人類の意識の次なるフロンティアだ」**

```
・所属層: グレー
・組織種別: 医療・脳科学研究財団
・シンボルカラー: ミントグリーン × クロームシルバー
・本拠地: アルプス地下生体研究特区
```

- **組織概要:**
  かつて少女が隔離されていた地方療養施設をルーツに持つ研究機関。少女の生体維持装置と脳波同期プロトコルの基本特許を保有しており、そのデータ解析権を維持する見返りとして代理戦を引き受けている。裏では少女の脳波サンプルの闇取引に深く関与していると噂される。
- **戦術思想（プレイスタイル）:**
  **【試合内ツリーの先行・バイオナノリペア・試作実験兵器】**
  中央拠点の研究資源を奪取した際の研究加速率が極めて高い。序盤は脆いが、終盤に未知の試作兵器を投入して劇的な逆転を狙うハイテク・レイトゲーム型。
- **ビジュアル規定:**
  現実では医療用白衣にサイバネティクス義肢を組み合わせた研究者スタイル。夢境ではDNA二重螺旋を思わせる有機的な幾何学タワー、ナノマシンを噴霧する医療系兵器。

### 05. 常闇の観測会（Noct-Observers）
**「彼女が見る夢こそが神託であり、我らはその結末を寿ぐ影にすぎない」**

```
・所属層: グレー
・組織種別: 少女崇拝系秘密結社
・シンボルカラー: ディープネイビー × アンティークゴールド
・本拠地: 所在不明（分散型隠れ家ネットワーク）
```

- **組織概要:**
  少女を「因果を紡ぐ生ける神（眠りの預言者）」として崇拝する宗教的カルト結社。国家からの報酬には一切興味を持たず、夢境の深淵に接近し「彼女の言葉」を聴く権利を得るために正規登録している。多くの政治家や富豪が秘密裏に信徒として名を連ねている。
- **戦術思想（プレイスタイル）:**
  **【未確定領域（霧）の活用・隠蔽奇襲・長距離呪詛砲撃】**
  索敵の霧の中に潜む部隊のステルス性能が高く、視界外からの奇襲や嫌がらせに長ける。予測不能な進軍ルートで敵を翻弄するトリッキースタイル。
- **ビジュアル規定:**
  現実では深フードのコート、天体図を模した装身具。夢境では黒曜石のような儀式尖塔、影を纏ったような輪郭の不鮮明な部隊トークン。

### 06. 零区（Zone-0 / ゾーン・ゼロ）
**「お前たちの茶番の未来、俺たちが丸ごと買い叩いてやるよ」**

```
・所属層: 違法（アンレジスタード）
・組織種別: 地下ハッカーシンジケート・未登録潜行者同盟
・シンボルカラー: マットブラック × アシッドイエロー
・本拠地: 旧スラム地下サーバー群、廃油田プラットフォーム
```

- **組織概要:**
  初期の小国から流出したプロトタイプ機材を闇改造し、登録組織の同期回線に「相乗り（ピギーバック）」して侵入するサイバー海賊。表向きは存在しないことになっているが、国家が「正規割り当てだけでは勝てない」と判断した際に裏金で雇われる。未来のインサイダー情報を抜き取るブローカーでもある。
- **戦術思想（プレイスタイル）:**
  **【電子ハッキング・敵拠点の奪回・ヒット＆アウェイ】**
  敵の部隊を一時的に暴走・乗っ取るスキルや、拠点を破壊して即座に資源を奪い逃亡する機動ゲリラ戦を得意とする。正面衝突を避け、盤面を混沌に陥れる。
- **ビジュアル規定:**
  現実ではジャンクパーツを継ぎ接ぎした非正規のダイブスーツ、覆面、タトゥー。夢境ではワイヤーフレームが剥き出しになった歪な拠点、ノイズの走る粗暴な改造兵器。

## 3. シーズン運営と組織の動態

組織の立ち位置は固定ではない。シーズンごとのストーリーや全プレイヤーの勝敗結果に応じて、組織の境界線が変動する。

- **合法組織の凋落:** 不祥事や機構への反逆により、合法組織がライセンスを剥奪され「違法側」へ転落する（新衣装・新ユニットの登場理由）。
- **違法組織の恩赦:** 功績や政治取引により、違法組織が正規登録を認められて「合法側」へ参入する。
- **衣装の2系統販売:**
  すべての組織の指導者キャラクターには、「現実の制服（日常・管制室）」と「夢の中の姿（戦場アバター）」の2系統のビジュアルが存在し、ガチャおよびシーズンパスの主要な収益軸となる。
