## トーン＆マナーの三原則

1. **清潔で冷徹な近未来官僚社会 × 現場の労働者のリアリティ**
   - 泥臭いポストアポカリプスや魔法ファンタジーではなく、極限まで合理化された近未来の企業・官僚社会を描く。
   - 指導者たちは英雄ではなく、「他国の国境のために戦わされる現場会社員・請負人」の疲弊とプロ意識を持つ。
2. **少女を単なる被害者やマスコットにしない**
   - 少女は同意なく十数年眠らされてきた被害者であると同時に、**自分を利用する世界に対して静かな加害を行う冷徹な執行者**である。
   - 性的・扇情的な演出、メルヘン調の甘い救済を完全に排除する。
3. **ゲーム仕様との完全な同期**
   - 画面上のチケット、アドオン、霧、三つ巴、リセットされる盤面は、すべて世界観上の物理・情報現象として合理的な説明を持つ。
