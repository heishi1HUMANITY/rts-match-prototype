# ROB YOU

銀行の支店長と強盗団に分かれて、金庫の金塊（$2,000,000）を守る・奪う、非対称型の見下ろし対戦ストラテジー。ブラウザで遊べます。相手側はAIが操作します（AI同士の観戦もできます）。

画面はニュース番組「LBN 24」の生中継という体裁です。上部のテロップの文面と色で状況が変わったことがわかり、下部の速報テロップとティッカーで事件の経過が流れます。

## 起動

```sh
npm install
npm run dev      # http://127.0.0.1:5173/
npm run check    # 型検査・テスト・ビルド
```

## スタンドアロン版（静的配信）

```sh
npm run build:standalone
```

`dist-standalone/` をそのまま静的ホスティングに置くか、`index.html` をブラウザで直接開けば遊べます（JS・CSS を埋め込んだ1ファイル。外部への読み込みは Web フォントだけ）。

- `index.html`：ゲーム本体（強盗・支店長で遊ぶ、AI同士を観戦する）
- `watch/index.html`：AI同士の中継だけを流し続けるページ。試合が終わると12秒後に次の試合。視点（全体／強盗／銀行、`V`）と速度（`1` `2` `3`、`Space` で一時停止）を切り替えられ、`N` で次の試合へ。URL で試合を指定できる：`?seed=12&layout=5038&plan=thermal-van&view=crew&speed=2`（パネルの「この試合のURL」）。開発中は `npm run dev` で `/watch/` を開く。

## 流れ

| 段階 | 状況 | 終わるとき |
| --- | --- | --- |
| 偵察（平常営業中） | 強盗は客と同じ見た目で下準備。支店長はカメラ・支店長室の窓・警備員の周りだけが見える | 支店長の通報、爆発音、強盗の強行開始、閉店時刻（15:00） |
| 警察到着待ち（速報） | 銃撃戦が始まる。強盗は人質を取り、籠城装備を展開する | 60秒後に警察が到着（爆発があると早まる） |
| 突入（緊急中継） | 支店長は警察を指揮。SWAT（同時4人まで）・狙撃手・道路封鎖・催涙ガス・壁の爆破 | 強盗が金塊4袋以上を持って逃走 → 強盗の勝ち／強盗全滅か8分経過 → 銀行の勝ち |

### 毎回少し違う間取り

試合ごとに支店のレイアウト番号が選ばれ、内部の扉の位置、各部屋の家具配置、金庫内の金塊の置き場、キーカードの在処、初期カメラの位置が少し変わります（作戦説明に番号が出ます）。外壁・出入口・金庫・支店長室・道路は固定です。

### 通報のルール（偵察中）

- 客を左クリックで選び、`F` を長押しして5秒観察する。その間に不審な行動（作業中・金塊を運ぶ・関係者エリアにいる）が3秒以上見えれば通報できる。見誤ると6秒間観察できない。
- 覆面・重武装の人物、または関係者エリア（赤い網掛け）で2.5秒続けて見えている人物は `R` で即通報できる。
- ループ映像を仕込まれたカメラや、買収された警備員の視界には強盗が映らない。

### 強盗団

- 事前計画で金庫の突破手段（ドリル／サーマルペースト／指向性爆薬）と逃走手段（バン／フルトン回収）を選ぶ。突破ツールはクルーの1人が持ち込む。
- バン：裏通りのバンに金塊を積んで走り去る。道路封鎖で止められ、走行中は撃たれる。
- フルトン回収：西隣のホテル屋上（路地の非常階段2か所から上がる）で金塊に気球を付け、「回収機を呼ぶ」と8秒後に屋上の上空を通過して気球を吊り上げる（呼んだときだけ来る）。屋上と地上の間では撃ち合えないので、警察は非常階段を上がって屋上で戦うしかない。最後は袋を抱えたまま自分に気球を付けて脱出できる（回収済み＋回収待ち＋抱えた袋が目標に届けば）。
- 支店長室の扉を小型ドリルで破ると、支店長のキーカードが手に入り、金庫を手段に関係なく開けられる（解錠は支店長側に通知される）。
- 籠城装備（タレット・バリケード・罠）は警察到着前に買って在庫にため、いつでも展開できる。突入中の購入は、人質を1人解放するごとに1回だけ。解放すると交渉カード（警察を8秒拘束）も得る。
- クルーは同時に最大5人（警察到着前なら欠員を補充できる）。警察到着後は増やせない。

## 操作

| 操作 | 内容 |
| --- | --- |
| 左クリック／ドラッグ | 自分のユニットを選択 |
| 右クリック | 移動・攻撃・文脈に応じた行動（ツールチップに表示） |
| `Shift`+右クリック | 扉を爆薬で破る（強盗） |
| `Q` | 全員選択 |
| 左パネルの「自動行動」 | 選んだ戦闘員に 迎撃（持ち場の近くの敵を迎え撃って戻る）・攻撃（見えている敵を追う）・人質（近くの民間人を拘束、強盗のみ）・徘徊（持ち場のまわりを歩く）を設定。手動の命令が優先され、移動させると持ち場もそこへ移る |
| `M` | マスク装着（強盗） |
| `F` 長押し／`R` | 観察／通報（支店長） |
| `Space` | 一時停止 |
| `1` `2` `3` | 速度 |
| `H` | ヘルプ |

## 構成

- `src/config.ts` 調整用の数値（予算・時間・武器・コストなど）
- `src/map/level.ts` 銀行のマップ（84×48タイル）と間取りの揺らぎ（`buildLevel(layout)`、0 が基準）
- `src/sim/` ゲームのルール（DOM非依存・乱数シード固定・固定tick）
- `src/ai/` 強盗側AI・銀行側AI（見えている情報だけを使う）
- `src/render/` Canvas描画（床の質感・壁の陰・家具・小物、人物の描き分け、自陣営の目印）、`src/ui/` ニュース風HUD・入力・画面
- `src/sim/auto.ts` 戦闘員ごとの自動行動
- `src/watch.ts`・`watch/index.html` AI中継ページ、`vite.standalone.config.ts`・`build/inline-html.ts` スタンドアロン版のビルド

## エージェント対戦（バランス調整用）

AIエージェント同士を、20ゲーム秒ごとのコマンド入力で対戦させるドライバー。両陣営は自陣営から見えている情報だけをテキストで受け取り、JSONのコマンド列を返す。両方そろうと時間が進む。

```sh
npm run agent -- new --session=.agent-play/m1 --seed=1 --every=20   # --layout=0 で基準の間取り（既定はシードと同じ番号）
npm run agent -- rules --side=crew --session=.agent-play/m1        # 規則とコマンド一覧（その試合の扉の位置つき）
npm run agent -- map --session=.agent-play/m1                      # 座標つきの地図
npm run agent -- view --session=.agent-play/m1 --side=bank
npm run agent -- submit --session=.agent-play/m1 --side=crew '[{"t":"plan","breach":"thermal","escape":"van"}]'
```

`submit` は相手の提出を待ってから時間を進め、次の観測を返す。片側を組み込みAIにするなら `new` に `--ai=bank` などを付ける。調整の経緯と結果は [BALANCE.md](BALANCE.md)。
